# 5. 기술 스택

---

## Front-End

| 기술 | 버전 / 비고 |
|------|------------|
| **React** | 19 |
| **TypeScript** | ~5.7 |
| **Vite** | 6.2 |
| **TailwindCSS** | v4 (`@tailwindcss/vite` 플러그인) |
| **Redux Toolkit + redux-saga** | 상태 관리·비동기 사이드 이펙트 |
| **react-router** | v7 (파일 기반 자동 라우팅) |
| **Axios** | API 클라이언트 (`VITE_API_HOST` 기반) |
| **shadcn/ui** | Radix UI 기반 컴포넌트 |
| **i18next** | 한국어/영어 다국어 |
| **Pretendard** | 웹폰트 (번들 포함) |
| **recharts** | 관리자 통계 차트 |
| **framer-motion** | UI 애니메이션 |
| **Yarn** | 4.9.4 (패키지 매니저) |

**주요 화면**
- **학생**: 홈, 제보 작성·완료, 제보 이력·상세, 포인트샵, 마이페이지
- **인증**: 로그인, 소속 선택 → 회원가입, Google OAuth 콜백, 계정 찾기
- **관리자**: 장소 관리(3단 컬럼 + Sheet CRUD), 제보 관리, 포인트·기프티콘 관리, 대시보드, 사용자 관리

## Back-End

| 기술 | 버전 / 비고 |
|------|------------|
| **Spring Boot** | 4.0.6 |
| **Java** | 17 |
| **Gradle** | 빌드 |
| **Spring Data JPA** | Hibernate, MySQL 연동 |
| **Spring Security** | OAuth2 Resource Server (JWT), BCrypt, Google OAuth2 |
| **springdoc-openapi** | 3.0.2 — Swagger UI (`/swagger-ui.html`) |
| **Spring Actuator** | 헬스 체크 (`/actuator/health`) |
| **Lombok** | 보일러플레이트 감소 |
| **Flyway** | DB 마이그레이션 (`db/migration/V*.sql`, repeatable seed) |

### 서비스 레이어

| Path | 기능 |
|------|------|
| `auth/` | BCrypt 로그인, JWT 발급, `AdminAuthorizationHelper` |
| `location/` | `LocationNode` CRUD, `LocationOperatingSchedule` 관리 |
| `member/` | 회원가입, 소속 변경 |
| `point/` | 포인트 잔액·적립·교환 |
| `report/` | 제보 생성(Cloud Run `/analyze` 호출), 조회 |
| `reward/` | 리워드 목록, 포인트 교환, 기프티콘 관리 |
| `savings/` | 건물별 절약량 집계, `isReportableAt()` |
| `admin/` | 제보·대시보드·통계·기프티콘 관리 |
| `tariff/` | `ElectricityTariffService` — 한전 OPEN API 월별 단가 동기화 |

## Database

| 기술 | 버전 / 비고 |
|------|------------|
| **MySQL** | 8.4 (Docker Compose, `energy_db`) |
| **DDL 전략** | `ddl-auto: validate` + Flyway 마이그레이션 |

### 엔티티

| 엔티티 | 테이블 | 설명 |
|--------|--------|------|
| `Member` | `member_db` | 회원 (email, BCrypt password, phoneNumber, userType, affiliation) |
| `Affiliation` | `affiliation_db` | 소속 캠퍼스/기관 — Flyway 시드 |
| `LocationNode` | `location_node_db` | 장소 트리 GROUP/LEAF, depth, sortOrder, LEAF 자원 수량 |
| `LocationOperatingSchedule` | `location_operating_schedule_db` | 장소별 요일 운영 스케줄 — AI metadata |
| `Report` | `report_db` | 제보 (imageUrl, wasteType, status, estimatedKwh, estimatedSavingsKrw, estimatedPoint, pointAwarded) |
| `MemberPoint` | `member_point_db` | 회원 포인트 (가입 시 0P 생성, 제보 적립) |
| `Reward` | `reward_db` | 리워드 상품 |
| `GifticonExchange` | `gifticon_exchange_db` | 기프티콘 교환 내역 |
| `ElectricityTariff` | `electricity_tariff_db` | 한전 API 월별 `unit_cost_krw` (교육용 계약) |

**시드**: Flyway `R__seed_dev.sql` — 소속(삼육대학교), 루트 GROUP + LEAF 장소, 리워드 샘플, admin/user 더미 계정

## AI

| 기술 | 버전 / 비고 |
|------|------------|
| **Gemini 2.5 Flash** | Vertex AI (`us-central1`) |
| **YOLOv8n** | Ultralytics COCO 사전학습 (person/chair/desk) |
| **YOLOv8n Custom** | `ac_best.pt` (Roboflow 파인튜닝, mAP 0.990) |
| **Roboflow** | `office-air-condition` v1 (2,016장) |
| **FastAPI** | AI 서비스 (monorepo `ai/for_deploy/campus_api/` → Cloud Run) |
| **OpenCV** | 이미지 크롭·전처리 |

### AI 응답 필드

| 필드 | 타입 | 설명 |
|------|------|------|
| `result` | String | `PASS` / `ERROR` / `WASTE_DETECTED` |
| `message` | String | 한국어 사용자 메시지 |
| `ac_status` | String | `ON` / `OFF` / `UNKNOWN` |
| `light_status` | String | `ON` / `OFF` |
| `reason` | String | Gemini 판단 근거 |
| `expected` | String | 예상 절약 금액, 예: `"494원"` |
| `expectedKwh` | String | 예상 절약 전기량, 예: `"3.8 kWh"` |

### 에너지·포인트 상수

| 구분 | 상수 | 비고 |
|------|------|------|
| **AI Gemini 프롬프트** | 형광등 32W · LED 15W · AC 1,500W · 120원/kWh · 방치 cap 60분 | Cloud Run `/analyze` |
| **BE `EnergyConstants`** | 형광등 40W · LED 20W · AC 1,500W · cap 120분 · 포인트율 0.18 | `SavingsCalculationService` |
| **전기 단가** | 한전 OPEN API `unitCost` (교육용 cntrCd=400) | 실패 시 **130원/kWh** fallback |

## Infra

| 기술 | 비고 | 상태 |
|------|------|------|
| **Docker Compose** | MySQL 8.4 + BE:8080 + FE:8081 (nginx) | ✅ 운영 중 (ubuntu03) |
| **학교 서버** | ubuntu03 Docker 배포 | ✅ |
| **GCP Cloud Run (AI)** | FastAPI `/analyze` (`us-central1`) | ✅ 배포·BE 연동 |

**배포 스크립트**: `deploy.sh` → `ai/deploy.sh` → `be/deploy.sh` → `fe/deploy.sh` (Docker Compose)

환경 변수는 프로젝트 루트 `.env` 단일 파일 (`cp .env.example .env`).
