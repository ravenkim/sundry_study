# 2. 서비스 개요

---

## 2.1. 서비스명

**에코리포트 (EcoReport)**

**한 줄 소개**: AI 기반 캠퍼스 에너지 낭비 제보 및 보상 플랫폼 — 학생의 작은 제보가 학교 전기료를 줄이고, 그 절약분을 학생에게 돌려주는 선순환 구조.

> **"빈 강의실에 켜진 전등 사진 한 장 → AI 분석 → 포인트 적립"**

---

## 2.2. 문제 정의

### 막대한 에너지 낭비 비용

대학 교내 전체 에너지 비용의 약 **30%**가 빈 강의실에 방치된 조명과 에어컨 등에서 발생합니다. 수업이 끝난 뒤에도 전열 기구가 수 시간 켜진 채 방치되면, 개별 강의실 단위로는 작아 보이지만 캠퍼스 전체로 합산하면 막대한 비용과 탄소 배출로 이어집니다.

| 지표 | 수치 |
|------|------|
| 강의실 평균 에너지 낭비 비율 | 교내 에너지 비용의 약 **30%** |
| 형광등 1개(32W) 1시간 방치 | 약 **0.032 kWh** |
| 에어컨(1,500W) 1대 4시간 방치 | 약 **6 kWh (720원, 120원/kWh 기준)** |
| 100개 강의실·월 20%·2시간 방치 가정 | 월 **800 kWh 이상**, 전기료 **약 10만 원 이상** |

### 기존 해결책의 한계

| 기존 방안 | 한계 |
|----------|------|
| **스마트빌딩 IoT 자동 제어** | 인프라 구축 비용 수억 원, 기존 건물 적용 어려움 |
| **관리인 순찰** | 인건비 발생, 실시간 대응 불가, 야간·주말 공백 |
| **학생 캠페인·스티커 부착** | 강제력 없음, 일시적 효과, 지속 참여 유도 어려움 |
| **절전 안내 방송** | 인지 → 행동 전환율 낮음, 피드백·보상 부재 |

### 행동 유인의 부재

강의실을 가장 마지막에 나서는 **학생**이 낭비를 가장 먼저 발견하지만, 본인의 시간과 수고를 들여 기기를 끌 **자발적 인센티브가 전혀 없습니다**.

> **핵심 가설**: "합리적인 보상이 주어진다면 대학생은 에너지 낭비를 자발적으로 제보할 것이다."

### 사회적·정책적 맥락

- **2030 탄소중립 국가 목표**: 교육 기관의 에너지 절감 의무화 논의 진행 중
- **교육부 그린스마트 미래학교 사업**: 학교·대학 에너지 효율화 국가 투자 확대
- **에너지 비용 급등**: 대학·공공기관의 에너지 관리 압박 증가

### 1차 타겟 — 대학 캠퍼스

- **관리 공백**: 동아리실·세미나실 등 수업 시간표와 무관한 공간의 운영 상태 파악 어려움
- **순찰 한계**: 층수가 높고 엘리베이터가 없는 건물, 언덕·계단 등 물리적 제약
- **문화 확산**: 배움의 장에서 친환경 습관을 익히고 졸업 후 사회로 확산

## 2.3. 해결 방안

### 크라우드소싱 기반 제보

별도의 설비 투자 없이, 학생들의 **스마트폰 하나**로 캠퍼스 내 에너지 낭비 상황을 실시간으로 수집합니다. 기존 건물 인프라를 전혀 변경하지 않고 카메라만으로 운영 가능합니다.

### AI 자동 판별 엔진

학생이 찍어 올린 사진을 **3단계 AI 비전 파이프라인**이 즉시 분석하여 켜진 조명/냉난방기 상태와 빈 강의실 여부를 검증하고, 어뷰징을 차단합니다.

1. **YOLOv8n** — person/chair/desk 탐지 → 빈 강의실만 통과
2. **YOLOv8n Custom** — 에어컨·형광등 등 에너지 소비 기기 탐지
3. **Gemini 2.5 Flash** — 운영 스케줄과 기기 상태 종합 → 낭비 여부·절약량 산출

판별은 **5초 이내** 완료되며, `expected`(절약 금액)와 `expectedKwh`(절약 전기량)를 반환합니다.

### 절약된 비용의 리워드화

낭비 제보가 확인되면 학교 시설팀에 전달되어 전력 소모를 차단하며, 학교가 아낀 전기료의 일부를 제보 학생에게 **에어프레시(탄소 절감 포인트)**로 지급하여 식비·기프티콘 등으로 사용할 수 있게 합니다.

```
[학생] 사진 제보 → [AI] 낭비 판별 + 절약량 계산 → [포인트] 즉시 적립
                                                       ↓
[관리자] 제보 확인 → 조치(소등 등) → [절약량] 실제 절감
                                                       ↓
[건물주] 절약 전기료의 20% 플랫폼 납부
         ├── 10% → 플랫폼 수수료
         └── 90% → 학생 포인트 풀 (기프티콘 교환)
```

### 어뷰징 방지 (요약)

4단계 다층 방어(L1~L4)를 적용합니다. 운영 시간 외만 제보·강의실당 1인 1회 중복 차단은 ✅ 구현 완료.
