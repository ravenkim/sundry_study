## 기능 1: AI 기반 낭비 상태 이미지 분석

제보된 이미지를 AI가 즉각 분석하여 형광등 켜짐, 에어컨 작동 및 사람 존재 여부(빈 강의실)를 파악하고 낭비 상황을 공식 인증합니다.

| 단계 | 모델 | 역할 |
|------|------|------|
| 1단계 | YOLOv8n (COCO) | person/chair/desk 탐지 → 강의실·사용 중 여부 |
| 2단계 | YOLOv8n Custom (`ac_best.pt`, mAP 0.990) | 에어컨·형광등 등 에너지 기기 탐지 |
| 3단계 | Gemini 2.5 Flash | ON/OFF 판별 + `expected`·`expectedKwh` 산출 |

**판별 결과**

| `result` | 의미 | BE 처리 |
|----------|------|---------|
| `WASTE_DETECTED` | 낭비 확인 | 제보 저장 + 포인트 즉시 적립 |
| `PASS` | 사용 중 또는 기기 꺼짐 | 저장 안 함 |
| `ERROR` | 강의실 아님·촬영 부적합 | 저장 안 함 (운영 중 강의실 안내) |

## 기능 2: 위치 태깅 기반 원클릭 제보

복잡한 텍스트 입력 없이 앱 실행 → 카메라 촬영 → 건물명·호수(`LocationNode` LEAF) 선택만으로 **10초 이내** 제보가 완료됩니다.

**제보 전 검증 (BE, AI 호출 전)**
- 운영 시간 중(`isReportableAt = false`) → 제보 불가
- 동일 회원+강의실 기존 제보 → `ALREADY_EXISTS`
- FE: `reportable: true`·`alreadyReported: false` LEAF만 목록 표시

**제보 UX 보조**
- `/report-form` 사진 단계: AI 판별 3조건 + 촬영 3항목 가이드 (`ReportCriteriaGuide`)
- 운영 중 강의실 미표시 → *"지금 제보할 수 있는 강의실이 없습니다"* 안내

## 기능 3: 실시간 리워드 포인트 정산

AI 판별이 성공하면 학생에게 **즉시 포인트**를 지급합니다.

- **포인트 산식**: `point = round(절약_원 × 0.18)` (`POINT_RATE = 0.18`)
- **잔액 조회**: `GET /api/points/me`
- **교환**: `POST /api/points/exchange` → `GifticonExchange` PENDING 생성
- **교환 이력**: `GET /api/points/exchanges/me`
- **관리자 승인**: `PATCH /api/admin/gifticon-exchanges/{id}` → `COMPLETED`

누적 포인트는 교내 식당 사용권·스타벅스 등 **기프티콘**으로 교환할 수 있습니다.

## 기능 4: 시설 관리자 AI 리포트 및 절약 대시보드

학교 시설팀에게 실시간 낭비 현황, 운영 스케줄 대조, 이번 달 누적 전기료 절약 추정액 및 정산 데이터를 시각화합니다.

| 화면 | 경로 | API |
|------|------|-----|
| 장소 관리 | `/admin/buildings` | `/api/admin/location-nodes/*` |
| 제보 관리 | `/admin/reports` | `GET/PATCH /api/admin/reports` |
| 포인트·기프티콘 | `/admin/points` | `/api/admin/gifticon-exchanges/*` |
| 통계 대시보드 | `/admin/stats` | `GET /api/admin/dashboard`, `/api/admin/stats` |
| 사용자 관리 | `/admin/users` | 회원 목록·관리 |

**대시보드 제공 지표 (예)**
- 월간 제보 건수, 추정 절감 전기료(kWh·원)
- 건물별 `totalKwh`, `thisMonthKwh`, `reportCount`
- 탄소 절감량·소나무 환산 (FE 집계 UI)

## 기능 5: 회원 인증·소속 관리

- **이메일 회원가입**: `/signup/affiliation` → 소속 선택 → `/signup` 정보 입력
- **Google OAuth**: `/oauth/callback?token=...` → 소속 미설정 시 affiliation PATCH
- **관리자 계정**: Flyway 시드 `UserType.ADMIN`
- **계정 찾기**: `/find-account`
- **다국어**: i18next 한국어/영어 (`src/assets/locales/`)

## 기능 흐름도

```
[학생]
  ├─ 로그인 (이메일 / Google OAuth)
  ├─ AI 기준 확인 → 사진 촬영 → 제보 가능 LEAF 선택
  │       ▼
  │   [AI 3단계 — Cloud Run] → WASTE_DETECTED → 포인트 즉시 적립
  ├─ 제보 이력·절약량 확인
  └─ 포인트샵 → 기프티콘 교환 신청

[관리자]
  ├─ 장소·운영 스케줄 CRUD
  ├─ 제보 목록 (AI 결과·사진·상태)
  ├─ 기프티콘 교환 승인
  └─ 월간 절감 대시보드
```
