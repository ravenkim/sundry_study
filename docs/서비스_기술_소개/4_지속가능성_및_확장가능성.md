# 4. 지속 가능성 및 확장 가능성

---

## 4.1. 기대 효과

### 환경적 효과

버려지는 에너지를 즉각 차단하여 탄소 배출을 줄이고, 대학의 ESG 경영 및 **그린 스마트 캠퍼스** 조성에 직접 기여합니다.

| 지표 | 1개 캠퍼스 (100개 강의실 기준) |
|------|-------------------------------|
| 월 절약 전기 | 약 **600~1,000 kWh** |
| 월 탄소 절감 | 약 **280~470 kg CO₂** (0.469 kgCO₂/kWh) |
| 연간 절감 효과 | 소나무 약 **50~80그루** 흡수량과 동등 |

2030 탄소중립·그린스마트 미래학교 사업 등 **정책 흐름**과 부합합니다. 전국 약 200개 4년제 대학 확산 시 **연간 수십만 kWh, 수천 톤 CO₂** 절감 잠재력이 있습니다.

### 경제적·사회적 효과

| 대상 | 효과 |
|------|------|
| **학교/건물주** | IoT 설비 없이 월 전기료 **10~30%** 절감 |
| **학생** | 제보 1건당 절약 금액의 일부 포인트 → 기프티콘·식비 등 체감 혜택 |
| **플랫폼** | 절감액 10% 수수료 — 100개 건물 기준 월 약 **22만 원** |

학생 주도 **액티브 참여 문화** 형성, 크라우드소싱 기반 **저비용 스마트캠퍼스** 모델 제시.

### 사용자 편의성

- **스마트폰만으로 즉시 참여**: 별도 앱 설치 없이 모바일 웹, `<input capture="environment">` 카메라 직접 호출
- **5초 이내 AI 판별**: "낭비 확인 + N원 절약 + N포인트" 한 화면 확인
- **직관적 UI**: Volt Yellow `#FFC107` · Eco Green `#4CAF50` 브랜드 컬러, 하단 탭 5개
- **진입 장벽 최소**: 기존 건물 인프라 교체·센서 부착 불필요

## 4.2. 확장 가능성

### 안정적 수익화 모델

학교가 실제로 절감한 전기료 중 일정 비율(예: **20%**)을 납부하면, 플랫폼이 **10%** 수수료를 취하고 나머지 **90%**를 학생 포인트 풀로 제공하는 **자체 자생형** 비즈니스 구조입니다.

```
[건물주 / 대학] ── 절약 전기료 20% ──► [에코리포트]
                                          ├── 10% 플랫폼 수익
                                          └── 90% 학생 포인트 풀
```

| 수익원 | 시점 | 예상 규模 |
|--------|------|----------|
| 플랫폼 수수료 | 즉시 | 건물 수 비례 |
| 친환경 브랜드 스폰서십 | 6개월+ | 월 100만 원 수준 |
| 익명 에너지 데이터 B2B | 1년+ | 에너지 컨설팅사 |
| 공공기관 B2G 납품 | 1년+ | 지자체·정부기관 |

**손익분기점(BEP)**: Gemini·GCP 등 월 고정 지출 약 7만 원 기준, **약 32개 건물** 가입 시 BEP.  
**Energy BEP**: 플랫폼 서버 전력(~40 kWh/월) 대비 순절약 전환 약 **월 22건** (하루 1건, 70% 실조치).

> 상세: [서버_전력_및_에너지_손익분기점.md](../기획/캠퍼스_에너지_절약/04_기술_기획/서버_전력_및_에너지_손익분기점.md)

### 타겟 시장의 확장

| 단계 | 시장 |
|------|------|
| **1차** | 국내 200여 개 4년제 대학 캠퍼스 (200만 명) |
| **2차** | 지자체 청사, 도서관, 공공기관, 기업 오피스 (B2G, B2B) |
| **3차** | 자원 유형 확장 — 전기 → 수도·공조·난방 |

### 데이터 비즈니스 진출

특정 건물·시간대의 에너지 낭비 패턴 **익명 데이터**를 축적하여, 상습 방치 강의실 예측·에너지 효율화 **컨설팅 사업**으로 발전 가능합니다.

### 성장 로드맵 (목표)

| 단계 | 기간 | 목표 |
|------|------|------|
| 파일럿 | 1개월 | 제보 500건, 참여 100명, 건물 1~3개 |
| 초기 성장 | 3개월 | 제보 5,000건, 건물 10개 |
| 확산 | 6개월 | 대학 5개교, MAU 1,000명 |
| 확장 | 1년 | 대학 20개교, 공공기관 진출 |

## 발표 핵심 메시지

> **"사진 한 장이 캠퍼스를 바꿉니다."**

1. **문제**: 대학 전기료의 30%가 빈 강의실에서 낭비
2. **해결**: 학생이 사진 찍으면 AI가 분석하고 포인트 즉시 적립
3. **임팩트**: 한 캠퍼스 월 수백 kWh 절약, 소나무 50그루 효과
4. **확장성**: IoT 없이 모든 대학에 즉시 도입 가능
5. **비즈니스**: 절약 전기료의 일부를 학생에게 돌려주는 선순환
