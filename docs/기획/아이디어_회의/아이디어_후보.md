# 아이디어 후보 (2026-05-16)

**주제: AI를 활용한 지속 가능한 환경 및 생활 문제 해결 서비스**

---

## 에너지 / 탄소

### 1. 개인 탄소발자국 트래커 + AI 감축 코칭
- 일상 소비(교통, 식단, 쇼핑)를 입력하면 AI가 탄소 배출량 계산
- 맞춤 감축 플랜 제안 + 게이미피케이션으로 꾸준한 참여 유도

### 2. 가전 전력 낭비 감지 서비스
- 스마트플러그 데이터나 전기요금 고지서 입력
- AI가 낭비 패턴을 찾고 절약 습관 제안 (소형 가구 대상)

---

## 소비 / 음식

### 3. 냉장고 재료 기반 AI 레시피 + 식품 낭비 최소화
- 냉장고 사진이나 재료 목록 입력 → AI가 소비 기한 임박 재료 우선 레시피 추천
- 음식물 쓰레기 절감

### 4. 환경 점수 기반 소비 가이드
- 상품 바코드를 찍으면 AI가 환경 등급(탄소, 포장재, 원산지) 평가
- 대안 상품 추천으로 착한 소비 유도

### 5. 로컬푸드 연결 플랫폼
- AI가 사용자 위치 기반 근거리 농가·직거래 마켓 매칭
- 운송 탄소 줄이고 소농 지원

---

## 자원 / 재활용

### 6. AI 분리수거 가이드 (이미지 인식)
- 쓰레기 사진을 찍으면 AI가 재질 인식 → 올바른 분리배출 방법 안내
- 지자체별 규정 반영

### 7. 중고거래 물건 상태 AI 자동 평가
- 중고 물품 사진을 올리면 AI가 상태를 등급화하고 적정 가격 추천
- 자원 순환 촉진

---

## 정보 / 행동 변화

### 8. 환경 뉴스 개인화 브리핑 + 행동 연결
- AI가 관심사 기반 환경 뉴스를 요약
- "오늘 할 수 있는 작은 행동 1가지"를 매일 제안 → 정보→행동 전환

### 9. 기업 ESG 리포트 AI 요약 & 비교 서비스
- 복잡한 ESG 보고서를 AI가 요약·시각화
- 소비자가 기업 환경 성과를 쉽게 비교 → 착한 소비 기반 정보 제공

---

## 지역사회 / 공유

### 10. 동네 물건 공유 매칭 플랫폼
- 잘 안 쓰는 물건(공구, 캠핑용품 등)을 AI가 근거리 이웃과 자동 매칭
- 대여·공유로 불필요한 생산 수요 감소

---

## 팀 회의 추가 아이디어 (2026-05-15)

### 11. 재활용 LLM 챗봇
- 분리수거·재활용이 애매한 물건을 LLM에게 질문하면 답변
- 구현 난이도 낮고 단기 완성에 유리
- 확장 방향: 산업 폐유 등 환경 법령 RAG 연계

### 12. 한국 환경 법령 RAG 서비스
- GitHub 공개 한국 법 레포 활용
- 환경·폐기물 관련 법령을 RAG로 구축해 질의응답
- Gemini API 활용, 기술 차별성 높음
- 이은총·김해준 긍정적 반응

### 13. 통계청 API + AI 환경 정책 제안
- 통계청 API로 사회·환경 통계 수집
- AI가 문제를 분석하고 정책 개선안 생성
- 비영리/영리 방향성 먼저 정해야 구체화 가능

### 14. AI 이메일/클라우드 클리너
- 쌓아두는 스팸 메일, 클라우드의 중복 사진들이 데이터 센터의 전력을 낭비
- AI가 사용자의 클라우드와 메일함을 스캔하여 '가치 없는 데이터(중복 스크린샷, 오래된 홍보물, 유사 사진)'를 식별, 자동 분류
- 이미지 유사도 분석 + 자연어 분류(NLP)를 통한 데이터 가치 판단
- 눈에 보이는 쓰레기가 아닌 보이지 않는 디지털 오염을 해결하는 넷 제로 솔루션

### 15. 개인 물 소비 최적화 및 누수 탐지
- 스마트 수도 계량기 데이터나 수전 소리 분석을 통해 AI가 가정 내 물 사용 패턴을 분석
- 샤워, 설거지 등 용도별 물 사용량을 추정, 비정상적인 물 흐름을 감지해 누수를 조기에 경고
- 즉각적인 비용 절감 효과로 인해 지속 가능성이 높음

### 16. AI 가전 자가진단 및 부품 매칭
- 작은 고장에도 수리비가 새로 사는 값과 비슷하거나 차이가 거의 없어 멀쩡한 가전이 버려짐. 부품을 구하기도 힘들고 수리법도 어렵기 때문
- 가전제품의 작동 소음이나 외관 촬영을 통해 AI가 고장 원인을 진단
- 단종된 부품은 3D 프린팅 도면을 찾아주거나 중고 부품 시장과 연결
- 초보자도 따라 할 수 있는 AR 수리 가이드를 생성
- 기술 포인트: 소리 분석 AI(이상 징후 포착) + 멀티모달 AI(수리 가이드 생성)
- 새 제품 소비를 조장하는 경제 구조에서 수리해서 오래 쓰는 순환 경제를 기술로 지원
