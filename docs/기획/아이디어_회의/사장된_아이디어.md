# 사장된 아이디어

> 영리 모델이 불명확하거나, 데이터 확보가 어렵거나, 공모전 완성도 내기 어려운 아이디어를 보관합니다.

---

## 비영리 색채가 강하거나 수익 모델이 불명확한 아이디어

### 1. 개인 탄소발자국 트래커 + AI 감축 코칭
- 사용자 직접 입력 기반 → 데이터는 쉬우나
- 탄소 감축 코칭 자체로 돈을 받기 어려움. NGO·정부 사업 느낌

### 6. AI 분리수거 가이드 (이미지 인식)
- 이미지 인식 자체는 쉬우나
- "무료 공공 서비스"로 인식되어 유료화·수익화 어려움

### 8. 환경 뉴스 개인화 브리핑 + 행동 연결
- 뉴스 요약은 이미 ChatGPT/뉴스앱이 포화. 차별성 없음
- 광고 외 수익 모델 없음

### 11. 재활용 LLM 챗봇
- 구현 쉽고 데모는 되지만 수익 모델이 없음
- 공공 서비스 포지셔닝이라 영리 공모전에 부적합

### 13. 통계청 API + AI 환경 정책 제안
- 정책 제안 자체가 비영리 영역
- 구매자(고객)가 누군지 불분명

---

## 데이터 확보가 어려운 아이디어

### 4. 환경 점수 기반 소비 가이드
- 상품별 탄소 배출량·포장재·원산지 DB가 국내에 없음
- 직접 구축하려면 수년 단위 작업 → 공모전 불가

### 5. 로컬푸드 연결 플랫폼
- 근거리 농가·직거래 마켓 정보 DB 없음
- 농가 온보딩이 선행되어야 해서 사전 작업 양이 너무 큼

### 10. 동네 물건 공유 매칭 플랫폼
- 사용자 네트워크(닭이 먼저냐 달걀이 먼저냐) 문제
- 데이터 없이는 "매칭"이 안 됨. 콜드 스타트 문제 해결 불가

### 14. AI 이메일/클라우드 클리너
- Google/Apple 클라우드 API 접근 권한 심사 수개월 소요
- 개인정보·보안 이슈로 실제 데이터 연동이 사실상 불가 (데모용에 그침)

### 15. 개인 물 소비 최적화 및 누수 탐지
- 스마트 수도계량기가 국내 보급률 매우 낮음
- 소리 분석도 실제 가정에서 수집 데이터 필요 → 하드웨어 없이 검증 불가
