# 기대 효과 및 성과 지표 (Expected Effects & KPIs)

---

## 1. 기대 효과

### 환경적 효과
| 지표 | 1개 캠퍼스 (100개 강의실 기준) |
|------|-------------------------------|
| 월 절약 전기 | 약 600~1,000 kWh |
| 월 탄소 절감 | 약 280~470 kg CO₂ (전력 탄소계수 0.469 kgCO₂/kWh) |
| 연간 절감 효과 | 소나무 약 50~80그루 흡수량과 동등 |

### 경제적 효과
| 대상 | 효과 |
|------|------|
| 건물주/대학 | 월 전기료 10~30% 절감 (설비 투자 없이) |
| 학생 | 월 평균 1,000~5,000P 적립 → 기프티콘 교환 |
| 플랫폼 | 100개 건물 기준 월 수수료 약 22만 원 |

### 사회적 효과
- 학생 주도 탄소중립 문화 형성
- 크라우드소싱 기반 스마트캠퍼스 모델 제시
- 교육부 그린스마트 미래학교 사업과 연계 가능

## 2. 핵심 성과 지표 (KPI)

### 해커톤 데모 목표 (D-Day 기준)

| KPI | 목표값 |
|-----|--------|
| P0 기능 구현 완료율 | 100% |
| 제보 → AI 판별 → 포인트 적립 End-to-End 시연 | 성공 |
| AI 판별 소요 시간 | 5초 이내 |
| 관리자 대시보드 데모 | 시연 가능 |

### 서비스 운영 지표 (가상 목표, 발표용)

| 단계 | 기간 | 목표 지표 |
|------|------|----------|
| 파일럿 | 출시 후 1개월 | 제보 건수 500건, 참여 학생 100명, 건물 1~3개 |
| 초기 성장 | 3개월 | 제보 건수 5,000건, 건물 10개, 월 절약 전기 5,000 kWh |

## 4. 발표 핵심 메시지

> **"사진 한 장이 캠퍼스를 바꿉니다."**

1. 문제 제시: "대학 전기료의 30%가 빈 강의실에서 낭비됩니다"
2. 해결책: "학생이 사진 찍으면 AI가 분석하고 포인트가 쌓입니다"
3. 임팩트: "한 캠퍼스에서 월 수백 kWh 절약, 소나무 50그루 효과"
4. 확장성: "IoT 설비 없이 대한민국 모든 대학에 즉시 도입 가능"
5. 비즈니스: "건물주가 절약한 전기료의 일부를 학생에게 돌려주는 선순환 구조"
