# 시장 현황 분석

## 1. 목표 시장 정의

### 1차 시장: 국내 대학 캠퍼스
| 지표 | 수치 |
|------|------|
| 국내 4년제 대학 수 | 약 200개교 |
| 평균 강의실 수 (교당) | 100~300개 |
| 대학생 수 | 약 200만 명 |
| 대학 연간 전기료 지출 (대형 국립대 기준) | 수십억 원 |

### 2차 시장 (확장)
- 공공기관 (지자체 청사, 도서관)
- 기업 오피스 빌딩
- 병원, 대형 복합 시설

## 2. 경쟁 서비스 분석

| 서비스 | 유형 | 특징 | 에코리포트와 차이 |
|--------|------|------|-----------------|
| 삼성 SmartThings | IoT 자동화 | 기기 연동 필수 | 기존 인프라 필요, B2C |
| KT AI 에너지관리 | B2B 솔루션 | 빌딩 자동 제어 | 고비용, 기업 전용 |
| 한전 에너지마켓플레이스 | 공공 플랫폼 | 에너지 거래 | 개인 참여 구조 아님 |
| 줄여봐 (앱) | 개인 절약 앱 | 전기료 계산기 | 크라우드소싱 없음 |

**에코리포트 차별점**: 학생 직접 참여 + AI 자동 판별 + 보상 연계 → 기존 서비스 공백 영역

## 3. 유사 성공 사례 (레퍼런스)

| 사례 | 내용 | 시사점 |
|------|------|--------|
| 당근마켓 | 로컬 크라우드소싱 + 보상 없이도 자발 참여 | 커뮤니티 동기 활용 |
| 포켓몬고 | 현실 공간 기반 앱 + 게이미피케이션 | 제보·탐색 행동 유도 |
| 씨리얼 (영수증 리워드) | 영수증 찍으면 포인트 | 일상 행동 → 보상 연결 성공 |
| 우리동네 환경지킴이 (지자체) | 시민 제보 → 포인트 → 지역화폐 | 공공 보상 모델 검증됨 |

## 4. SWOT 분석

| | 긍정 | 부정 |
|--|------|------|
| **내부** | **강점(S)**: 저비용 도입, 학생 참여 동기(보상), AI 자동화 | **약점(W)**: 초기 제보 데이터 부족, 어뷰징 리스크 |
| **외부** | **기회(O)**: 탄소중립 정책 수혜, 그린캠퍼스 트렌드, 에너지 비용 급등 | **위협(T)**: IoT 설비 확대 시 플랫폼 필요성 감소 |

---

## 5. 시장 진입 전략

```
Phase 1 (해커톤)
└── MVP: 단일 캠퍼스 시뮬레이션 데모

Phase 2 (3개월 내)
└── 파일럿: 1개 대학 실제 운영 → 데이터 수집

Phase 3 (6개월~1년)
└── 대학 10개교 → 교육부 그린스마트 연계 입찰

Phase 4 (장기)
└── 공공기관·기업 오피스로 확장, B2G 솔루션화
```
