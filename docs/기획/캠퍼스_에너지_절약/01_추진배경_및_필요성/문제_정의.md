# 추진 배경 및 문제 정의

---

## 1. 문제 상황

### 현상
- 대학 캠퍼스 내 빈 강의실·복도·화장실에서 조명·에어컨·히터 등이 장시간 켜진 채 방치되는 일이 빈번하게 발생
- 수업이 끝난 강의실에서 마지막 학생이 소등하지 않으면 수 시간 동안 전기가 낭비됨

### 수치 (추정 근거)
| 지표 | 수치 |
|------|------|
| 강의실 평균 에너지 낭비 비율 | 전체 교내 에너지 비용의 약 30% |
| 형광등 1개 시간당 전력 | 약 40W → 8시간 방치 시 0.32 kWh |
| 에어컨(중형) 1대 시간당 전력 | 약 1.5 kW → 4시간 방치 시 6 kWh |
| 100개 강의실 기준 월 낭비 비용 | 수백만 원 수준 (전기료 단가 130원/kWh 기준) |

> ※ 위 수치는 공모전 발표 전까지 실제 학교 에너지 공시 자료 또는 한국전력 통계로 보완 필요

## 2. 기존 해결 방안의 한계

| 기존 방안 | 한계 |
|----------|------|
| 스마트빌딩 IoT 자동 제어 | 인프라 구축 비용 수억 원, 기존 건물 적용 어려움 |
| 관리인 순찰 | 인건비 발생, 실시간 대응 불가 |
| 학생 캠페인/스티커 부착 | 강제력 없음, 일시적 효과 |
| 절전 안내 방송 | 인지 → 행동 전환율 낮음 |

## 3. 인사이트: 왜 학생인가?

- 강의실에서 마지막으로 나가는 사람은 **학생**
- 동선상 가장 먼저 낭비를 발견하는 것도 **학생**
- 그러나 현재는 행동에 대한 **인센티브 부재** → 무관심

### 핵심 가설
> "합리적인 보상이 주어진다면 대학생은 에너지 낭비를 자발적으로 제보할 것이다."

## 4. 에코리포트의 포지셔닝

```
              저비용 ◄──────────────────────► 고비용
                  │                              │
          [에코리포트]                  [IoT 스마트빌딩]
       (크라우드소싱 기반)              (인프라 구축 필요)
                  │                              │
           학생 자발 참여                   자동화 완성
                  │                              │
         즉시 도입 가능                  장기 투자 필요
```

에코리포트는 **기존 건물 인프라 변경 없이** 스마트폰 카메라만으로 즉시 운영 가능한 **소프트웨어 우선** 접근
