# 사업 개요 — 에코리포트 (EcoReport)

> 캠퍼스 에너지 낭비 제보 기반 AI 절약 보상 플랫폼

---

## 사업 개요표

| 항목 | 내용 |
|------|------|
| 사업명 | 에코리포트 (EcoReport) |
| 부제 | AI 기반 캠퍼스 에너지 낭비 제보 및 보상 플랫폼 |
| 공모전 주제 | AI를 활용한 지속 가능한 환경 및 생활 문제 해결 서비스 |
| 대상 사용자 | 대학생 (제보자), 건물 관리자/건물주 (관리자) |
| 핵심 기술 | AI 이미지 분석, 절약량 자동 산출, 포인트 정산 엔진 |
| 플랫폼 형태 | 웹 앱 (모바일 우선) |
| 팀 | 14팀 (김해준, 정윤지, 차성호, 이은총) |

---

## 한 줄 요약

> **"빈 강의실에 켜진 전등 사진 한 장 → AI 분석 → 포인트 적립"**  
> 학생의 작은 제보가 학교 전기료를 줄이고, 그 절약분을 학생에게 돌려주는 선순환 구조.

---

## 서비스 구조 요약

```
[학생 사용자]
    ↓ 빈 강의실 낭비 사진 업로드
[에코리포트 플랫폼]
    ↓ AI 이미지 분석 (낭비 판별 + 위치 파악)
[관리자 대시보드]
    ↓ 건물주/관리자 확인 및 조치
[절약량 자동 계산]
    ↓ 월 단위 전기료 절감액 산출
[포인트 정산]
    → 학생: 포인트 → 기프티콘/리워드 교환
    → 플랫폼: 절감액의 10% 수수료
```

## 평가 항목 대응

| 평가 항목 | 대응 전략 |
|----------|----------|
| 주제 적합성 (20점) | 에너지 절약 + AI 분석 → 환경·지속가능성 직결 |
| 창의성/혁신성 (20점) | 크라우드소싱 + 보상 구조 = 기존 스마트빌딩과 차별, 학생 주도 |
| 기술성/완성도 (30점) | AI 이미지 분석, 관리자 대시보드, 포인트 정산 모두 시연 가능 목표 |
| 활용성 (20점) | 대학 → 공공건물 → 기업 확장 가능, 탄소 절감 사회적 가치 |
| 발표 (10점) | 시나리오 기반 데모 시연, 절감 수치 강조 |
