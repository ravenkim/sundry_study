# 비즈니스 모델 캔버스 (Business Model Canvas)

---

## 린 캔버스 (Lean Canvas)

| 항목 | 내용 |
|------|------|
| **문제** | 캠퍼스 빈 강의실 에너지 낭비 / 학생에게 행동 인센티브 없음 |
| **고객 세그먼트** | 대학생 (제보자) / 대학·건물 관리자 (구매자) |
| **고유 가치 제안** | "IoT 없이, 스마트폰 하나로 캠퍼스 전기료 줄이고 포인트 번다" |
| **해결책** | AI 이미지 분석 제보 앱 + 관리자 대시보드 + 포인트 정산 엔진 |
| **채널** | 학교 커뮤니티(에브리타임), 시설팀 B2B 영업, 학생처 파트너십 |
| **수익 구조** | 건물주 절약액의 20% → 플랫폼 10% 수수료 수취 |
| **비용 구조** | AI API 비용 (Gemini), 서버 비용, 포인트 풀 운영 |
| **핵심 지표** | 월간 제보 건수, 검증률, 절약 전기료, 포인트 교환률 |
| **경쟁 우위** | 크라우드소싱 네트워크 효과 (참여자 多 → 데이터 多 → 정확도↑) |

## 9-Block BMC

### 핵심 파트너
- Google Cloud / Gemini API (AI 기술)
- 기프티콘 공급사 (카카오, GS25 등)
- 대학 시설팀 / 건물주 (데이터·수익 파트너)
- 한국전력 (전기료 단가 기준 데이터)

### 핵심 활동
- AI 이미지 분석 모델 운영 및 개선
- 제보 검증 및 포인트 정산
- 어뷰징 모니터링
- 관리자 대시보드 운영

### 핵심 자원
- Gemini Vision API 기반 AI 판별 엔진
- 건물·강의실 DB
- 포인트 정산 엔진
- 개발팀 (BE: 차성호·이은총, FE·기획: 김해준)

### 가치 제안
| 고객군 | 가치 |
|--------|------|
| 학생 | 사진 한 장 → 즉각 보상 (포인트) |
| 건물주 | 무설비 투자로 전기료 절감 + 데이터 기반 관리 |
| 사회 | 탄소 감축, 에너지 낭비 문화 개선 |

### 고객 관계
- 학생: 게이미피케이션 (포인트, 랭킹, 뱃지) → 지속 참여 유도
- 건물주: 월간 리포트 자동 발송, 전담 CS

### 채널
- 학생: 에브리타임, 학교 공식 앱, 입소문
- 건물주: 시설팀 직접 영업, 대학 본부 파트너십

### 고객 세그먼트
- **B2C**: 대학생 (제보자, 무료 사용)
- **B2B**: 대학 시설팀, 건물 관리 회사 (유료, 수수료 납부)

### 비용 구조
| 항목 | 유형 |
|------|------|
| Gemini API 호출 비용 | 변동비 (제보 건수 비례) |
| 서버 인프라 (GCP) | 고정비 |
| 포인트 구매 비용 (기프티콘) | 변동비 (교환 건수 비례) |
| 운영·개발 인건비 | 고정비 |

### 수익 구조
| 수익원 | 내용 |
|--------|------|
| 플랫폼 수수료 | 건물주 납부액의 10% |
| (장기) 광고/스폰서십 | 친환경 브랜드 캠퍼스 광고 |
| (장기) 데이터 판매 | 건물 에너지 낭비 패턴 익명 데이터 → 에너지 컨설팅사 |
