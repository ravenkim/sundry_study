                   │ HTTPS                │ HTTPS
                   ▼                      ▼
┌─────────────────────────────────────────────────────────────────┐

│                                                                 │
│              [Spring Boot REST API]                             │
│         ┌───────────┬──────────────┬────────────┐              │
│         │ Auth API  │ Report API   │ Admin API  │              │
│         │ (JWT)     │ (제보 CRUD)  │ (대시보드) │              │

│                            │                                    │

           ┌─────────────────┼─────────────────┐
           ▼                 ▼                 ▼
  [Google Gemini       [MySQL DB]        [GCS Bucket]

## 2. 기술 스택

| 레이어 | 기술 | 선택 이유 |
|--------|------|----------|
| Frontend | React + TailwindCSS | 팀 CLAUDE.md 계획 스택 |
| Backend | Spring Boot 3.x | 팀 CLAUDE.md 계획 스택, 현재 코드베이스 |
| Database | MySQL | 팀 계획 스택, JPA 연동 용이 |
| AI | Google Gemini Vision API | 해커톤 주제 연계 (Google Cloud), 멀티모달 지원 |
| 이미지 저장 | Google Cloud Storage | Gemini와 동일 클라우드, 비용 효율 |
| 인프라 | Google Cloud (Cloud Run) | Docker 기반 서버리스 배포 |
| 인증 | JWT (Spring Security) | 현재 코드베이스에 구현됨 |

## 4. AI 판별 처리 흐름

```
[클라이언트]
    │ 사진 파일 업로드
    ▼
[Spring Boot API]
    │ 1. 이미지 → GCS 저장 (비공개 버킷)
    │ 2. GCS URI → Gemini Vision API 호출
    ▼
[Gemini Vision API]
    │ 프롬프트: "이 사진에 조명이나 에어컨 등 전열기구가 켜져 있고
    │           강의실에 사람이 없는지 판별하세요.
    │           응답 형식: { detected: boolean, type: string, confidence: float }"
    ▼
[Spring Boot API]
    │ 3. 판별 결과 파싱
    │ 4. confidence < 0.7 → "판별 불가" 처리
    │ 5. 어뷰징 필터 (동일 위치 1시간 내 중복 체크)
    │ 6. 포인트 적립 트랜잭션
    ▼
[클라이언트] ← 결과 반환
```

## 5. 데이터베이스 ERD (간략)

```
Member ──< Report >── Building ──< Room
  │                                 │
  └──< PointTransaction         Schedule (수업 시간표)
```

### 주요 테이블

**Member**: id, email, password_hash, point_balance, created_at

**Building**: id, name, address, admin_id, electricity_rate

**Room**: id, building_id, room_number, floor, devices(JSON)

**Report**: id, member_id, room_id, image_url, ai_result, ai_confidence, point_awarded, status, created_at

**PointTransaction**: id, member_id, amount, type(EARN/REDEEM), reference_id, created_at

## 7. 해커톤 MVP 범위 제한

해커톤 시간 내 구현 목표 (P0만):
- Spring Boot 백엔드 기본 API (회원, 제보, 포인트)
- Gemini Vision API 연동 (판별 기능)
- React 프론트 (홈, 제보 플로우, 포인트 확인)
- 관리자 대시보드 (제보 목록 + 월간 현황)
- MySQL + GCS 연동
