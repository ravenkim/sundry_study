## 2. 이해관계자별 상세 분석

### A. 학생 사용자 (제보자)

| 항목 | 내용 |
|------|------|
| 페르소나 | 캠퍼스 생활 중 빈 강의실을 자주 지나치는 재학생 |
| 주요 동기 | 포인트 → 기프티콘/편의점 교환으로 실질적 이득 |
| 제보 행동 | 빈 강의실 켜진 조명·에어컨 사진 촬영 → 앱 업로드 |
| 우려 사항 | "귀찮다", "내가 뭘 잘못 찍으면 어떡하나" |
| 해소 방안 | AI 자동 판별(틀려도 사용자 탓 없음) + 즉각 포인트 표시 |

**주요 사용 시나리오**
1. 수업 끝나고 강의실 나오다 켜진 조명 발견
2. 앱 켜서 사진 찍기 (10초 이내)
3. AI가 "낭비 확인됨" 판별 → 포인트 즉시 적립
4. 포인트 모아서 기프티콘 교환

---

### B. 건물주 / 건물 관리자

| 항목 | 내용 |
|------|------|
| 페르소나 | 대학 시설팀 담당자, 사립 건물 관리 회사 |
| 주요 동기 | 전기료 절감 → 절약분의 80%를 실제로 돌려받음 |
| 주요 역할 | 건물·강의실 등록, 전열기구 목록 입력, 리포트 확인 |
| 우려 사항 | "학생들이 악의적으로 어뷰징하지 않을까?" |
| 해소 방안 | AI 판별 정확도 + 위치 메타데이터 검증 + 이상 제보 필터링 |

**관리자 대시보드 주요 기능**
- 건물별 제보 현황 실시간 확인
- 월 절약량 및 정산 내역 시각화
- 강의실 수업 시간표 연동 (예약 여부 자동 확인)
- 이상 제보 신고 및 처리

---

### C. 플랫폼 운영자

| 항목 | 내용 |
|------|------|
| 역할 | 서비스 유지·운영, 포인트 정산 관리, AI 모델 운영 |
| 수익 | 건물주 지급액의 10% 수수료 |
| 책임 | 어뷰징 모니터링, AI 오판 이의제기 처리 |

---

## 3. 이해관계자 간 가치 흐름

```
[건물주]
   │ 절약 전기료의 20% 지급
   ▼
[플랫폼]
   ├── 10% (플랫폼 수수료)
   └── 90% → 포인트 풀로 전환
              │
              ▼
          [학생들]
          제보 기여도에 비례하여 포인트 분배
          → 기프티콘 / 리워드 교환
```

**예시 계산**
- 한 달간 절약된 전기료: **10만 원**
- 건물주 → 플랫폼 지급: **2만 원** (20%)
- 플랫폼 수수료: **2,000원** (10%)
- 학생 포인트 풀: **1만 8,000원** (90%)
- 제보 건수 100건 기준: 건당 약 180원 포인트
