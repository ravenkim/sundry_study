# 기능 정의서 (Feature Specification)

---

## 1. 기능 우선순위 분류

| 구분 | 기준 |
|------|------|
| **P0** | 해커톤 데모 필수 — 없으면 시연 불가 |
| **P1** | 완성도를 높이는 핵심 기능 |
| **P2** | 있으면 좋지만 시간 내 미구현 시 허용 |

---

## 2. 학생 사용자 기능

### P0 — 필수

| 기능 ID | 기능명 | 설명 |
|---------|--------|------|
| U-01 | 회원가입 / 로그인 | 이메일 또는 소셜 로그인 (Google) |
| U-02 | 제보 사진 업로드 | 강의실 사진 촬영 또는 갤러리 선택 후 업로드 |
| U-03 | AI 판별 결과 확인 | "낭비 확인됨 / 확인 불가" 결과 표시 + 포인트 즉시 적립 |
| U-04 | 포인트 잔액 확인 | 누적 포인트, 이번 달 획득량 표시 |

### P1 — 핵심

| 기능 ID | 기능명 | 설명 |
|---------|--------|------|
| U-05 | 제보 이력 조회 | 내가 올린 제보 목록 및 처리 상태 확인 |
| U-06 | 포인트 교환 | 포인트 → 기프티콘 선택 및 교환 신청 |
| U-07 | 건물/강의실 선택 | 제보 시 위치 태깅 (건물명·호수 선택) |

### P2 — 선택

| 기능 ID | 기능명 | 설명 |
|---------|--------|------|
| U-08 | 랭킹 / 리더보드 | 이달의 에코 히어로 (제보 순위) |
| U-09 | 탄소 절감 뱃지 | 누적 절감량 달성 시 뱃지 획득 |
| U-10 | 푸시 알림 | 포인트 정산 완료, 교환 처리 결과 알림 |

---

## 3. 관리자 기능

### P0 — 필수

| 기능 ID | 기능명 | 설명 |
|---------|--------|------|
| A-01 | 관리자 로그인 | 별도 관리자 계정 |
| A-02 | 건물 등록 | 건물명, 강의실 수, 전열기구 종류 및 소비전력 입력 |
| A-03 | 제보 목록 확인 | AI 판별 결과 포함 제보 목록, 사진 확인 |
| A-04 | 월 절약량 대시보드 | 이번 달 제보 건수, 추정 절감 전기료 표시 |

### P1 — 핵심

| 기능 ID | 기능명 | 설명 |
|---------|--------|------|
| A-05 | 제보 이의 신청 | 오판 또는 어뷰징 의심 제보에 이의 제기 |
| A-06 | 수업 시간표 등록 | 강의실별 수업 시간 등록 → 사용 중 강의실 자동 필터 |
| A-07 | 정산 내역 확인 | 학생별 포인트 지급 내역, 플랫폼 수수료 내역 |

### P2 — 선택

| 기능 ID | 기능명 | 설명 |
|---------|--------|------|
| A-08 | 월별 트렌드 그래프 | 제보 수·절약량 월별 추이 시각화 |
| A-09 | 강의실 대여 시스템 연동 | 외부 예약 시스템 API 연동 |

---

## 4. AI 기능

| 기능 ID | 기능명 | 설명 | 모델/방법 |
|---------|--------|------|----------|
| AI-01 | 낭비 판별 | 사진에서 조명·에어컨 켜짐 여부 감지 | Gemini Vision API |
| AI-02 | 빈 강의실 확인 | 사람 없는 강의실인지 판별 | 인물 감지 (사람 있으면 제보 반려) |
| AI-03 | 절약량 계산 | 기구 종류·소비전력·꺼짐 시간 기반 kWh 산출 | 규칙 기반 계산 엔진 |
| AI-04 | 어뷰징 탐지 | 동일 위치 반복 제보, 짧은 간격 연속 제보 패턴 감지 | 규칙 기반 필터 |

---

## 5. 기능 흐름도

```
[학생]
  │
  ├─ 앱 실행 → 로그인 (U-01)
  │
  ├─ 사진 촬영/업로드 (U-02)
  │       │
  │       ▼
  │   [AI 판별] (AI-01, AI-02)
  │       │
  │   판별 성공? ──────────────────────► 실패 → "판별 불가" 안내
  │       │ Yes
  │       ▼
  │   포인트 즉시 적립 (U-03)
  │       │
  │       ▼
  │   제보 데이터 저장 → 관리자 대시보드 전달
  │
  └─ 포인트 교환 신청 (U-06)

[관리자]
  │
  ├─ 건물 등록 (A-02)
  │
  ├─ 제보 확인 (A-03) → 이의 신청 (A-05)
  │
  └─ 월 정산 확인 (A-07) → 플랫폼 납부
```
