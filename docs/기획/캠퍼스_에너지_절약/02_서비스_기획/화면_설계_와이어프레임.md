# 화면 설계 / 와이어프레임 (Wireframe)

> 텍스트 기반 레이아웃. 실제 디자인은 `docs/디자인/` 폴더에서 관리.  
> **플랫폼: 모바일 웹 (네이티브 앱 아님)** — 모바일 브라우저(Chrome, Safari) 최적화.  
> 뷰포트 기준: 최대 너비 390px, 하단 고정 탭 네비게이션, touch 이벤트 대응.  
> 카메라 접근: `<input type="file" accept="image/*" capture="environment">` 사용.

---

## 1. 네비게이션 구조

```
첫 접속
  │
  ├─ [로그인 / 회원가입]
  │
  └─ [메인 레이아웃]
       ├─ 상단: 헤더 앱바
       ├─ 중단: 페이지 콘텐츠 (스크롤 영역)
       └─ 하단: 고정 탭 바 (Bottom Navigation)
            ├─ 홈 (제보하기 CTA)
            ├─ 제보 이력
            ├─ 포인트
            └─ 마이페이지
```

## 3. 화면 전환 흐름

```
홈
 ├─ 제보하기 CTA
 │    └─ 카메라 → 위치 선택 → 결과 → 홈
 │
 ├─ 포인트 탭
 │    └─ 교환하기 → 상품 선택 → 확인 → 완료
 │
 └─ 제보 이력
      └─ 제보 상세보기
```
