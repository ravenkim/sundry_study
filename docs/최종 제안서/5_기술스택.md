# 5. 기술 스택

---

## Front-End

| 기술 | 버전/비고 |
|------|----------|
| **React** | 19 |
| **TypeScript** | ~5.7 |
| **Vite** | 6.2 (빌드 도구) |
| **TailwindCSS** | v4 (`@tailwindcss/vite` 플러그인) |
| **Redux Toolkit** | 상태 관리 |
| **redux-saga** | 비동기 사이드 이펙트 |
| **react-router** | v7 (파일 기반 자동 라우팅) |
| **Axios** | API 클라이언트 |
| **shadcn/ui** | Radix UI 기반 컴포넌트 |
| **i18next** | 한국어/영어 다국어 |
| **Pretendard** | 웹폰트 (번들 포함) |

**선택 이유**: 모바일 우선 설계(최대 너비 390px), 하단 탭 네비게이션, `<input capture="environment">` 카메라 접근, 빠른 개발·배포.

---

## Back-End

| 기술 | 버전/비고 |
|------|----------|
| **Spring Boot** | 4.0.6 |
| **Java** | 17 |
| **Gradle** | 빌드 |
| **Spring Data JPA** | Hibernate, MySQL 연동 |
| **Spring Security** | JWT, OAuth2 (카카오) |
| **springdoc-openapi** | Swagger UI |
| **Spring Actuator** | 헬스 체크 |
| **Lombok** | 보일러플레이트 감소 |
| **Apache Kafka** | 포인트 비동기 정산 |

**선택 이유**: 레이어드 아키텍처(Controller → Service → Repository → Entity), `ApiResponse`/`ErrorCode` 규격, 팀 개발 역량.

---

## Database

| 기술 | 버전/비고 |
|------|----------|
| **MySQL** | 8.4 (Docker Compose / 학교 서버) |
| **DDL** | `auto: update` (개발) |

**주요 테이블**: Member, Building, Location, ResourceType, LocationResource, Report, Schedule, PointTransaction

---

## AI

| 기술 | 버전/비고 |
|------|----------|
| **Gemini 2.5 Flash** | Vertex AI (Google DeepMind) |
| **YOLOv8n** | Ultralytics COCO 사전학습 (person/chair/desk) |
| **YOLOv8n Custom** | `ac_best.pt` (Roboflow 파인튜닝, mAP 0.990) |
| **Roboflow** | `office-air-condition` v1 (2,016장) |
| **FastAPI** | AI 서비스 (Python) |
| **Ultralytics** | 객체 탐지 |

**선택 이유**: 해커톤 주제(Google Cloud) 연계, 멀티모달 지원, 5초 이내 판별, Prompt Engineering만으로 ON/OFF 판별.

---

## Infra

| 기술 | 버전/비고 |
|------|----------|
| **GCP Cloud Run** | BE + AI Service + FE (asia-northeast3) |
| **Google Cloud Storage** | 제보 사진 저장 (비공개 버킷) |
| **Docker Compose** | 로컬 통합 (MySQL + BE:8080 + FE:8081) |
| **nginx** | FE 정적 파일 서빙 |
| **학교 서버** | MySQL, Docker 배포 (SSH 터널링) |

**배포 스크립트**: `deploy.sh`, `be/deploy.sh`, `fe/deploy.sh`

---

## Message Queue

| 기술 | 용도 |
|------|------|
| **Apache Kafka** | 포인트 적립 비동기 처리 (`ECO_POINT_TOPIC`, `PointProducer`/`PointConsumer`) |

## 요약 (한눈에 보기)

```
Front-End:  React 19, TypeScript, Vite, TailwindCSS v4, Redux Toolkit, shadcn/ui
Back-End:   Spring Boot 4, Java 17, Spring Data JPA, Spring Security(JWT/OAuth2)
Database:   MySQL 8.4
AI:         Gemini 2.5 Flash (Vertex AI), YOLOv8n, Ultralytics, Roboflow, FastAPI
Infra:      GCP Cloud Run, Google Cloud Storage, Docker Compose, nginx
Message:    Apache Kafka
```
