## Front-End

| 기술 | 버전/비고 |
|------|----------|
| **React** | 19 |
| **TypeScript** | ~5.7 |
| **Vite** | 6.2 (빌드 도구) |
| **TailwindCSS** | v4 (`@tailwindcss/vite` 플러그인) |
| **Redux Toolkit** | 상태 관리 |
| **redux-saga** | 비동기 사이드 이펙트 |
| **react-router** | v7 (파일 기반 자동 라우팅) |
| **Axios** | API 클라이언트 (`VITE_API_HOST` 기반) |
| **shadcn/ui** | Radix UI 기반 컴포넌트 |
| **i18next** | 한국어/영어 다국어 |
| **Pretendard** | 웹폰트 (번들 포함) |
| **Yarn** | 4.9.4 (패키지 매니저) |
| **recharts** | 관리자 통계 차트 |
| **framer-motion** | UI 애니메이션 |

**선택 이유**: 모바일 우선 설계(최대 너비 390px), 하단 탭 5개(홈·제보·이력·포인트샵·마이페이지), `<input capture="environment">` 카메라 접근, 빠른 개발·배포.

**주요 화면 구성**:
- 학생: 홈, 제보 작성·완료, 제보 이력·상세, 포인트샵, 마이페이지
- 인증: 로그인, 회원가입(소속 선택 → 정보 입력), 관리자 가입 문의, Google OAuth 콜백, 계정 찾기
- 관리자: 장소 관리(3단 컬럼 탐색기 + Sheet CRUD), 제보 관리, 포인트·기프티콘 관리, 통계, 사용자 관리

## Back-End

| 기술 | 버전/비고 |
|------|----------|
| **Spring Boot** | 4.0.6 |
| **Java** | 17 |
| **Gradle** | 빌드 |
| **Spring Data JPA** | Hibernate, MySQL 연동 |
| **Spring Security** | OAuth2 Resource Server (JWT), BCrypt, Google OAuth2 |
| **springdoc-openapi** | 3.0.2 — Swagger UI (`/swagger-ui.html`) |
| **Spring Actuator** | 헬스 체크 (`/actuator/health`) |
| **Lombok** | 보일러플레이트 감소 |
| **Flyway** | DB 마이그레이션 (`db/migration/V*.sql`, repeatable seed) |
| **Apache Kafka** | 포인트 비동기 정산 *(코드만, `auto-startup: false`)* |

**선택 이유**: 레이어드 아키텍처(Controller → Service → Repository → Entity), `ApiResponse`/`ErrorCode` 규격, 팀 개발 역량.

**서비스 레이어 구성** (`org.example.be.service`):
- `auth/` — BCrypt 로그인 검증, JWT 발급, 관리자 권한 확인(`AdminAuthorizationHelper`)
- `building/` — 장소 트리 조회
- `location/` — `LocationNode` CRUD, `LocationOperatingSchedule` 관리
- `member/` — 회원가입, 중복 확인, 소속·담당 구역 변경
- `point/` — 포인트 잔액 조회
- `report/` — 제보 생성(Cloud Run `/analyze` 호출), 조회
- `reward/` — 리워드 목록, 포인트 교환, 기프티콘 교환 관리
- `savings/` — 건물별 절약량 집계 API (`BuildingSavingsService`); `SavingsCalculationService`는 제보 플로우 미사용(Phase 2 참고)

## Database

| 기술 | 버전/비고 |
|------|----------|
| **MySQL** | 8.4 (Docker Compose, `energy_db`) |
| **DDL** | `ddl-auto: validate` + **Flyway** 마이그레이션 |

**현재 구현 테이블** (엔티티 기준):

| 엔티티 | 테이블 | 설명 |
|--------|--------|------|
| `Member` | `member_db` | 회원 (email, BCrypt password, phoneNumber, userType, affiliation, locationNode) |
| `Affiliation` | `affiliation_db` | 소속 캠퍼스/기관 (Flyway 시드) |
| `LocationNode` | `location_node_db` | 장소 트리 (GROUP/LEAF, depth, sortOrder, LEAF 자원 수량: acCount·fluorescentCount·ledCount) |
| `LocationOperatingSchedule` | `location_operating_schedule_db` | 장소별 요일 운영 스케줄 (on/off 시간, 휴무 여부) — AI metadata |
| `Report` | `report_db` | 제보 (imageUrl, wasteType, status, locationNode, estimatedKwh, estimatedSavingsKrw, estimatedPoint, pointAwarded) |
| `MemberPoint` | `member_point_db` | 회원 포인트 (가입 시 0P 생성) |
| `Reward` | `reward_db` | 리워드 상품 (name, pointCost, category, tag, imageKey, isActive) |
| `GifticonExchange` | `gifticon_exchange_db` | 기프티콘 교환 내역 (member, reward, pointUsed, status, createdAt, processedAt) |

**시드**: Flyway `R__seed_dev.sql` — 소속(삼육대학교), 4개 루트 GROUP + LEAF 장소, 리워드 상품 샘플, admin/user 더미 계정

**목표 확장 스키마** *(P1)*: ResourceType, LocationResource, PointTransaction, Schedule

## AI

| 기술 | 버전/비고 |
|------|----------|
| **Gemini 2.5 Flash** | Vertex AI (Google DeepMind, `us-central1`) |
| **YOLOv8n** | Ultralytics COCO 사전학습 (person/chair/desk) |
| **YOLOv8n Custom** | `models/ac_best.pt` (Roboflow 파인튜닝, mAP 0.990) |
| **Roboflow** | `office-air-condition` v1 (2,016장) |
| **FastAPI** | AI 서비스 (Python, monorepo `ai/for_deploy/campus_api/` → Cloud Run) |
| **Ultralytics** | 객체 탐지 |
| **OpenCV** | 이미지 크롭·전처리 |

**AI 응답 필드**:

| 필드 | 타입 | 설명 |
|------|------|------|
| `result` | String | `PASS` / `ERROR` / `WASTE_DETECTED` |
| `message` | String | 사용자에게 보여줄 한국어 메시지 |
| `ac_status` | String | `ON` / `OFF` / `UNKNOWN` |
| `light_status` | String | `ON` / `OFF` |
| `reason` | String | Gemini 판단 근거 |
| `expected` | String | 예상 절약 금액 (예: `"494원"`) |
| `expectedKwh` | String | 예상 절약 전기량 (예: `"3.8 kWh"`) |

**에너지 상수** (Gemini 프롬프트 기준):
- 형광등: 32W/개 · LED: 15W/개 · 에어컨: 1,500W/대
- 전기요금: 120원/kWh · 비운영 방치 시간 cap: 60분

> AI 학습·배포 코드는 monorepo `ai/`에 포함. `.pt` 가중치는 Git 미포함 — 배포 시 `for_deploy/campus_api/models/ac_best.pt`에 수동 배치. BE `POST /api/reports`에서 Cloud Run `/analyze` 호출 완료.

**선택 이유**: 해커톤 주제(Google Cloud) 연계, 멀티모달 지원, 5초 이내 판별, Prompt Engineering만으로 ON/OFF + 절약량 판별.
