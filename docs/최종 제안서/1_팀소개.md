# 1. 팀 소개

> **14팀** — 2026 두유톤 해커톤  
> **팀원**: 김해준, 차성호, 이은총  
> AI를 활용한 지속 가능한 환경 및 생활 문제 해결 서비스

---

## 팀원 소개

### 김해준 — 기획 총괄 · 프론트엔드 · UI/UX · 인프라

**역할**
- 서비스 기획 총괄 및 기능 정의서·와이어프레임 작성
- React 프론트엔드 개발 (홈, 제보 플로우, 관리자 UI)
- 발표 자료(PPT) 제작
- Docker 배포 및 학교 서버 인프라 구축

**강점 · 성격**
- 공공 데이터(통계청 API, 법령 레포 등)를 적극 활용하는 방향성을 제시하며, 서비스의 사회적 가치와 실현 가능성을 동시에 고려합니다.
- 아이디어 선정 전부터 비영리/영리 방향성, 타겟 사용자 등 **전략적 프레임**을 먼저 확정하려는 체계적 사고를 보입니다.
- AI 활용 구체 방법을 대시보드 형태로 정리하고, 일정 초안을 작성해 팀 전체의 개발 리듬을 맞춥니다.
- DB 접속 정보 Git 노출 등 **보안 이슈를 선제적으로 발견**하고 `.env.example` 방식으로 전환을 주도했습니다.
- CORS·배포 편의성을 고려한 인프라 의사결정(Docker, 동일 서버 배포)에 적극적으로 참여합니다.

---

### 차성호 — 백엔드 개발

**역할**
- Spring Boot REST API 설계 및 구현
- 회원·제보·포인트·관리자 API 개발
- DB 스키마 및 JPA 엔티티 구현

**강점 · 성격**
- 기술 스택(React + Spring Boot + MySQL + Gemini)에 대한 **합의를 빠르게 도출**하고, 세부 구현에 집중하는 실용적 개발자입니다.
- 수업 시간표 데이터 연동, 강의실 대예 시스템 연결 등 **서비스 확장성**을 고려한 기능 아이디어를 제안합니다.
- FE 디자인을 참고하며 BE 틀 기반으로 API를 구현하고, DBeaver로 MySQL 접속·스키마 검증까지 직접 수행합니다.
- `master_be` 브랜치 기반으로 안정적인 백엔드 코드를 작성하며, Kafka 등 신규 기술 도입 시 충돌 해결에도 유연하게 대응합니다.

---

### 이은총 — AI · 백엔드 · 인프라

**역할**
- AI 모델 학습·배포 (YOLOv8n, Gemini Vision)
- FastAPI AI 서비스 Cloud Run 배포
- MySQL 서버 구축, Kafka 포인트 비동기 처리
- 학교 IT팀 포트 개방 등 인프라 협조

**강점 · 성격**
- **수상 확률을 높이려면 사회적 약자·환경에 실질적 도움이 되는 서비스**가 필요하다는 관점으로, 아이디어의 참신함과 사회적 가치를 동시에 추구합니다.
- GPU 할당 거절 등 **기술적 애로를 극복**하며 YOLOv8n Custom 모델(`ac_best.pt`, mAP 0.990)을 직접 학습·배포했습니다.
- Roboflow 데이터셋 확보, Google Cloud 크레딧 조사, AI 코드 작성까지 **AI 파이프라인 전체**를 담당합니다.
- 학교 서버 MySQL 설치, Docker 배포, Kafka 작동 확인 등 **인프라 구축**을 주도하며, 완성 우선의 실용적 배포 전략을 제시합니다.
- 후원사 크레딧 수령 등 해커톤 운영 사항도 꼼꼼히 챙기는 **팀 운영형 개발자**입니다.

## 팀의 강점

1. **기획-개발 일체형**: 기획·문서(김해준) → FE(김해준) → BE·AI(차성호·이은총)까지 3인이 전 과정 커버
2. **AI + 백엔드 시너지**: 이은총의 AI 파이프라인과 차성호의 Spring Boot API가 긴밀히 연동
3. **빠른 의사결정**: 카카오톡·디스코드 기반 실시간 소통으로 일정·역할 분담을 신속히 확정
4. **실용주의**: 해커톤 기간 내 데모 가능한 P0 기능에 집중, P1/P2는 로드맵으로 분리
