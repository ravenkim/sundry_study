# 에코리포트 (EcoReport)
## 크라우드소싱 기반 AI 캠퍼스 에너지 절약 플랫폼

> 2026 두유톤 해커톤 | 14팀

---

## 1. 팀 소개

에코리포트를 개발한 **14팀**은 기획, 프론트엔드, 백엔드, AI 엔진 개발 전문가 3인으로 구성되어 있으며, 실제 캠퍼스 현장의 에너지 낭비 문제를 기술로 해결하는 데 역량을 집중했습니다.

**김해준 (기획 총괄 / FE / 인프라)**
공공 데이터를 활용한 전략적 서비스 방향성 수립, React 19 기반 15개 이상 화면 개발, Docker Compose 배포 및 학교 서버 인프라 구축을 담당했습니다. 아이디어 기획 단계부터 비영리/영리 방향성과 타겟 사용자를 명확히 정의하고, DB 접속 정보 Git 노출 방지 등 보안 이슈를 선제적으로 대응했습니다.

**차성호 (백엔드 개발)**
Spring Boot REST API 설계·구현, 회원·제보·장소·리워드·기프티콘·절약량 전 API를 담당했습니다. DB 스키마 및 JPA 엔티티 구현(Member, Affiliation, LocationNode, Report, MemberPoint, Reward, GifticonExchange)과 수업 시간표 연동 등 서비스 확장성을 고려한 구조를 설계했습니다.

**이은총 (AI / 인프라)**
YOLOv8n Custom 모델 학습(mAP 0.990)·배포, FastAPI AI 서비스 Cloud Run 배포, BE `/api/reports` 연동을 담당했습니다. GPU 할당 거절 등 하드웨어 제약을 극복하고 Roboflow 데이터셋 2,016장으로 파인튜닝하여 고정밀 에어컨 탐지 모델을 완성했습니다.

**팀의 강점**: 기획·FE·BE·AI 전 과정을 3인이 커버하는 일체형 구조, AI 파이프라인과 Spring Boot API의 긴밀한 연동, 해커톤 기간 내 데모 가능한 핵심 기능에 집중하는 실용주의적 개발 방식.

## 2. 문제 정의

대학 캠퍼스는 수백 개의 강의실·복도·화장실로 구성되어 있으며, 수업 종료 후에도 조명과 냉난방기가 가동되는 **'보이지 않는 낭비'**가 만연합니다.

교내 전체 에너지 비용의 약 **30%**가 빈 강의실 등에서 낭비되는 것으로 추정됩니다. 100개 강의실 기준으로 하루 20% 공간에서 2시간씩 기기가 방치될 경우 **월 800 kWh(전기료 약 10만 원 이상)**의 불필요한 비용이 발생하며, 연간으로 환산하면 **수천만 원** 규모에 달합니다.

| 기존 방안 | 한계 |
|----------|------|
| 스마트빌딩 IoT | 수억 원 초기 투자, 노후 건물 적용 불가 |
| 관리인 순찰 | 인건비 발생, 야간·주말 공백 |
| 캠페인·안내 방송 | 인센티브 없어 지속 참여 유도 어려움 |

**핵심 가설**: 강의실에서 낭비를 가장 먼저 발견하는 사람은 **학생**입니다. 합리적인 보상(포인트·기프티콘)이 주어진다면, 학생은 에너지 낭비를 자발적으로 제보할 것입니다.

## 3. 서비스 해결책

에코리포트는 **"사진 한 장으로 시작하는 캠퍼스 탄소중립"**을 지향합니다.

**서비스 핵심 프로세스**
1. **제보**: 학생이 빈 강의실의 낭비 사진을 촬영하여 업로드
2. **분석**: 3단계 AI 파이프라인이 5초 이내에 낭비 여부를 정밀 분석
3. **보상**: 낭비 확인 시 절약 금액·포인트 즉시 확인, 기프티콘 교환

기존 건물 인프라를 전혀 수정하지 않고, 학생의 **스마트폰 카메라만**으로 운영 가능합니다. IoT 센서·스마트 조명 교체 등 수억 원 규모의 설비 투자 없이 소프트웨어와 AI만으로 캠퍼스 에너지 낭비를 줄입니다.

## 4. 핵심 기술: 3단계 AI 파이프라인

| 단계 | 모델 | 역할 |
|------|------|------|
| 1단계 | YOLOv8n (COCO 사전학습) | 사람·가구 탐지 → 빈 강의실 여부 판별 |
| 2단계 | YOLOv8n Custom (`ac_best.pt`, mAP 0.990) | 천장형 에어컨 탐지·크롭 |
| 3단계 | Gemini 2.5 Flash (Vertex AI) | 조명·에어컨 ON/OFF 판별 + 절약 금액·전기량 산출 |

Gemini는 장소별 **운영 스케줄** 데이터를 종합하여 `ac_status`, `light_status`, `expected`(원), `expectedKwh`를 JSON으로 반환합니다. BE는 이를 파싱해 `estimatedSavingsKrw`·`estimatedKwh`·`estimatedPoint`를 저장하고 포인트를 즉시 적립합니다.

**기술 스택 요약**

| 분류 | 스택 |
|------|------|
| Front-End | React 19, TypeScript, Vite, TailwindCSS v4, Redux Toolkit + redux-saga |
| Back-End | Spring Boot 4.0.6, Java 17, Spring Security (JWT/OAuth2), Flyway |
| AI / ML | FastAPI, YOLOv8n Custom (mAP 0.990), Gemini 2.5 Flash, OpenCV |
| Infrastructure | Ubuntu 24.04.3 (ubuntu03), Docker Compose, MySQL 8.4, GCP Cloud Run |

**하이브리드 배포 구조**: 메인 API·DB는 학교 서버(ubuntu03)에서 운영하고, 고성능 연산이 필요한 AI 서비스는 GCP Cloud Run(`us-central1`)에 배치하여 비용 최적화와 탄력적 확장성을 확보했습니다.

## 5. 구현 성과

**완성된 핵심 기능**

| 영역 | 구현 내용 |
|------|-----------|
| 인증 | 이메일 + Google OAuth2, JWT 기반 권한 관리 |
| 제보 파이프라인 | 사진 업로드 → Cloud Run AI 판별 → 포인트 즉시 적립 |
| 장소 관리 | 3단 계층 구조 CRUD (관리자 FE + BE 실연동) |
| 포인트·리워드 | 잔액 조회, 기프티콘 교환 신청·이력, 관리자 교환 승인 |
| 절약량 집계 | 건물별 `totalKwh`, `thisMonthKwh`, `reportCount` |
| 관리자 대시보드 | 제보 목록, 월간 절감 현황, 기프티콘 관리 |
| 운영 배포 | Docker Compose (FE:8081, BE:8080, MySQL) — ubuntu03 24시간 운영 |

**화면 구성**: 학생용(홈·제보·이력·포인트샵·마이페이지) + 관리자용(장소 관리·제보·기프티콘·통계·사용자) 총 15개 이상의 화면을 React로 완성했습니다.

**품질 검증**: IntelliJ, WebStorm, VS Code를 활용한 IDE 교차 검증으로 코드 품질을 높이고, Docker Compose 기반 Ubuntu 24.04.3 환경에서 안정적인 운영을 확인했습니다.

## 6. 지속 가능성 및 확장 가능성

**환경적 임팩트** (1개 캠퍼스, 100개 강의실 기준)
- 월 절약 전기: 약 **600~1,000 kWh**
- 월 탄소 절감: 약 **280~470 kg CO₂**
- 연간 효과: 소나무 **50~80그루** 흡수량과 동등

**경제적 타당성**
- 대학: 추가 설비 투자 없이 전기료 **10~30% 절감**
- 플랫폼: 약 **32개 건물** 가입 시 손익분기점(BEP) 달성, 이후 선형 수익 증가
- 학생: 제보 포인트 → 기프티콘 교환

**정책적 정합성**: 교육부 그린스마트 미래학교 사업의 에너지 효율화 기조와 정확히 부합하며, B2G 시장 진출 가능성이 높습니다.

**확장 로드맵**

| 단계 | 기간 | 목표 |
|------|------|------|
| 파일럿 | 1개월 | 제보 500건, 학생 100명, 건물 1~3개 |
| 초기 성장 | 3개월 | 건물 10개, 월 절약 5,000 kWh |
| 확산 | 6개월 | 대학 5개교, MAU 1,000명 |
| 확장 | 1년 | 대학 20개교, 공공기관 진출 |

## 7. 결론

> **"사진 한 장이 캠퍼스를 바꿉니다."**

에코리포트는 학생 주도형 참여를 통해 일상의 낭비를 가치 있는 리워드로 전환하는 **탄소중립 문화의 정착**을 지향합니다.

- **문제**: 대학 전기료의 30%가 빈 강의실에서 낭비됩니다.
- **해결**: 학생이 사진 찍으면 AI가 분석하고 포인트가 즉시 적립됩니다.
- **임팩트**: 한 캠퍼스에서 월 수백 kWh 절약, 소나무 50그루 효과.
- **확장성**: IoT 설비 없이 대한민국 모든 대학에 즉시 도입 가능.
- **비즈니스**: 건물주가 절약한 전기료의 일부를 학생에게 기프티콘으로 돌려주는 선순환 구조.

AI 기술로 절감 가치를 정밀하게 수치화하고 이를 커뮤니티의 혜택으로 환원하는 선순환 모델을 통해, 에코리포트는 사회적 가치 실현과 기술적 혁신이 결합된 실천적 솔루션으로서 더 스마트하고 지속 가능한 캠퍼스의 미래를 열어갑니다.
