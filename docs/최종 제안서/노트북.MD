해커톤 제안서 에코리포트(EcoReport): 크라우드소싱 기반 AI 캠퍼스 에너지 절약 플랫폼
1. 팀 소개: 융합형 역량 기반의 최적화된 조직 구성
에코리포트를 개발한  14팀 은 기술적 완성도와 비즈니스 가치를 동시에 실현하기 위해 기획, 프론트엔드, 백엔드, AI 엔진 개발 전문가들이 전략적으로 결집한 조직입니다. 우리는 단순한 기능 구현을 넘어, 실제 캠퍼스 현장의 페인 포인트(Pain Point)를 해결하고 즉각적인 도입이 가능한 '실전형 서비스'를 구축하는 데 역량을 집중했습니다.
팀원별 역할 및 핵심 역량 상술
김해준 (기획 총괄 / FE / 인프라)
전략적 프레임 구축:  공공 데이터와 법령 레포트를 분석하여 서비스의 사회적 가치를 정의하고, 비영리/영리 방향성을 아우르는 비즈니스 모델을 수립했습니다.
보안 이슈 선제 대응:  Git 내 DB 접속 정보 노출 위험을 사전에 발견하여 .env.example 체계로의 전환을 주도하는 등 시스템 보안 무결성을 확보했습니다.
UI/UX 최적화:  React 19 기반으로 15개 이상의 화면을 개발하며, 사용자 동선을 고려한 직관적인 제보 플로우를 구현했습니다.
차성호 (백엔드 개발)
실용적 개발 합의 도출:  Spring Boot와 MySQL 기반의 REST API 스택에 대한 빠른 합의를 이끌어내고, 수업 시간표 및 강의실 예약 시스템 연동을 고려한 확장형 DB 스키마를 설계했습니다.
안정적 아키텍처 구현:  브랜치 전략을 통한 코드 관리와 Kafka 등 신규 기술 도입 시의 충돌 해결을 통해 백엔드 환경의 안정성을 극대화했습니다.
이은총 (AI / 인프라)
고성능 AI 모델 학습:  GPU 할당 한계 등 하드웨어 제약을 극복하고, 파인튜닝을 통해  mAP 0.990 이라는 탁월한 정확도의 YOLOv8n Custom 모델을 완성했습니다.
인프라 구축 주도:  학교 서버(ubuntu03) 포트 개방 협조부터 Docker 기반 배포, FastAPI 서비스의 Cloud Run 배치까지 전체 인프라 파이프라인을 설계했습니다.
협업 체계의 강점
기획-개발 일체형 구조:  기획 단계부터 FE/BE/AI 개발자가 밀접하게 소통하여 문서화된 아이디어가 즉시 코드로 치환되는 고성능 개발 리듬을 확보했습니다.
AI+백엔드 시너지:  독자적인 AI 파이프라인이 Spring Boot API와 유기적으로 연동되어, 제보 즉시 분석 결과가 도출되는 고성능 시스템을 구축했습니다.
실용주의적 로드맵 분리:  해커톤 기간 내 구현 가능한 핵심 기능(P0)과 향후 고도화할 확장 기능(P1/P2)을 명확히 정의하여 프로젝트의 완결성을 높였습니다.
2. 문제 정의: 캠퍼스 내 방치되는 에너지 낭비의 심각성
현재 대학 캠퍼스는 수백 개의 공간에서 수업 종료 후에도 조명과 냉난방기가 가동되는 '보이지 않는 낭비'가 만연한 상태입니다. 이는 단순한 부주의를 넘어 막대한 재정적 손실과 환경 파괴로 이어지고 있습니다.
에너지 낭비 데이터 분석
경제적 손실 규모:  교내 전체 에너지 비용의 약 **30%**가 빈 강의실 등에서 발생하는 것으로 추정됩니다.
구체적 손실 수치:  100개 강의실 기준, 하루 20% 공간에서 2시간씩 기기가 방치될 경우 **월 800kWh(전기료 약 10만 원 이상)**의 불필요한 비용이 발생합니다.
시각적 강조:  전국 단위 대학으로 환산 시 연간  수억 원 규모 의 예산이 허공으로 사라지고 있습니다.
기존 해결책의 한계 및 '학생' 중심의 가설 설정
구분,스마트빌딩 IoT,관리인 순찰,캠페인 및 안내,에코리포트(EcoReport)
비용,수억 원의 초기 투자,높은 인건비 지속,저비용(일시적),최저비용(Software-First)
대응성,노후 건물 적용 불가,야간·주말 공백 발생,인지-행동 전환율 낮음,실시간 크라우드소싱 대응
보상,없음,고정 급여,없음,참여 기반 리워드
핵심 가설: "에너지 낭비의 골든 타임을 잡을 수 있는 유일한 존재는 학생이다."  강의실 수업이 종료되는 순간, 동선상 낭비를 가장 먼저 발견할 수 있는 사람은 해당 수업을 들은 '학생'뿐입니다. 이들이 마지막 소등을 책임지는 '제보자'가 되도록 실질적인 보상(포인트)을 결합한다면, 인프라 투자 없이도 자발적인 탄소중립 문화를 정착시킬 수 있습니다.
3. 서비스 개요 및 해결 방안: 크라우드소싱과 AI의 결합
에코리포트는 **"사진 한 장으로 시작하는 캠퍼스 탄소중립"**을 지향합니다. 고가의 하드웨어 설치 없이 학생의 스마트폰과 AI 기술을 결합하여 에너지 낭비를 해결하는 선순환 구조를 제안합니다.
서비스 핵심 프로세스
제보:  학생이 빈 강의실의 조명/에어컨 상태를 사진 촬영하여 업로드합니다.
분석:  3단계 AI 파이프라인이 5초 이내에 낭비 여부를 정밀 분석합니다.
보상:  검증된 제보에 대해 즉시 포인트가 적립되며, 학생은 이를 기프티콘으로 교환합니다.
'소프트웨어 우선(Software-First)' 접근법의 이점
에코리포트는 기존 건물 인프라를 전혀 수정하지 않습니다. 스마트폰 카메라를 센서로, AI를 관리자로 대체함으로써 수억 원의 설비 투자 없이 즉시 도입 가능한 혁신적인 비용 효율성을 자랑합니다.
어뷰징 방지 및 신뢰도 확보 전략
24시간 중복 제보 제한:  동일 장소 및 동일 사용자에 대해 24시간 내 중복 제보를 차단하여 무분별한 포인트 획득을 방지합니다.
운영 스케줄 데이터 연동:  장소별 운영 시간 데이터를 참조하여, 실제 수업 중인 강의실에 대한 제보는 AI 분석 단계에서 자동으로 필터링합니다.
다층 신뢰도 검증:  AI 분석 신뢰도가 낮은 경우 관리자 수동 검토 단계로 분류하여 지급 프로세스의 무결성을 유지합니다.
4. 핵심 기술 구현: 3단계 AI 파이프라인 및 시스템 아키텍처
데이터의 무결성을 검증하고 실질적인 절감 가치를 산출하기 위해, 고도화된 AI 분석 전략을 구축했습니다.
3단계 AI 분석 상세 (Active Pipeline)
YOLOv8n (사용 여부 판별):  사람과 가구를 감지하여 강의실이 실제로 비어 있는 상태인지 최우선으로 검증합니다.
YOLOv8n Custom (에어컨 정밀 탐지):  파인튜닝된 모델( mAP 0.990 )을 통해 천장형 에어컨 위치를 탐지하고 영역을 크롭하여 분석 효율을 극대화합니다.
Gemini 2.5 Flash (최종 판별 및 데이터 산출):  운영 스케줄 데이터를 종합하여 최종 ON/OFF 상태를 판정합니다. 이 과정에서 **expected (예상 절약 금액)**와  expectedKwh  (절약 전기량)  필드를 포함한 정밀한 분석 결과를 JSON 포맷으로 반환합니다.
기술 스택 및 인프라 구성
분류,상세 기술 스택
Front-End,"React 19, TypeScript, Vite, TailwindCSS v4, Redux-Saga"
Back-End,"Spring Boot 4.0.6 , Java 17, JPA, Spring Security (JWT), Flyway"
AI / ML,"FastAPI, YOLOv8n (Custom), Gemini 2.5 Flash, OpenCV"
Infrastructure,"Ubuntu 24.04.3 LTS (ubuntu03) , Docker, MySQL 8.4, GCP Cloud Run"
하이브리드 배포 구조의 효율성:  24시간 가용성이 필요한 메인 API와 DB는 학교 서버(ubuntu03)에서 운영하고, 고성능 연산이 필요한 AI 서비스는 GCP Cloud Run에 배치함으로써 인프라 비용 최적화와 탄력적인 확장성을 동시에 확보했습니다.
5. 지속 가능성 및 확장 가능성: 환경적·경제적 임팩트
기대 효과 정량 분석 (1개 캠퍼스 기준)
환경적 임팩트:  월 약  280~470kg의 CO₂  절감이 가능하며, 이는 연간  소나무 50~80그루 를 식재하는 것과 동일한 탄소 흡수 효과를 가집니다.
경제적 타당성:  대학은 추가 설비 투자 없이 전기료를  10~30% 절감 할 수 있습니다. 플랫폼 비즈니스 측면에서는 약 **32개 건물 가입 시 손익분기점(BEP)**을 달성하며, 이후 선형적인 수익 증대가 가능한 모델입니다.
정책적 정합성:  본 서비스는  '교육부 그린스마트 미래학교(Green Smart Future School)'  사업의 에너지 효율화 기조와 정확히 부합하며, 향후 정부 주도의 B2G 시장 진출 가능성이 매우 높습니다.
확장 로드맵 및 SWOT 분석
S(강점):  무설비 도입 가능성, 고정밀 AI 자동 검증.
O(기회):  국가 탄소중립 정책 강화, 에너지 비용 급등에 따른 수요 증가.
Roadmap:  캠퍼스 파일럿(1개월) → 전국 대학 확산(6개월) → 공공기관 및 대형 오피스 진출(1년).
6. 구현 상세 및 MVP 범위: 해커톤 성과 보고
본 팀은 제한된 시간 내에 핵심 가설을 완벽히 검증하기 위해 실연동이 완료된 MVP 개발에 집중했습니다.
구현 완료 기능 및 성과 (Backend Integrated)
인증 시스템:  이메일 및  Google OAuth2 를 통한 안정적인 소셜 로그인 및 JWT 기반 권한 관리 체계 구축.
장소 관리 (LocationNode CRUD):  관리자가 3단 계층 구조의 장소 트리를 생성, 수정, 삭제할 수 있는 관리 기능을 백엔드와 실연동하여 구현 완료.
포인트 및 리워드 시스템:  제보 결과에 따른 포인트 조회 및 기프티콘 교환 신청(POST /api/points/exchange) 프로세스 백엔드 연동 완료.
제보 파이프라인:  실제 사진 업로드 시 Cloud Run AI 서비스와 통신하여 실시간 분석 결과를 반환하는 End-to-End 흐름 완성.
화면 구현 및 개발 신뢰성
15개 이상의 실물 화면:  학생용(제보, 상점, 이력 등)과 관리자용(장소 관리 등) 화면을 React 기반으로 완성했습니다. 단, 관리자용 제보 목록 및 월간 대시보드 통계는 현재  UX Mock 으로 구현되어 향후 고도화 예정입니다.
품질 검증:  IntelliJ, WebStorm, VS Code를 활용한  IDE 교차 검증 을 통해 코드 품질을 높였으며, Docker Compose를 이용해  Ubuntu 24.04.3 LTS  환경에서 안정적인 운영을 확인했습니다.
7. 결론: "사진 한 장이 바꾸는 캠퍼스의 미래"
에코리포트가 제안하는 가치는 명확합니다. **"학생 주도형 참여를 통해 일상의 낭비를 가치 있는 리워드로 전환하는 탄소중립 문화의 정착"**입니다.우리는 단순히 전등을 끄는 행위를 넘어, AI 기술로 절감 가치를 정밀하게 수치화하고 이를 커뮤니티의 혜택으로 환원하는 선순환 모델을 증명했습니다. 에코리포트는 사회적 가치 실현과 기술적 혁신이 결합된 가장 실천적인 솔루션으로서, 더 스마트하고 지속 가능한 캠퍼스의 미래를 열어갈 준비가 되어 있습니다.
