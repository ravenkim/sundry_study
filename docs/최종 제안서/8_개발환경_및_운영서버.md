# 8. 개발 환경 및 운영 서버

> 에코리포트 개발에 사용한 IDE·AI·디자인 도구와 실제 운영 중인 서버 사양

---

## 1. 개발 IDE (교차 검증)

본 프로젝트는 단일 IDE에 의존하지 않고, 여러 개발 환경을 **번갈아 가며 교차 검증**하는 방식으로 진행했다.  
동일 코드베이스를 서로 다른 에디터·IDE에서 열어 빌드·실행·리팩터링 결과를 비교함으로써 환경 종속 이슈와 숨은 오류를 조기에 발견했다.

| 도구 | 용도 |
|------|------|
| **Antigravity** | AI 기반 개발 보조, 코드 생성·리뷰 |
| **Cursor** | AI 페어 프로그래밍, 에이전트 기반 코드 수정 |
| **VS Code** | 범용 경량 에디터, 확장 플러그인 활용 |
| **IntelliJ IDEA** | Spring Boot 백엔드 개발·디버깅 |
| **WebStorm** | React/TypeScript 프론트엔드 개발·디버깅 |

**교차 검증 방식**

- FE: WebStorm / VS Code / Cursor에서 빌드·린트·실행 결과 비교
- BE: IntelliJ / VS Code / Cursor에서 Gradle 빌드·부트 실행·API 테스트 비교
- AI 도구(Antigravity, Cursor)로 생성된 코드는 반드시 다른 IDE에서 한 번 더 열어 컴파일·실행 확인

---

## 2. AI 코딩 도구

코드 작성·리팩터링·디버깅·문서화 과정에서 아래 AI 모델·도구를 **상황에 맞게 병행** 사용했다.

| 도구 / 모델 | 주요 활용 |
|-------------|----------|
| **Composer 2.5** (Cursor) | 멀티파일 편집, 기능 단위 구현, 리팩터링 |
| **Claude** | 아키텍처 설계 검토, 복잡한 로직 설명·코드 리뷰, 문서 작성 |
| **Gemini CLI** | 터미널 기반 빠른 질의, 스크립트·설정 파일 작성 |
| **Gemini** (웹/API) | AI 모델 연동 설계, 프롬프트 초안, 문서 작성 |
| **GPT** | 대안 구현 제안, API 명세·에러 메시지 정리 |

**워크플로우 요약**

```
기능 기획 → Composer/Claude로 초안 구현
         → Gemini CLI/GPT로 대안·엣지 케이스 검토
         → IntelliJ/WebStorm/VS Code에서 빌드·실행 검증
         → Cursor Agent로 수정·통합
```

## 3. 디자인 도구 및 코드 전환

UI/UX 시안은 AI 디자인 도구로 먼저 제작한 뒤, **Google AI Studio**를 통해 React/Tailwind 코드로 변환하여 프로젝트에 반영했다.

| 도구 | 역할 |
|------|------|
| **Stitch** (Google) | 화면 와이어프레임·UI 시안 생성, 프롬프트 기반 디자인 |
| **VinSign** | 시각 디자인·브랜딩 요소 보완 |
| **Google AI Studio** | Stitch/VinSign 시안 → React + Tailwind 코드 변환 |

**디자인 → 코드 파이프라인**

```
Stitch / VinSign (시안·프롬프트)
        ↓
Google AI Studio (코드 생성)
        ↓
fe/src/ (React 19 + TailwindCSS v4 + shadcn/ui로 통합)
        ↓
디자인_가이드.md 토큰(Volt Yellow #FFC107, Eco Green #4CAF50) 적용
```

관련 문서: [디자인 가이드](../디자인/디자인_가이드.md), [Stitch 프롬프트](../디자인/stitch_프롬프트.md)

## 6. Docker 컨테이너 (운영 중)

서버에서 Docker Compose로 FE·BE·MySQL 3컨테이너를 운영한다. Docker MySQL 단일화 적용, AI FastAPI는 GCP Cloud Run에 별도 배포.

| 컨테이너명 | 이미지 | 포트 매핑 | 역할 |
|------------|--------|-----------|------|
| `ecoreport-fe` | `duyuthon-fe` | `0.0.0.0:8081 → 80` | 프론트엔드 (nginx) |
| `ecoreport-be` | `duyuthon-be` | `0.0.0.0:8080 → 8080` | 백엔드 (Spring Boot) |
| `ecoreport-mysql` | `mysql:8.4` | `3306` (내부) | MySQL `energy_db` (healthy) |

### DB (Docker MySQL 단일화)

| 항목 | 값 |
|------|-----|
| DB 이름 | `energy_db` |
| 마이그레이션 | **Flyway** (`db/migration/V*.sql` + `R__seed_dev.sql`) |
| BE 연결 | `jdbc:mysql://mysql:3306/energy_db` |
| DDL 전략 | `ddl-auto: validate` (스키마 변경 시 Flyway 마이그레이션 추가) |
| 데이터 영속 | Docker volume `mysql_data` |
| 호스트 MySQL | 중지·비활성화 — `systemctl disable mysql` |

**현재 DB 테이블**: `member_db`, `affiliation_db`, `location_node_db`, `location_operating_schedule_db`, `report_db`, `member_point_db`, `reward_db`, `gifticon_exchange_db`. `report_db`에는 estimated·point_awarded 컬럼 포함.

상세: [DB_설정_가이드.md](../기획/캠퍼스_에너지_절약/04_기술_기획/DB_설정_가이드.md) §7

### AI FastAPI (GCP Cloud Run)

| 항목 | 값 |
|------|-----|
| 서비스명 | Cloud Run (`us-central1`) |
| 엔드포인트 | `POST /analyze` |
| 모델 파일 | `models/ac_best.pt` (수동 배치, Git 미포함) |
| 연동 | BE `ReportService.callAiApi()` — 제보 생성 시 자동 호출. URL은 Java 상수 하드코딩, `.env` 분리 예정 |

### 접속 URL (원격 서버)

| 서비스 | URL |
|--------|-----|
| 프론트엔드 | `http://<DEPLOY_PUBLIC_HOST>:8081` |
| 백엔드 API | `http://<DEPLOY_PUBLIC_HOST>:8080` |
| Swagger UI | `http://<DEPLOY_PUBLIC_HOST>:8080/swagger-ui.html` |
| 헬스 체크 | `http://<DEPLOY_PUBLIC_HOST>:8080/actuator/health` |

> **운영 범위**: `ubuntu03`에는 FE·BE·MySQL 3컨테이너만 가동. **AI FastAPI는 GCP Cloud Run(`us-central1`)에 별도 배포**되며, 제보 저장 시 BE가 `/analyze`를 호출한다. FE `simulateAiAnalysis()`는 3단계 진행 UI 시연용. Kafka·BE/FE Cloud Run은 미배포.  
> **시연 URL**: 해커톤 시 Cloudflare Tunnel 등 임시 URL 사용 가능.

> MySQL은 Docker **내부 네트워크**(`mysql:3306`)로만 BE에 노출된다.  
> CLI 접속: `docker exec -it ecoreport-mysql mysql -u <MYSQL_USER> -p energy_db`  
> 상세: [DB_설정_가이드.md](../기획/캠퍼스_에너지_절약/04_기술_기획/DB_설정_가이드.md) · [배포 가이드](../기획/캠퍼스_에너지_절약/04_기술_기획/배포_가이드.md)

## 8. 환경 변수 (`.env`)

프로젝트 루트 `.env` 단일 파일로 관리 (`cp .env.example .env`). Git 제외.

| 변수 | 용도 |
|------|------|
| `MYSQL_DATABASE`, `MYSQL_USER`, `MYSQL_PASSWORD` | Docker MySQL 설정 |
| `SPRING_DATASOURCE_URL/USERNAME/PASSWORD` | BE DB 연결 |
| `JWT_SECRET` | JWT HS256 서명 키 |
| `GOOGLE_CLIENT_ID/SECRET` | Google OAuth2 |
| `CAMPUS_AI_API_URL` | Cloud Run `/analyze` 엔드포인트 — 목표. 현재 BE `ReportService` 하드코딩 URL 사용 |
| `VITE_API_HOST` | FE API baseURL (빌드 타임 주입) |
| `DEPLOY_PUBLIC_HOST` | 학교 서버 공개 IP |
