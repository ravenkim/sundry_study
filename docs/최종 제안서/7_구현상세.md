### 아키텍처

- **파일 기반 자동 라우팅**: `src/pages/url/` 하위 `.tsx`가 자동 등록 (`router.tsx`)
- **모바일 우선 UI**: 최대 너비 390px, 하단 탭 5개
- **Redux Toolkit + redux-saga**: `reduxStore.tsx`에 slice·saga 등록
- **Axios 클라이언트**: `src/globals/api/client.tsx`, `VITE_API_HOST`로 API baseURL 설정
- **TailwindCSS v4** + **shadcn/ui** + **Pretendard** 폰트
- **i18next**: 한국어/영어
- **recharts**, **framer-motion**: 관리자 차트·애니메이션

### 인증·제보 플로우

- **이메일 로그인/회원가입**: BE `/login`, `/register` 연동 — JWT `accessToken` + Axios `Bearer`
- **회원가입**: `/signup/affiliation`에서 소속 선택 → `/signup`에서 정보 입력
- **Google OAuth**: Google 로그인 → `/oauth/callback?token=...` → 소속 미설정 시 선택 후 `PATCH /api/me/affiliation`
- **제보 플로우**: 카메라·갤러리 → 건물·강의실(LEAF) 선택 → `POST /api/reports` → BE AI 판별 → 포인트 적립

### 관리자 장소 관리

- **`/admin/buildings`**: 3단 컬럼(1·2·3단계) + Sheet CRUD
- 모듈: `fe/src/features/admin/buildings/` (`LocationExplorer`, `useLocationTree`)
- API: `locationNodesApi.ts` — BE 실연동 전용

## Back-End

### Spring Boot 레이어드 아키텍처

```
Controller → Service(인터페이스+구현체) → Repository → Entity
```

- **응답 규격**: `ApiResponse<T>` (성공 code + body) / `ApiErrorResponse` (실패 code + message) + `ControllerAdvice`
- **Swagger**: `http://localhost:8080/swagger-ui.html`
- **Actuator**: `http://localhost:8080/actuator/health`

### 인증

- **SecurityConfig**: OAuth2 Resource Server JWT + `/login`, `/register` 등 `permitAll`
- **MemberAuthService**: BCrypt + JPA 로그인 검증
- **Google OAuth2**: `application.yaml` OAuth2 설정, FE `/oauth/callback?token=...` 연동
- **JWT**: HS256 발급·검증 — `@AuthenticationPrincipal Jwt` → `memberSeq` claim
- **AdminAuthorizationHelper**: `requireAdmin(memberSeq)` — ADMIN 권한 확인 유틸

### 제보·포인트 처리

- **ReportService**: LocationNode LEAF 조회 → Cloud Run FastAPI `POST /analyze`
  - `ERROR` / `PASS`: `BusinessLogicException(INVALID)` — 저장 거부
  - `WASTE_DETECTED`: `WasteType` 설정, `ExpectedKrwParser`/`ExpectedKwhParser`로 `estimatedSavingsKrw`·`estimatedKwh`·`estimatedPoint` 저장 → `MemberPoint` 즉시 적립
  - AI 통신 실패: `INTERNAL_SERVER_ERROR` (5003)
- **절약량**: `BuildingSavingsService` — 건물별 `totalKwh`, `thisMonthKwh`, `reportCount` 집계

### 포인트·교환·리워드

- **PointService**: `currentBalance`·`totalRedeemed` 조회
- **RewardService.exchange()**: 잔액 확인 → `MemberPoint` 차감 → `GifticonExchange` PENDING 생성
- **RewardService.getActiveRewards()**: `isActive=true`인 `Reward` 목록 반환
- **관리자 교환 관리**: 목록·통계·상태 변경(`COMPLETED`/`CANCELLED`) + `processedAt` 기록

### DB 엔티티

| 엔티티 | 주요 필드 |
|--------|-----------|
| `Member` | userName, BCrypt password, email, phoneNumber, affiliation FK, userType |
| `Affiliation` | name, address — Flyway 시드 |
| `LocationNode` | parent, affiliation, name, nodeKind GROUP/LEAF, depth, sortOrder, acCount·fluorescentCount·ledCount |
| `LocationOperatingSchedule` | locationNode, dayOfWeek 1~7, isClosed, powerOnTime, powerOffTime |
| `Report` | member, locationNode LEAF, wasteType, imageUrl, status, estimatedKwh, estimatedSavingsKrw, estimatedPoint, pointAwarded |
| `MemberPoint` | member, currentBalance |
| `Reward` | name, pointCost, category, tag, imageKey, isActive |
| `GifticonExchange` | member, reward, rewardName, pointUsed, status, createdAt, processedAt |

시드: Flyway `R__seed_dev.sql` — 소속(삼육대학교), GROUP + LEAF 장소, 리워드 샘플, admin/user 더미 계정

## AI

### FastAPI AI Service (Cloud Run — 운영 중)

- **엔드포인트**: `POST /analyze` — Cloud Run us-central1 배포·BE 연동
- **입력**: `image: UploadFile` + `metadata: Form` JSON 문자열
  - metadata: `roomName`, `reportedAt`, `fluorescentCount`, `ledCount`, `acCount`, `operatingSchedules`
- **3단계**: YOLOv8n → YOLOv8n Custom (`ac_best.pt`, mAP 0.990) → Gemini 2.5 Flash
- **에너지 상수**: 형광등 32W, LED 15W, 에어컨 1,500W, 전기요금 120원/kWh, 방치 cap 60분

**monorepo `ai/` 구조**

| 경로 | 내용 |
|------|------|
| `ai/model_train.py`, `ai/model_train_re.ipynb` | YOLOv8n Custom 학습 스크립트 |
| `ai/model_test.py`, `ai/model_test.ipynb` | 추론·파이프라인 테스트 |
| `ai/train_result/` | 학습 결과 (weights/best.pt, mAP/F1 그래프, confusion matrix) |
| `ai/for_deploy/campus_api/` | Cloud Run FastAPI 배포용 (main.py, Dockerfile) |
| `ai/yolov8n.pt` | COCO 사전학습 1단계 모델 |
