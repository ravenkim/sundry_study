### Mock vs Real API

- **`VITE_USE_MOCK`**: 미설정 또는 `true`이면 mock 사용 (기본값 mock)
- **mock AI**: `simulateAiAnalysis()` — 파일명 휴리스틱 + 3~5초 지연으로 AI UX 시뮬레이션
- **`VITE_USE_MOCK=false`** 시 아래 API가 BE 실연동:
  - `GET /api/buildings`, `GET /api/affiliations`
  - `GET /api/points/me`, `POST /api/points/exchange`, `GET /api/points/exchanges/me`
  - `POST /api/reports`, `GET /api/reports/me`
  - `GET /api/savings/buildings/me`
  - `GET /api/rewards`
  - `GET|POST|PATCH|DELETE /api/admin/location-nodes/**` (mock 없음)
  - `GET|PATCH /api/admin/gifticon-exchanges/**`
- **관리자 제보·대시보드·월간통계**: FE mock (`adminApi`) ⏳

- ~~카카오 OAuth~~: 2026-05-24 제외 — Google + 이메일만

## Back-End

### Spring Boot 레이어드 아키텍처

```
Controller → Service(인터페이스+구현체) → Repository → Entity
```

- **응답 규격**: `ApiResponse<T>` (성공 code + body) / `ApiErrorResponse` (실패 code + message) + `ControllerAdvice`
- **Swagger**: `http://localhost:8080/swagger-ui.html`
- **Actuator**: `http://localhost:8080/actuator/health`

### 인증

- **SecurityConfig**: OAuth2 Resource Server JWT + `/login`, `/register` 등 `permitAll`, 그 외 `authenticated`
- **MemberAuthService**: BCrypt + JPA 로그인 검증 ✅
- **Google OAuth2**: `application.yaml`에 `spring.security.oauth2` 설정, FE `/oauth/callback?token=...` 연동 ✅
- **JWT**: HS256 발급·검증 ✅ — `@AuthenticationPrincipal Jwt` → `memberSeq` claim
- **AdminAuthorizationHelper**: `requireAdmin(memberSeq)` — ADMIN 권한 확인 유틸

### 제보

- **ReportService**: JWT 회원·LocationNode(LEAF) 조회 → **Cloud Run FastAPI `POST /analyze`** (URL 현재 `ReportService` 상수 하드코딩, `.env` `CAMPUS_AI_API_URL` 분리 목표)
  - `ERROR` / `PASS`: `BusinessLogicException(INVALID)` — 저장 거부
  - `WASTE_DETECTED`: AI `light_status`/`ac_status`로 `WasteType` 설정, `description`에 AI 메시지 append
  - **`ExpectedKrwParser`/`ExpectedKwhParser`**: AI `expected`/`expectedKwh` → `estimatedSavingsKrw`·`estimatedKwh`·`estimatedPoint` 저장 (`pointAwarded=0`)
  - AI 통신 실패: `INTERNAL_SERVER_ERROR` (5003)
- **절약량**: `BuildingSavingsService` — 담당 건물별 제보에서 `totalKwh`, `thisMonthKwh`, `reportCount` 집계
- **이미지**: GCS 미연동, placeholder URL (`storage.ecoreport.kr/reports/...`)
- **미연동**: `aiResult` JSON API 반환, **제보 시 `MemberPoint` 자동 증가**, Kafka 발행

### 포인트 조회·교환·리워드

- **PointService.getMyPoints()**: `currentBalance`·`totalRedeemed` 실값, `thisMonthEarned=0` 고정 — **제보 적립 미반영**
- **RewardService.exchange()**: 잔액 확인 → `MemberPoint` 차감 → `GifticonExchange(PENDING)` 생성 → `Exchange` DTO 반환 (잔액 포함)
- **RewardService.getActiveRewards()**: `isActive=true`인 `Reward` 목록 반환
- **RewardService.getMyExchanges()**: 본인 교환 이력 (`GifticonExchange`) 반환
- **관리자 교환 관리**:
  - `getAdminExchanges(status)`: 전체 목록, status `null` 시 전체
  - `getAdminExchangeStats()`: 총 교환 건수·포인트 합계
  - `updateExchangeStatus(exchangeId, status)`: `COMPLETED`/`CANCELLED` 등 상태 변경 + `processedAt` 기록

### Kafka (코드만)

- `PointProducer` / `PointConsumer` 존재, 토픽 `member-point-topic`
- `application.yaml`: `spring.kafka.listener.auto-startup: false`
- Docker Compose에 Kafka 없음, Producer 호출 코드 없음

### DB 엔티티 (현재)

| 엔티티 | 주요 필드 |
|--------|-----------|
| `Member` | userName, password(BCrypt), email, **phoneNumber**, **`affiliation`(FK)**, **`locationNode`(FK, GROUP)**, **`userType`** |

## AI

### FastAPI AI Service (Cloud Run — 운영 중)

- **엔드포인트**: `POST /analyze` — **Cloud Run (`us-central1`) 배포·BE 연동 완료**
- **입력**: `image: UploadFile` + `metadata: Form` (JSON 문자열)
  - metadata: `roomName`, `reportedAt`, `fluorescentCount`, `ledCount`, `acCount`, `operatingSchedules`(요일별 `{dayOfWeek, isClosed, powerOnTime, powerOffTime}`)
- **응답 DTO**: `AiAnalysisResponse`

| 필드 | 설명 |
|------|------|
| `result` | `PASS` / `ERROR` / `WASTE_DETECTED` |
| `message` | 한국어 사용자 메시지 |
| `ac_status` | `ON` / `OFF` / `UNKNOWN` |
| `light_status` | `ON` / `OFF` |
| `reason` | Gemini 판단 근거 |
| `expected` | 예상 절약 금액 (예: `"494원"`) |
| `expectedKwh` | 예상 절약 전기량 (예: `"3.8 kWh"`) |

- **3단계**: YOLOv8n → YOLOv8n Custom (`ac_best.pt`, mAP 0.990) → Gemini 2.5 Flash
- **에너지 상수**: 형광등 32W, LED 15W, 에어컨 1,500W, 전기요금 120원/kWh, 방치 cap 60분
- **monorepo `ai/`** (2026-05-23 추가): 학습·추론·배포 소스가 본 저장소에 포함됨

| 경로 | 내용 |
|------|------|
| `ai/model_train.py`, `ai/model_train_re.ipynb` | YOLOv8n Custom 학습 스크립트 |
| `ai/model_test.py`, `ai/model_test.ipynb` | 추론·파이프라인 테스트 |
| `ai/train_result/` | 학습 결과 (`weights/best.pt`, mAP/F1 그래프, confusion matrix) |
| `ai/for_deploy/campus_api/` | Cloud Run FastAPI 배포용 (`main.py`, `models/ac_best.pt`, Dockerfile) |
| `ai/yolov8n.pt` | COCO 사전학습 1단계 모델 |

### MVP 데모: FE Mock

```typescript
// fe/src/globals/api/mock/simulator.ts
simulateAiAnalysis() → WASTE_DETECTED | PASS | ERROR + mock 포인트
```

파일명에 `error`/`pass` 포함 시 결과 분기, 기본은 WASTE_DETECTED. BE 실 AI 판별과 병존 (mock 제거 예정).

## Infra

### Docker Compose (운영 중 — ubuntu03)

```bash
bash deploy.sh    # be/deploy.sh → fe/deploy.sh
```

| 서비스 | 포트 | 컨테이너 |
|--------|------|----------|
| FE (nginx) | 8081 | `ecoreport-fe` |
| BE (Spring Boot) | 8080 | `ecoreport-be` |
| MySQL 8.4 | 3306 (내부) | `ecoreport-mysql` |

**DB 단일화 (2026-05-24)**: Docker MySQL만 사용, 호스트 MySQL 비활성화(`systemctl disable mysql`).
