# 7. 구현 상세

> 각 스택의 **현재 구현 상태**와 **목표 설계**를 구분해 기술한다.

---

## Front-End

### React 19 + Vite + TypeScript

- **파일 기반 자동 라우팅**: `src/pages/url/` 하위 `.tsx`가 자동 등록 (`router.tsx`)
- **모바일 우선 UI**: 최대 너비 390px, 하단 탭 5개 — 홈·낭비 제보·제보 이력·포인트샵·마이페이지
- **Redux Toolkit + redux-saga**: `reduxStore.tsx`에 slice·saga 등록
- **Axios 클라이언트**: `src/globals/api/client.tsx`, `VITE_API_HOST`로 API baseURL 설정

### 화면 라우트 (구현 완료)

| 경로 | 화면 |
|------|------|
| `/`, `/login`, `/signup` | 홈, 로그인, 회원가입 |
| `/report-form`, `/report-success` | 제보 작성·완료 |
| `/reports`, `/reports/:reportId` | 제보 이력·상세 |
| `/shop`, `/profile` | 포인트샵, 마이페이지 |
| `/admin`, `/admin/reports`, `/admin/buildings` (장소 관리), `/admin/points`, `/admin/stats`, `/admin/users` | 관리자 6화면 |

### UI/UX

- **TailwindCSS v4** + **shadcn/ui** + **Pretendard** 폰트
- **i18next**: 한국어/영어
- **recharts**, **framer-motion**: 관리자 차트·애니메이션
- **마스코트 이미지**: `fe/src/assets/mascort/` (AI 결과 피드백용)

### Mock vs Real API

- **`VITE_USE_MOCK`**: 미설정 또는 `true`이면 mock 사용 (기본값 mock)
- **mock AI**: `simulateAiAnalysis()` — 파일명 휴리스틱 + 3~5초 지연으로 AI UX 시뮬레이션
- **mock 포인트·제보·관리자**: `src/globals/api/mock/data.ts` 기반
- **`VITE_USE_MOCK=false`** 시 buildings·affiliations·points·reports·제보 저장·**장소 관리(location-nodes)** BE 연동 가능
- **관리자 제보·대시보드·기프티콘**: FE mock (`adminApi`); **장소 CRUD**는 BE 실연동 (`locationNodesApi`, mock 없음)

### 관리자 장소 관리 (FE)

- **`/admin/buildings`**: UI 명칭 **장소 관리** — 3단 컬럼(1·2·3단계) + Sheet CRUD
- 모듈: `fe/src/features/admin/buildings/` (`LocationExplorer`, `useLocationTree`, `LOC` 용어)
- 관리자 소속: JWT scope 고정 (select 없음)
- 제보 관리: `ReportLocationCell` — 상위 그룹(작게) + 항목명(크게)

### 인증·제보 플로우

- **이메일 로그인/회원가입**: BE `/login`, `/register` 연동 ✅ — JWT `accessToken` + Axios `Bearer`
- **Google OAuth**: BE OAuth2 → FE `/oauth/callback?token=...` ✅
- **카카오 OAuth UI**: 버튼만 존재, BE provider 미등록
- **제보 플로우**: 카메라·갤러리·`GET /api/buildings` → `POST /api/reports` (이미지 필수, BE가 Cloud Run `/analyze` 호출, `WASTE_DETECTED`만 저장) → FE `simulateAiAnalysis` (mock 제거 전까지 중복)

## Back-End

### Spring Boot 레이어드 아키텍처

```
Controller → Service → Repository → Entity
```

- **응답 규격**: `ApiResponse<T>` / `ApiErrorResponse` + `ControllerAdvice`
- **Swagger**: `http://localhost:8080/swagger-ui.html`
- **Actuator**: `http://localhost:8080/actuator/health`

### 현재 API (주요)

| Method | Endpoint | 동작 |
|--------|----------|------|
| GET | `/ping` | 서버 상태 |
| POST | `/login` | BCrypt 검증 + JWT 발급 (`memberSeq` claim) |
| POST | `/register` | 회원 생성 + `MemberPoint` 0P — body에 **`affiliation`(Long, 선택)** 가능, `UserType.USER` 설정 |
| GET | `/register/check-email`, `/register/check-username` | 중복 확인 |
| GET | `/api/affiliations` | 소속 목록 — permitAll |
| GET | `/api/buildings` | 장소 트리 (nested `children`, JWT 시 scope) |
| GET | `/api/admin/location-nodes/tree` | 관리자 장소 트리 — ADMIN |
| POST/PATCH/DELETE | `/api/admin/location-nodes` | 장소 CRUD — ADMIN |
| PATCH | `/api/me/affiliation`, `/api/me/building` | 소속·담당 구역 설정 |
| GET | `/api/points/me` | 잔액 (`currentBalance`; 월/누적은 0) — JWT 필요 |
| POST | `/api/reports` | 제보 저장 — 이미지 필수, FastAPI `/analyze` 호출, `WASTE_DETECTED`만 `PENDING` 저장, `PASS`/`ERROR` 거부 — JWT 필요 |
| GET | `/api/reports/me` | 내 제보 목록 (page, size, status) — JWT 필요 |
| GET | `/api/reports/{reportId}` | 제보 상세 (본인만) — JWT 필요 |

### 인증

- **SecurityConfig**: OAuth2 Resource Server JWT + `/login`, `/register` 등 `permitAll`, 그 외 `authenticated`
- **MemberAuthService**: BCrypt + JPA 로그인 검증 ✅
- **JWT**: HS256 발급·검증 ✅ — 제보·포인트·장소 API에서 `@AuthenticationPrincipal Jwt` → `memberSeq`

### 제보

- **ReportService**: JWT 회원·LocationNode(LEAF) 조회 → **Cloud Run FastAPI `POST /analyze`**
  - `ERROR` / `PASS`: `BusinessLogicException(INVALID)` — 저장 거부
  - `WASTE_DETECTED`: AI `light_status`/`ac_status`로 WasteType 덮어쓰기, description에 AI 메시지 append
  - AI 통신 실패: `INTERNAL_SERVER_ERROR` (5003)
- **조회**: `getMyReports`, `getReportDetail` — 페이지네이션·상태 필터·소유권 검증
- **이미지**: GCS 미연동, placeholder URL (`storage.ecoreport.kr/reports/...`)
- **미연동**: `aiResult` JSON 컬럼 저장·API 반환, 포인트 적립, Kafka 발행

### Kafka (코드만)

- `PointProducer` / `PointConsumer` 존재, 토픽 `member-point-topic`
- `application.yaml`: `spring.kafka.listener.auto-startup: false`
- Docker Compose에 Kafka 없음, Producer 호출 코드 없음

### DB 엔티티 (현재)

| 엔티티 | 설명 |
|--------|------|
| Member | userName, password(BCrypt), email, **`affiliation`(FK)**, **`locationNode`(FK, GROUP)**, **`userType`** |
| Affiliation | name, address — Flyway 시드 (삼육대학교) |
| LocationNode | parent(self), affiliation, name, **nodeKind** (GROUP/LEAF), depth, sortOrder |
| Report | member, **locationNode**(LEAF), locationDetail, wasteType, imageUrl, status |
| MemberPoint | 가입 시 생성, `GET /api/points/me` |

> 시드: Flyway `R__seed_dev.sql` — 4개 루트 GROUP + LEAF 항목, admin/user 더미 계정. 상세: [장소_관리_모델.md](../기획/캠퍼스_에너지_절약/04_기술_기획/장소_관리_모델.md)

## AI

### 목표: FastAPI AI Service (Cloud Run)

- **엔드포인트**: `POST /analyze` — **Cloud Run 배포·BE 연동 완료** (`ReportService.callAiApi`)
- **응답 DTO**: `AiAnalysisResponse` — `result` (`PASS`/`ERROR`/`WASTE_DETECTED`), `message`, `ac_status`, `light_status`, `reason`
- **3단계**: YOLOv8n → YOLOv8n Custom (`ac_best.pt`, mAP 0.990) → Gemini 2.5 Flash
- **monorepo `ai/`** (2026-05-23 추가): 학습·추론·배포 소스가 본 저장소에 포함됨

| 경로 | 내용 |
|------|------|
| `ai/model_train.py`, `ai/model_train_re.ipynb` | YOLOv8n Custom 학습 스크립트 |
| `ai/model_test.py`, `ai/model_test.ipynb` | 추론·파이프라인 테스트 |
| `ai/train_result/` | 학습 결과 (`weights/best.pt`, mAP/F1 그래프, confusion matrix) |
| `ai/for_deploy/campus_api/` | Cloud Run FastAPI 배포용 (`main.py`, `models/ac_best.pt`, Dockerfile) |
| `ai/yolov8n.pt` | COCO 사전학습 1단계 모델 |

> API 키·GCP 프로젝트 ID는 코드에서 placeholder 처리 (`.gitignore`에 `.idea/` 추가).

### MVP 데모: FE Mock

```typescript
// fe/src/globals/api/mock/simulator.ts
simulateAiAnalysis() → WASTE_DETECTED | PASS | ERROR + mock 포인트
```

파일명에 `error`/`pass` 포함 시 결과 분기, 기본은 WASTE_DETECTED.

## Infra

### Docker Compose (운영 중)

```bash
bash deploy.sh    # be/deploy.sh → fe/deploy.sh
```

| 서비스 | 포트 | 컨테이너 |
|--------|------|----------|
| FE (nginx) | 8081 | `ecoreport-fe` |
| BE (Spring Boot) | 8080 | `ecoreport-be` |
| MySQL 8.4 | 3306 (내부) | `ecoreport-mysql` |

**학교 서버 `ubuntu03`** (운영 IP는 `.env`의 `DEPLOY_PUBLIC_HOST` 참고): 위 3컨테이너 24시간 가동. Kafka·Cloud Run 미배포.

### 미구현 배포

- `bash deploy.sh down` / `cloudrun` — 루트 스크립트에 없음
- GCP Cloud Run, GCS 버킷 — 목표 인프라
