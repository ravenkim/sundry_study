## 기능1: AI 이미지 낭비 분석

**설명**

학생이 업로드한 강의실 사진을 **3단계 AI 파이프라인**으로 분석하여, 빈 강의실에서 조명·에어컨이 켜져 있는지 자동 판별하고, **절약 가능한 금액과 전기량**을 즉시 계산합니다.

| 단계 | 모델 | 역할 |
|------|------|------|
| 1단계 | YOLOv8n (COCO 사전학습) | person/chair/desk 탐지 → 강의실 여부·사용 중 여부 판별 |
| 2단계 | YOLOv8n Custom (`ac_best.pt`) | 천장 4-way 에어컨 탐지 (mAP 0.990) |
| 3단계 | Gemini 2.5 Flash (Vertex AI) | 조명·에어컨 ON/OFF 상태 + 절약 금액 JSON 반환 |

**3단계 판별 로직**

- **1단계**: chair=0 AND desk=0 → `ERROR` (강의실 아님) / person≥1 → `PASS` (사용 중) / person=0 → 2단계 진행
- **2단계**: 에어컨 탐지 시 크롭 이미지와 원본을 Gemini에 전달(시나리오 A), 미탐지 시 원본만 전달(시나리오 B)
- **3단계**: `ac_status=ON` 또는 `light_status=ON` → **`WASTE_DETECTED`** (낭비 확인) / 둘 다 `OFF` → `PASS`

**절약량 자동 계산**

Gemini가 `operatingSchedules`(장소별 운영 스케줄)를 참고하여 비운영 시간 기준 낭비 시간을 산출하고, 에너지 상수(형광등 32W, LED 15W, 에어컨 1,500W, 전기요금 120원/kWh)를 적용해 절약 금액(예: `"494원"`)과 전기량(예: `"3.8 kWh"`)을 반환합니다.

- 판별 소요 시간: **5초 이내**
- Gemini API 비용: 건당 약 **0.01달러 이하**

## 기능2: 제보·절약량 처리

**설명**

학생이 사진을 촬영·업로드하면, AI 판별 결과에 따라 제보가 저장되고 절약량이 집계됩니다.

- **제보 업로드**: 강의실 사진 촬영 또는 갤러리 선택, 건물·강의실 위치 태깅 (`LocationNode` LEAF 선택)
- **이미지 저장**: Google Cloud Storage(GCS) 비공개 버킷 ⏳ (현재 placeholder URL)
- **estimated 저장** (✅): AI `expected`/`expectedKwh` → `estimatedSavingsKrw`·`estimatedKwh`·`estimatedPoint` DB 저장 (`pointAwarded=0`)
- **절약량 집계**: `GET /api/savings/buildings/me` — 건물별 `totalKwh`, `thisMonthKwh`, `reportCount` 반환
- **AI 메타데이터**: 제보 시 `operatingSchedules`·LEAF 자원 수량 포함 → Gemini가 운영시간 외 낭비·절약량 계산
- **비동기 처리**: Apache Kafka 포인트 정산 Producer/Consumer (`member-point-topic`) ⏳ 코드만

예: 303호 형광등 10개(32W) + 에어컨 1대(1,500W), 비운영 시간 1시간 방치 → **`"216원"`** 예상 절약 (`estimatedPoint` 저장, 잔액 적립 ⏳).

## 기능3: 포인트 교환·리워드

**설명**

적립·교환된 포인트를 **기프티콘·리워드**로 교환하고, 게이미피케이션으로 지속 참여를 유도합니다.

> **MVP 구분**: 제보 시 `MemberPoint` 잔액 자동 증가는 ⏳. **교환 API**는 잔액 차감·`GifticonExchange` 생성 ✅.

### 리워드 목록 (`GET /api/rewards`)

| 필드 | 설명 |
|------|------|
| `name` | 리워드 상품명 (예: 스타벅스 아메리카노) |
| `pointCost` | 교환에 필요한 포인트 |
| `category` | 카테고리 (예: COFFEE, CONVENIENCE) |
| `tag` | 태그 (예: 인기, NEW) |
| `imageKey` | 상품 이미지 키 |

### 포인트 교환 (`POST /api/points/exchange`)

- 리워드 선택 → 포인트 차감 → `GifticonExchange` 생성 (`PENDING` 상태)
- 교환 후 잔액 및 처리 상태 즉시 반환
- 관리자가 기프티콘 발급 후 `COMPLETED`로 상태 변경

### 교환 이력 (`GET /api/points/exchanges/me`)

- 내가 신청한 교환 목록 + 상태(PENDING/COMPLETED/CANCELLED) 조회

### 관리자 기프티콘 관리 (`/api/admin/gifticon-exchanges`)

- 전체 교환 신청 목록·필터(상태별) 조회
- 교환 통계 (건수·포인트 총합) 조회
- 개별 교환 상태 변경 (`PATCH /{exchangeId}`)

## 기능4: 관리자 대시보드

**설명**

건물 관리자·건물주는 **웹 대시보드**에서 다음을 확인합니다.

- **장소 관리** (✅): 1·2·3단계 그룹/항목 CRUD — FE+BE 실연동
- **운영 스케줄** (✅): 장소별 요일·시간대 on/off 설정 (`LocationOperatingSchedule`)
- **절약량 현황** (✅): `GET /api/savings/buildings/me` — 건물별 kWh·제보 건수 집계
- **기프티콘 교환 관리** (✅): 교환 신청 목록·통계·상태 변경
- **제보 목록** (⏳ mock): AI 판별 결과, 사진, 처리 상태
- **월간 절감 대시보드** (⏳ mock): 월간 제보 건수, 추정 절감 전기료, 탄소 절감량
- **어뷰징 의심 제보** 이의 신청 및 포인트 회수

## 기능5: 어뷰징 방지

**설명**

조명을 일부러 켜고 사진을 찍는 등 **악의적 제보**를 규칙 기반 필터로 차단합니다.

| 규칙 | 임계값 | 처리 |
|------|-------|------|
| 동일 강의실 중복 제보 | 1시간 내 같은 room_id | 두 번째부터 자동 반려 |
| 단기간 과다 제보 | 1일 20건 초과 | 계정 경고 + 제보 잠금 |
| 야간 시간대 제보 | 자정~06시 | 자동 보류 → 관리자 수동 검토 |
| 동일 IP 다중 계정 | 같은 IP 5계정 이상 | 신규 제보 차단 |

관리자는 **제보 이의 신청**을 통해 오판·어뷰징 의심 건에 대해 포인트 회수 가능.

## 기능6: 회원 인증·소속 관리

**설명**

학생 및 관리자 계정 관리와 소속 캠퍼스·담당 구역 연결을 지원합니다.

- **이메일 회원가입**: `/signup/affiliation`(소속 선택) → `/signup`(정보 입력) — **소속(Affiliation)만** 선택, 건물·강의실은 제보 시 선택
- **Google OAuth**: 소속 선택 후 Google 로그인 → FE `/oauth/callback?token=...` → 필요 시 `PATCH /api/me/affiliation`
- **관리자 계정**: Flyway 시드 `UserType.ADMIN` — `/signup/admin`은 **승인 문의 UI** (자가 가입 아님)
- **계정 찾기**: `/find-account` 화면
- **소속·담당 구역 변경**: `PATCH /api/me/affiliation`, `PATCH /api/me/building` (OAuth·관리자 담당 GROUP)
- **전화번호**: 회원가입 시 `phoneNumber` 수집, 중복 확인(`GET /register/check-phone`) 지원
- ~~카카오 OAuth~~: 2026-05-24 제외 — Google + 이메일만

## 기능 흐름도

```
[학생]
  │
  ├─ 앱 실행 → 로그인 (이메일 / Google OAuth)
  │
  ├─ 사진 촬영/업로드 + 위치 선택 (LocationNode LEAF)
  │       │
  │       ▼
  │   [AI 3단계 판별 — Cloud Run]
  │   YOLOv8n → YOLOv8n Custom → Gemini 2.5 Flash
  │       │
  │   낭비 확인? ──Yes──► WASTE_DETECTED 저장 → estimatedKwh·estimatedPoint 저장 (잔액 적립 ⏳)
  │       │ No/Error
  │       └──► "판별 불가" 안내 (저장 안 됨)
  │
  ├─ 제보 이력 조회 + 절약량 확인
  │
  └─ 포인트 교환 신청 → 기프티콘 수령 대기

[관리자]
  │
  ├─ 장소 관리 (1·2·3단계 그룹/항목 CRUD)
  ├─ 운영 스케줄 등록 (요일별 on/off 시간)
  ├─ 기프티콘 교환 관리 (목록·상태 변경·통계)
  ├─ 제보 확인 → 이의 신청 (필요 시) ⏳
  └─ 월 정산 확인 ⏳
```
