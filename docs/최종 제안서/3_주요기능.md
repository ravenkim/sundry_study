## 기능1: AI 이미지 낭비 분석

**설명**

학생이 업로드한 강의실 사진을 **3단계 AI 파이프라인**으로 분석하여, 빈 강의실에서 조명·에어컨이 켜져 있는지 자동 판별합니다.

| 단계 | 모델 | 역할 |
|------|------|------|
| 1단계 | YOLOv8n (COCO 사전학습) | person/chair/desk 탐지 → 강의실 여부·사용 중 여부 판별 |
| 2단계 | YOLOv8n Custom (`ac_best.pt`) | 천장 4-way 에어컨 탐지 (mAP 0.990) |
| 3단계 | Gemini 2.5 Flash (Vertex AI) | 조명·에어컨 ON/OFF 상태 JSON 반환 |

- **1단계**: chair=0 AND desk=0 → "강의실 아님" ERROR / person≥1 → "사용 중" PASS / person=0 → 2단계 진행
- **2단계**: 에어컨 탐지 시 크롭 이미지와 원본을 Gemini에 전달(시나리오 A), 미탐지 시 원본만 전달(시나리오 B)
- **3단계**: ac_status=ON 또는 light_status=ON → **WASTE_DETECTED** (낭비 확인), 둘 다 OFF → PASS

판별 소요 시간 **5초 이내**, Gemini API 비용 건당 약 0.01달러 이하.

## 기능2: 제보·포인트 정산 처리

**설명**

학생이 사진을 촬영·업로드하면, AI 판별 결과에 따라 **포인트를 즉시 적립**하고, 절약량을 자동 계산합니다.

- **제보 업로드**: 강의실 사진 촬영 또는 갤러리 선택, 건물·강의실 위치 태깅
- **이미지 저장**: Google Cloud Storage(GCS) 비공개 버킷에 저장
- **절약량 계산**: 기구 종류·소비전력·방치 시간(수업표 연동 또는 기본 2시간) 기반 kWh 산출
- **포인트 적립**: `총 절약 금액 × 0.18` (건물주 납부 20% × 사용자 몫 90%) → 즉시 PointTransaction 생성
- **비동기 처리**: Apache Kafka를 통한 포인트 정산 Producer/Consumer (`ECO_POINT_TOPIC`)

예: 303호 형광등 10개(40W) + 에어컨 1대(1.5kW), 2시간 방치 → 약 **89포인트** 적립.

## 기능3: 관리자 대시보드

**설명**

건물 관리자·건물주가 제보 현황과 절약 효과를 한눈에 파악할 수 있는 **웹 대시보드**입니다.

- **건물·강의실 등록**: 건물명, 강의실 수, 전열기구 종류·소비전력 입력
- **제보 목록 확인**: AI 판별 결과(JSON), 사진, 포인트 지급 내역 조회
- **월 절약량 대시보드**: 이번 달 제보 건수, 추정 절감 전기료, 누적 탄소 배출 절감량
- **수업 시간표 등록**: 강의실별 수업 시간 → 사용 중 강의실 자동 필터
- **정산 내역**: 학생별 포인트 지급, 플랫폼 수수료 내역

## 기능4: 어뷰징 방지

**설명**

조명을 일부러 켜고 사진을 찍는 등 **악의적 제보**를 규칙 기반 필터로 차단합니다.

| 규칙 | 임계값 | 처리 |
|------|-------|------|
| 동일 강의실 중복 제보 | 1시간 내 같은 room_id | 두 번째부터 자동 반려 |
| 단기간 과다 제보 | 1일 20건 초과 | 계정 경고 + 제보 잠금 |
| 야간 시간대 제보 | 자정~06시 | 자동 보류 → 관리자 수동 검토 |
| 동일 IP 다중 계정 | 같은 IP 5계정 이상 | 신규 제보 차단 |

관리자는 **제보 이의 신청**을 통해 오판·어뷰징 의심 건에 대해 포인트 회수 가능.

---

## 기능5: 포인트 교환·리워드

**설명**

적립된 포인트를 **기프티콘·리워드**로 교환하고, 게이미피케이션으로 지속 참여를 유도합니다.

- **포인트 잔액 확인**: 누적 포인트, 이번 달 획득량 표시
- **포인트 교환**: 기프티콘 선택 및 교환 신청 → 카카오톡 등으로 발송
- **제보 이력 조회**: 내가 올린 제보 목록 및 처리 상태
- **랭킹·리더보드** (P1): 이달의 에코 히어로 (제보 순위)
- **탄소 절감 뱃지** (P1): 누적 절감량 달성 시 뱃지 획득

## 기능 흐름도

```
[학생]
  │
  ├─ 앱 실행 → 로그인 (카카오/이메일)
  │
  ├─ 사진 촬영/업로드 + 위치 선택
  │       │
  │       ▼
  │   [AI 3단계 판별]
  │       │
  │   낭비 확인? ──Yes──► 포인트 즉시 적립
  │       │ No
  │       └──► "판별 불가" 안내
  │
  └─ 포인트 교환 신청

[관리자]
  │
  ├─ 건물 등록
  ├─ 제보 확인 → 이의 신청 (필요 시)
  └─ 월 정산 확인
```
