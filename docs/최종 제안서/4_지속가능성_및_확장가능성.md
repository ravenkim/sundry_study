# 4. 지속 가능성 및 확장 가능성

---

## 기대 효과

### 환경적 효과

에코리포트는 **IoT 설비 없이** 학생의 자발적 참여와 AI 자동 판별만으로 캠퍼스 에너지 낭비를 줄입니다. 100개 강의실을 보유한 1개 캠퍼스 기준으로 산출한 환경적 임팩트는 다음과 같습니다.

| 지표 | 1개 캠퍼스 (100개 강의실 기준) |
|------|-------------------------------|
| 월 절약 전기 | 약 **600~1,000 kWh** |
| 월 탄소 절감 | 약 **280~470 kg CO₂** (전력 탄소계수 0.469 kgCO₂/kWh) |
| 연간 절감 효과 | 소나무 약 **50~80그루** 흡수량과 동등 |

대학 캠퍼스 전체 에너지 비용의 약 30%가 빈 강의실·복도·화장실 등에서 낭비된다는 추정치를 적용하면, 에코리포트 도입 시 **교내 전기 소비의 상당 부분을 즉시 절감**할 수 있습니다. AI가 제보 건마다 절약 금액과 전기량을 자동 계산(`expected`, `expectedKwh`)하여, 학생이 사진 한 장의 실질적 임팩트를 즉시 체감할 수 있습니다.

에코리포트는 **장소별 운영 스케줄**(`LocationOperatingSchedule` — 요일별 on/off 시간)을 기반으로 비운영 시간의 낭비 여부를 정확히 판별합니다. 운영 중인 강의실(수업 시간 내)은 PASS 처리하여 오판을 최소화하고, 비운영 시간대의 실질적 낭비만 집계합니다.

2030 탄소중립 국가 목표와 교육부 그린스마트 미래학교 사업 등 **정책적 흐름**과도 정확히 부합합니다. 전국 약 200개 4년제 대학, 200만 명의 대학생이라는 1차 시장 규모를 고려할 때, 확산 시 **연간 수십만 kWh, 수천 톤 CO₂** 규모의 절감 잠재력을 가집니다.

또한 전기(조명·에어컨)뿐 아니라 **수도(화장실 수도꼭지)** 등 자원 유형 확장 설계가 이미 반영되어 있어, 단일 플랫폼으로 **에너지·수자원 통합 관리**가 가능합니다. ResourceType 마스터(ELECTRICITY/WATER)와 LocationResource 구조를 통해, 관리자가 건물별로 전열기구·수도 기구를 자유롭게 등록·확장할 수 있습니다.

### 경제적 효과

| 대상 | 효과 |
|------|------|
| **건물주/대학** | 월 전기료 **10~30% 절감** (설비 투자 없이) |
| **학생** | 제보 1건당 절약 금액의 일부 포인트 → 기프티콘 교환 |
| **플랫폼** | 100개 건물 기준 월 수수료 약 **22만 원** |

건물주·대학은 **수억 원 규모의 IoT·스마트빌딩 설비 없이** 전기료를 절감할 수 있습니다. 1개 건물(강의실 50개, 일 20% 낭비, 2시간 방치, 22영업일) 기준 월 낭비 전기료 약 10만 원 중, 절약분의 20%를 플랫폼에 납부하고 나머지 80%는 실질적 절감으로 확보합니다. **100개 건물**이 플랫폼에 가입하면 플랫폼 월 수수료 약 22만 원, **연 264만 원** 수준의 지속 가능한 수익 구조가 형성됩니다.

학생은 **사진 한 장**으로 AI가 계산한 절약 금액 기반 포인트를 적립하고, 기프티콘·리워드로 교환할 수 있습니다. 현재 MVP에서는 `GET /api/rewards` — 리워드 상품 목록 조회, `POST /api/points/exchange` — 포인트 교환 신청, `GET /api/points/exchanges/me` — 교환 이력 조회가 **BE 실연동** 완료되어 있습니다.

플랫폼은 절감액의 10% 수수료로 **손익분기점(BEP)**을 달성합니다. Gemini API·GCP 서버 등 월 고정 지출 약 7만 원 기준, **약 32개 건물** 가입 시 BEP 달성. 이후 건물 수에 비례해 수익이 선형적으로 증가하는 **확장 가능한 단위 경제성**을 갖습니다.

### 사회적 효과

- **학생 주도 탄소중립 문화 형성**: "내가 사진 찍으면 캠퍼스가 바뀐다"는 체감을 통해, 패시브한 환경 인식에서 **액티브한 참여 문화**로 전환
- **크라우드소싱 기반 스마트캠퍼스 모델 제시**: IoT·스마트빌딩과 달리 **저비용·즉시 도입** 가능한 대안으로, 국내 유사 서비스 공백 영역을 선점
- **교육부 그린스마트 미래학교 사업 연계**: 학교·대학 에너지 효율화 국가 투자와 연계하여 **B2G(정부-기업)** 납품·파일럿 확대 가능
- **데이터 기반 에너지 관리**: 제보·절약량·패턴 데이터 축적으로, 상습 방치 강의실 예측·관리자 알림 등 **중장기 고도화** 기반 마련
- **사회적 약자·환경에 실질적 도움**: 팀 기획 방향(이은총)과 같이, 수상·확산 시 **환경·지속가능성**이라는 공공 가치를 실현

당근마켓(로컬 크라우드소싱), 포켓몬고(현실 공간 + 게이미피케이션) 등 **참여 동기 부여** 성공 사례를 벤치마킹하여, 포인트·랭킹·뱃지 등 게이미피케이션으로 **지속 참여**를 유도합니다.

---

### 사용자 편의성

- **스마트폰만으로 즉시 참여**: 별도 앱 설치 없이 모바일 웹(React)으로 접속, `<input capture="environment">`로 카메라 직접 호출
- **5초 이내 AI 판별**: YOLOv8n + Gemini 2.5 Flash 파이프라인으로 **즉각 피드백**, "낭비 확인됨 + N원 절약" + 포인트 적립을 한 화면에서 확인
- **즉시 교환**: 포인트 적립 → `POST /api/points/exchange` → 기프티콘 교환 신청 — BE 실연동
- **직관적 UI**: Google Stitch·VinSign 시안 → AI Studio 코드 변환, Volt Yellow·Eco Green 브랜드 컬러, 하단 탭 5개(홈·제보·이력·포인트샵·마이페이지)
- **다양한 로그인**: 이메일 회원가입/로그인(다단계 플로우) + Google OAuth — 모두 BE 연동 완료

관리자는 **웹 대시보드**에서 장소 관리(3단 컬럼 탐색기), 기프티콘 교환 관리, 건물별 절약량 현황을 한눈에 확인하고, 운영 스케줄 설정으로 **AI가 수업 중 강의실을 자동 필터**하여 오판을 최소화합니다.

## 확장 가능성

### 실제 서비스화 가능성

에코리포트는 **해커톤 MVP**를 넘어 실제 서비스로 확장 가능한 구조를 갖추고 있습니다.

| 단계 | 기간 | 목표 |
|------|------|------|
| **파일럿** | 출시 후 1개월 | 제보 500건, 참여 학생 100명, 건물 1~3개 |
| **초기 성장** | 3개월 | 제보 5,000건, 건물 10개, 월 절약 전기 5,000 kWh |
| **확산** | 6개월 | 대학 5개교, 건물 50개, MAU 1,000명 |
| **확장** | 1년 | 대학 20개교, 공공기관 진출 논의 |

- **Phase 1 (해커톤)**: UI 전체 + 이메일/Google OAuth + BE AI 판별(Cloud Run) + 제보 DB 저장 + 리워드·포인트 교환 + 기프티콘 관리 + 건물 절약량 + mock 관리자 제보/대시보드 UX 시연
- **Phase 2 (파일럿)**: 1~2개 대학과 MOU, GCS 이미지 저장, Kafka 포인트 자동 적립, 실제 제보·포인트 정산 운영
- **Phase 3 (확산)**: 에브리타임·학교 커뮤니티 채널, 시설팀 B2B 영업
- **Phase 4 (B2G)**: 지자체·교육부 그린스마트학교 사업 연계, 공공기관 납품

기술적으로 Spring Boot + MySQL + Docker Compose 조합은 **검증된 스택**이며, `deploy.sh`로 FE·BE·MySQL을 **학교 서버(`ubuntu03`)에 즉시 배포**할 수 있다. AI FastAPI는 **GCP Cloud Run(`us-central1`)에 배포**되어 BE가 `/analyze`를 호출한다. GCS·Kafka는 **목표 인프라**로 설계되어 있으며, Phase 2에서 연동한다.

### 다른 분야 확장 가능성

| 확장 영역 | 내용 |
|----------|------|
| **1차 시장** | 국내 대학 캠퍼스 (약 200개교, 200만 명) |
| **2차 시장** | 공공기관(지자체 청사, 도서관), 기업 오피스, 병원·복합시설 |
| **자원 유형** | 전기(조명·에어컨) → 수도(수도꼭지) → 공조·난방 (ResourceType 확장) |
| **데이터 활용** | 익명 에너지 낭비 데이터 → 에너지 컨설팅사 B2B, 상습 방치 패턴 예측 |
| **자동화 연계** | 낭비 패턴 시계열 분석 → IoT·BMS 연동 시 자동 제어 트리거 (장기) |

경쟁 서비스(삼성 SmartThings, KT AI 에너지관리, 한전 에너지마켓플레이스)와 달리, 에코리포트는 **학생 직접 참여 + AI 자동 판별 + 보상 연계**로 기존 공백 영역을 공략합니다. IoT 설비 확대 시에도 **크라우드소싱 데이터**는 IoT 센서 보완·검증 수단으로 활용 가능합니다.

### 수익화 모델

```
[건물주 / 대학]
       │ 절약된 전기료의 20% 납부
       ▼
[에코리포트 플랫폼]
       ├── 10% (플랫폼 수수료) ──► 플랫폼 수익
       └── 90% (포인트 풀) ──────► 학생 포인트 (기프티콘 교환)
```

| 수익원 | 시점 | 예상 규모 |
|--------|------|----------|
| **플랫폼 수수료** (핵심) | 즉시 | 건물 수 비례, 100개 건물 시 월 22만 원 |
| **친환경 브랜드 스폰서십** | 6개월 이후 | 월 100만 원 수준 |
| **익명 에너지 낭비 데이터 판매** | 1년 이후 | 에너지 컨설팅사 B2B |
| **공공기관 B2G 솔루션 납품** | 1년 이후 | 지자체·정부기관 |

- **핵심 파트너**: Google Cloud/Gemini, 기프티콘 공급사(카카오, GS25), 대학 시설팀, 한국전력
- **경쟁 우위**: 크라우드소싱 **네트워크 효과** (참여자 多 → 데이터 多 → 정확도↑)

### SWOT 요약

| | 긍정 | 부정 |
|--|------|------|
| **내부** | **강점(S)**: 저비용 도입, 학생 참여 동기(보상), AI 자동화, 포인트 교환 실연동 | **약점(W)**: 초기 제보 데이터 부족, 어뷰징 리스크, GCS·Kafka 미연동 |
| **외부** | **기회(O)**: 탄소중립 정책, 그린캠퍼스 트렌드, 에너지 비용 급등 | **위협(T)**: IoT 설비 확대 시 플랫폼 필요성 감소 |

어뷰징(조명 켜고 허위 제보) 발생 시 관리자 이의 신청·포인트 회수, 계정당 일일 제보 캡, AI 탐지 등 **다층 방어**로 재무·신뢰 리스크를 관리합니다.

## 발표 핵심 메시지

> **"사진 한 장이 캠퍼스를 바꿉니다."**

1. **문제**: "대학 전기료의 30%가 빈 강의실에서 낭비됩니다"
2. **해결**: "학생이 사진 찍으면 AI가 분석하고 절약 금액과 포인트가 쌓입니다"
3. **임팩트**: "한 캠퍼스에서 월 수백 kWh 절약, 소나무 50그루 효과"
4. **확장성**: "IoT 설비 없이 대한민국 모든 대학에 즉시 도입 가능"
5. **비즈니스**: "건물주가 절약한 전기료의 일부를 학생에게 기프티콘으로 돌려주는 선순환 구조"
