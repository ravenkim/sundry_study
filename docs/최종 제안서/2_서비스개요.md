# 2. 서비스 개요

---

## 서비스명

**에코리포트 (EcoReport)**

> AI 기반 캠퍼스 에너지 낭비 제보 및 보상 플랫폼

---

## 한 줄 소개

**"빈 강의실에 켜진 전등 사진 한 장 → AI 분석 → 포인트 적립"**

학생의 작은 제보가 학교 전기료를 줄이고, 그 절약분을 학생에게 돌려주는 선순환 구조.

---

## 문제 정의

### 1. 캠퍼스 에너지 낭비의 현실

대학 캠퍼스는 수백 개의 강의실, 복도, 화장실, 휴게 공간으로 구성되어 있으며, 이 공간들의 조명·에어컨·히터 등 전열 기구가 **수업이 끝난 뒤에도 장시간 켜진 채 방치**되는 일이 빈번하게 발생합니다.

수업이 종료된 강의실에서 마지막으로 나가는 학생이 소등하지 않으면, 다음 수업까지 수 시간 동안 불필요한 전력이 소비됩니다. 복도·화장실·무인 공간에서는 관리자가 순찰하기 전까지 에너지 낭비가 지속됩니다. 이러한 **"보이지 않는 낭비"**는 개별 건물·강의실 단위로는 작아 보이지만, 캠퍼스 전체로 합산하면 막대한 비용과 탄소 배출로 이어집니다.

### 2. 수치로 보는 문제의 규모

| 지표 | 수치 |
|------|------|
| 강의실 평균 에너지 낭비 비율 | 교내 에너지 비용의 약 **30%** |
| 형광등 1개(32W) 1시간 방치 | 약 **0.032 kWh** → 100개 강의실 기준 월 수천 원 |
| 에어컨(1,500W) 1대 1시간 방치 | 약 **1.5 kWh** → 4시간 방치 시 **6 kWh (720원)** |
| 100개 강의실 기준 월 낭비 비용 | **수백만 원** 수준 (전기요금 120원/kWh 기준) |

100개 강의실을 보유한 중형 대학 기준, 하루 20%의 강의실(20개)에서 평균 2시간씩 조명·에어컨이 방치된다고 가정하면, 월 약 **800 kWh 이상**, 전기료 **약 10만 원 이상**이 불필요하게 지출됩니다. 이는 연간 **수천만 원** 규모의 낭비로 확대됩니다.

### 3. 기존 해결 방안의 한계

| 기존 방안 | 한계 |
|----------|------|
| **스마트빌딩 IoT 자동 제어** | 인프라 구축 비용 수억 원, 기존 건물 적용 어려움 |
| **관리인 순찰** | 인건비 발생, 실시간 대응 불가, 야간·주말 공백 |
| **학생 캠페인·스티커 부착** | 강제력 없음, 일시적 효과, 지속 참여 유도 어려움 |
| **절전 안내 방송** | 인지 → 행동 전환율 낮음, 피드백·보상 부재 |

스마트빌딩 솔루션은 **고비용·장기 투자**가 필요하여 대부분의 대학 캠퍼스에는 도입이 어렵습니다. 관리인 순찰은 **인건비**와 **시간 지연** 문제가 있고, 학생 대상 캠페인은 **인센티브 부재**로 지속적 참여를 이끌어내기 힘듭니다.

### 4. 왜 학생인가?

강의실에서 마지막으로 나가는 사람은 **학생**입니다. 동선상 가장 먼저 낭비를 발견하는 것도 **학생**입니다. 그러나 현재는 행동에 대한 **인센티브가 전혀 없기** 때문에, 대부분의 학생은 "내가 꺼야 하나?"라는 생각조차 하지 않거나, 꺼더라도 아무런 보상 없이 그냥 지나칩니다.

> **핵심 가설**: "합리적인 보상이 주어진다면 대학생은 에너지 낭비를 자발적으로 제보할 것이다."

Z세대는 환경 문제에 대한 **높은 관심**을 보이지만, 실질적 보상(포인트, 기프티콘)이 결합된 친환경 행동에 **더 높은 참여율**을 보입니다. 씨리얼(영수증 리워드), 우리동네 환경지킴이(시민 제보 → 지역화폐) 등 **일상 행동 → 보상 연결** 모델이 이미 검증되어 있습니다.

### 5. 사회적·정책적 맥락

- **2030 탄소중립 국가 목표**: 교육 기관의 에너지 절감 의무화 논의가 진행 중입니다.
- **교육부 그린스마트 미래학교 사업**: 학교·대학 에너지 효율화에 대한 국가 투자가 확대되고 있습니다.
- **에너지 비용 급등**: 전기료·가스비 상승으로 대학·공공기관의 에너지 관리 압박이 커지고 있습니다.

에코리포트는 이러한 **정책·사회적 흐름**과 정확히 부합하며, IoT 설비 없이 **즉시 도입 가능한 소프트웨어 우선** 접근으로 캠퍼스 에너지 문제를 해결합니다.

### 6. 왜 대학을 1차 타겟으로 하는가?

공공기관·오피스로의 확장을 염두에 두되, **초기 타겟은 대학 캠퍼스**입니다.

- **넓은 캠퍼스, 알 수 없는 운영 상태**: 강의실뿐 아니라 **동아리실·세미나실**처럼 수업 시간표와 무관한 공간은 지금 사용 중인지, 불필요하게 전기가 켜져 있는지 **관리자가 실시간으로 알기 어렵습니다**.
- **순찰로는 커버하기 힘든 물리 환경**: **층수가 높고 엘리베이터가 없는 건물**, **언덕·계단**이 많은 동선 등으로 관리인 순찰만으로는 전 구역을 돌기 어렵습니다. 학생의 일상 동선에서 발견·제보하는 **크라우드소싱**이 현실적 대안입니다.
- **문화 확산 — 배움의 장에서 시작**: 대학은 환경·지속가능성을 배우는 **교육 공간**입니다. 캠퍼스에서 "내 행동이 변화를 만든다"는 경험이 졸업 후 직장·지역사회로 **친환경 문화**를 퍼뜨리는 출발점이 됩니다.

## 해결 방안

### 1. 에코리포트의 접근: 크라우드소싱 + AI + 보상

에코리포트는 **학생이 스마트폰으로 빈 강의실의 낭비 사진을 찍어 제보**하면, **AI가 자동으로 낭비 여부를 판별하고 절약 금액을 계산**하며, **검증된 제보에 대해 즉시 포인트를 지급**하는 크라우드소싱 플랫폼입니다.

```
              저비용 ◄──────────────────────► 고비용
                  │                              │
          [에코리포트]                  [IoT 스마트빌딩]
       (크라우드소싱 기반)              (인프라 구축 필요)
                  │                              │
           학생 자발 참여                   자동화 완성
                  │                              │
         즉시 도입 가능                  장기 투자 필요
```

기존 건물 인프라를 **전혀 변경하지 않고**, 학생이 이미 가지고 있는 **스마트폰 카메라**만으로 운영 가능합니다.

### 2. 3단계 AI 파이프라인

제보된 사진은 **3단계 AI 분석**을 거칩니다.

1. **YOLOv8n (사람·가구 감지)**: 강의실인지, 사람이 있는지 판별 → 빈 강의실만 다음 단계로
2. **YOLOv8n Custom (에어컨 탐지)**: 천장 4-way 에어컨 탐지 및 크롭 → Gemini에 전달
3. **Gemini 2.5 Flash (ON/OFF 판별)**: 조명·에어컨 켜짐/꺼짐 상태를 JSON으로 반환 → 낭비 여부 최종 판정

Gemini는 장소의 **운영 스케줄** 데이터를 참고하여 현재 시각이 운영 외 시간대인지 판단합니다. 낭비가 확인되면 방치 시간과 기기 수를 계산해 **절약 금액** 예: `"494원"`과 **절약 전기량** 예: `"3.8 kWh"`을 반환합니다.

AI 판별은 **5초 이내**에 완료되며, 학생은 즉시 "낭비 확인됨" 결과와 함께 절약 금액·적립 포인트를 확인할 수 있습니다.

### 3. 포인트 보상 및 선순환 구조

```
[학생] 사진 제보 → [AI] 낭비 판별 + 절약량 계산 → [포인트] 즉시 적립
                                                       ↓
[관리자] 제보 확인 → 조치(소등 등) → [절약량] 실제 절감
                                                       ↓
[건물주] 절약 전기료의 20% 플랫폼 납부
         ├── 10% → 플랫폼 수수료
         └── 90% → 학생 포인트 풀 (기프티콘 교환)
```

- **학생**: 사진 한 장 → 절약량·포인트 확인 → 기프티콘·리워드 교환
- **건물주/대학**: 무설비 투자로 전기료 10~30% 절감, 데이터 기반 관리
- **플랫폼**: 절감액의 10% 수수료로 지속 가능한 운영

### 4. 관리자 대시보드

건물 관리자·건물주는 **웹 대시보드**에서 다음을 확인합니다.

- AI 판별 결과가 포함된 **제보 목록** 및 사진
- **건물별 절약량** — `totalKwh`, `thisMonthKwh`, `reportCount`
- **장소 관리** — 1·2·3단계 그룹/항목 CRUD, 요일별 운영 스케줄
- **기프티콘 교환 관리** — 교환 신청 목록·통계·상태 변경

### 5. 어뷰징 방지

조명을 일부러 켜고 사진을 찍는 등 **악의적 사용**에 대해 **4단계 다층 방어(L1~L4)**를 적용합니다.

- **L1 사전**: 운영 시간 외만 제보 ✅, 강의실당 1인 1회 ✅, 1시간 중복·일 20건 캡·야간 보류 ⏳
- **L2 AI**: 사람·강의실·ON/OFF 자동 판별 ✅
- **L3 지급**: 포인트 지연 확정(24~48h)·확인형 지급으로 「켜고 찍기」 즉시 수익 차단 ⏳
- **L4 사후**: 관리자 이의·포인트 회수·계정 제한 ⏳

> 사진 AI만으로는 「누가 켰는지」 판별 불가 — 반복·경제·운영 장치로 **악용 이득 < 전기료·제재**를 목표로 합니다.

## 서비스 구조 요약

```
[학생 사용자]
    ↓ 빈 강의실 낭비 사진 업로드 (모바일 웹)
[에코리포트 BE — Spring Boot]
    ↓ AI 이미지 분석 요청
[AI FastAPI — GCP Cloud Run]
    ↓ YOLOv8n → YOLOv8n Custom → Gemini 2.5 Flash
    → WASTE_DETECTED + 절약금액("494원") + 절약전기량("3.8 kWh")
[에코리포트 BE]
    ↓ 제보 DB 저장 + 포인트 즉시 적립
[학생] 포인트 → 기프티콘 교환 신청
[관리자] 제보 확인 → 기프티콘 승인 → 학생에게 발급
```
