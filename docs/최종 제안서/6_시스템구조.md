## 3. AI 판별 처리 흐름 (시퀀스)

```mermaid
sequenceDiagram
  participant Client as StudentApp
  participant BE as SpringBootAPI
  participant GCS as GCSBucket
  participant AI as FastAPICloudRun
  participant YOLO as YOLOv8n
  participant Gemini as Gemini25Flash
  participant DB as MySQL
  participant Kafka as KafkaQueue

  Client->>BE: POST /api/reports (image)
  BE->>GCS: Save image
  BE->>AI: POST /analyze
  AI->>YOLO: Step1 person/chair/desk
  alt person greater than 0
    YOLO-->>AI: PASS used room
    AI-->>BE: PASS
  else empty classroom
    AI->>YOLO: Step2 AC detect
    YOLO-->>AI: AC crop or none
    AI->>Gemini: Step3 ON/OFF JSON
    Gemini-->>AI: ac_status light_status
    AI-->>BE: WASTE_DETECTED or PASS
  end
  BE->>DB: Save Report
  BE->>Kafka: Point earn event
  BE-->>Client: Result + points
```

## 4. AI 3단계 판별 로직

```
[클라이언트] 사진 업로드
    ▼
[Spring Boot] GCS 저장 → AI Service POST /analyze
    ▼
[1단계] YOLOv8n (conf=0.3, person/chair/desk)
    ├─ chair=0 AND desk=0 → ERROR (강의실 아님)
    ├─ person ≥ 1 → PASS (사용 중)
    └─ person = 0 ↓
[2단계] YOLOv8n Custom ac_best.pt (conf=0.4)
    ├─ 에어컨 미탐지 → [3단계 시나리오 B]
    └─ 에어컨 탐지 → 크롭 → [3단계 시나리오 A]
[3단계] Gemini 2.5 Flash
    ├─ 낭비 감지 → WASTE_DETECTED
    └─ 모두 꺼짐 → PASS
    ▼
[Spring Boot] Report 저장 → 어뷰징 필터 → 절약량 계산 → Kafka 포인트 적립
    ▼
[클라이언트] 결과 반환
```

## 6. 배포 구성

```mermaid
flowchart LR
  subgraph local [LocalDockerCompose]
    FE8081[FE_nginx_8081]
    BE8080[BE_Spring_8080]
    MySQL3306[MySQL_3306]
  end

  subgraph gcp [GCPCloudRun]
    CR_FE[ecoreport-fe]
    CR_BE[ecoreport-be]
    CR_AI[AI_FastAPI]
  end

  subgraph school [SchoolServer]
    SchoolMySQL[MySQL_SSH7540]
    SchoolDocker[Docker_BE]
  end

  FE8081 --> BE8080
  BE8080 --> MySQL3306
  CR_FE --> CR_BE
  CR_BE --> CR_AI
  SchoolDocker --> SchoolMySQL
```

| 환경 | 명령 | 구성 |
|------|------|------|
| **로컬 통합** | `bash deploy.sh` | Docker Compose: MySQL + BE(8080) + FE(8081, nginx) |
| **BE 단독** | `be/deploy.sh` {build\|docker\|cloudrun} | Spring Boot multi-stage Dockerfile |
| **FE 단독** | `fe/deploy.sh` {build\|docker\|cloudrun} | Vite build → nginx, `VITE_API_HOST` bake-in |
| **GCP** | `bash deploy.sh cloudrun` | BE Cloud Run → FE Cloud Run (asia-northeast3) |
| **학교 서버** | Docker + Git clone | MySQL(SSH 7540), BE 8081 (외부 포트 개방 신청) |

## 7. 주요 API 엔드포인트

| Method | Endpoint | 설명 |
|--------|----------|------|
| POST | `/api/reports` | 제보 사진 업로드 + AI 판별 요청 |
| GET | `/api/reports/me` | 내 제보 이력 |
| GET | `/api/points/me` | 내 포인트 잔액 |
| POST | `/api/points/exchange` | 포인트 교환 신청 |
| POST | `/admin/buildings` | 건물 등록 (관리자) |
| GET | `/admin/reports` | 제보 목록 (관리자) |
| GET | `/admin/dashboard` | 월간 절약 현황 (관리자) |
| POST | `/analyze` | AI Service — 이미지 분석 (FastAPI) |
