## 3. AI 판별 처리 흐름 (시퀀스)

```mermaid
sequenceDiagram
  participant Client as StudentApp
  participant BE as SpringBootAPI
  participant AI as FastAPICloudRun
  participant YOLO as YOLOv8n
  participant Gemini as Gemini25Flash
  participant DB as MySQL

  Client->>BE: POST /api/reports (image + metadata)
  BE->>AI: POST /analyze (image + operatingSchedules)
  AI->>YOLO: Step1 person/chair/desk
  alt person greater than 0
    YOLO-->>AI: PASS used room
    AI-->>BE: PASS
    BE-->>Client: 사용 중 안내 (저장 안 됨)
  else empty classroom
    AI->>YOLO: Step2 AC detect
    YOLO-->>AI: AC crop or none
    AI->>Gemini: Step3 ON/OFF + expected 계산
    Gemini-->>AI: ac_status, light_status, expected, expectedKwh
    AI-->>BE: WASTE_DETECTED (or PASS)
    BE->>DB: Save Report + estimatedKwh·estimatedPoint
    BE->>DB: MemberPoint 포인트 적립
    BE-->>Client: Result + expected + pointAwarded
  end
```

## 4. AI 3단계 판별 로직

```
[클라이언트] 사진 업로드 + 위치(LocationNode LEAF) 선택
    ▼
[Spring Boot] BE → AI Service POST /analyze
             (image + operatingSchedules metadata)
    ▼
[1단계] YOLOv8n (conf=0.3, person/chair/desk)
    ├─ chair=0 AND desk=0 → ERROR (강의실 아님)
    ├─ person ≥ 1 → PASS (사용 중)
    └─ person = 0 ↓
[2단계] YOLOv8n Custom ac_best.pt (conf=0.4)
    ├─ 에어컨 미탐지 → [3단계 시나리오 B: 원본만 전달]
    └─ 에어컨 탐지 → OpenCV 크롭 → [3단계 시나리오 A: 원본 + 크롭 전달]
[3단계] Gemini 2.5 Flash
    ├─ operatingSchedules 참고 → 운영 외 시간대 판단
    ├─ ac_status=ON 또는 light_status=ON → WASTE_DETECTED
    │   └─ 에너지 상수(형광등 32W, LED 15W, AC 1,500W, 120원/kWh) 적용
    │       → expected("N원"), expectedKwh("N kWh") 산출
    └─ 모두 꺼짐 또는 운영 중 → PASS
    ▼
[Spring Boot]
    ├─ WASTE_DETECTED → Report 저장 + estimated 필드 저장 + MemberPoint 적립
    ├─ PASS / ERROR → 저장 안 함 (BusinessLogicException 반환)
    └─ AI 통신 실패 → INTERNAL_SERVER_ERROR (5003)
    ▼
[클라이언트] 결과 + 절약 금액·전기량·적립 포인트 표시
```

## 5. 데이터베이스 ERD

```mermaid
erDiagram
  Affiliation ||--o{ LocationNode : owns
  Affiliation ||--o{ Member : belongs
  LocationNode ||--o{ LocationNode : parent
  LocationNode ||--o{ Report : leaf_target
  LocationNode ||--o{ LocationOperatingSchedule : has_schedule
  Member ||--o{ Report : submits
  Member ||--|| MemberPoint : has
  Member ||--o{ GifticonExchange : requests
  Reward ||--o{ GifticonExchange : exchanged_to

  Affiliation {
    int id
    string name
    string address
  }

  LocationNode {
    int id
    int parent_id
    string name
    string nodeKind
    int depth
    int sortOrder
    int acCount
    int fluorescentCount
    int ledCount
  }

  LocationOperatingSchedule {
    int seq
    int location_node_seq
    int dayOfWeek
    boolean isClosed
    time powerOnTime
    time powerOffTime
  }

  Member {
    int id
    string email
    string phoneNumber
    int affiliation_id
    string userType
  }

  Report {
    int id
    string image_url
    string status
    string wasteType
    decimal estimated_kwh
    int estimated_savings_krw
    int estimated_point
    int point_awarded
  }

  MemberPoint {
    int id
    int member_id
    int balance
  }

  Reward {
    int seq
    string name
    int pointCost
    string category
    string tag
    boolean isActive
  }

  GifticonExchange {
    int seq
    int member_seq
    int reward_seq
    int pointUsed
    string status
    datetime createdAt
    datetime processedAt
  }
```
