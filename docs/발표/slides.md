# 발표 PPT 슬라이드 구성

> 각 슬라이드별 포함할 내용을 작성합니다. 확정된 내용은 ✅, 작성 중은 🔧, 미정은 ⬜로 표시합니다.

---

## 01. 표지 ⬜

- 서비스명
- 팀명 / 팀원 이름
- 공모전명 / 제출일

---

## 02. 목차 ⬜

- 발표 흐름 한눈에 보기
- 예: 문제 정의 → 솔루션 → 핵심 기능 → 기술 → 기대효과 → 팀 소개

---

## 03. 문제 정의 ⬜

- 해결하려는 사회적/산업적 문제
- 현재 시장의 Pain Point
- 관련 통계 또는 레퍼런스

---

## 04. 솔루션 소개 ⬜

- 우리 서비스가 문제를 해결하는 방식 (한 줄 요약)
- 서비스 핵심 컨셉
- 차별점 / 경쟁 서비스 대비 우위

---

## 05. 핵심 기능 ⬜

- 기능 1: 이름 / 설명 / 스크린샷 or 목업
- 기능 2: 이름 / 설명 / 스크린샷 or 목업
- 기능 3: 이름 / 설명 / 스크린샷 or 목업
- (필요 시 추가)

---

## 06. 서비스 플로우 ⬜

- 사용자 시나리오 (유저 저니 or 플로우차트)
- 주요 화면 흐름 설명

---

## 07. 기술 스택 ⬜

- Frontend: (예: Next.js, TailwindCSS)
- Backend: (예: NestJS, PostgreSQL)
- Infra: (예: AWS, Docker)
- 아키텍처 다이어그램 (선택)

---

## 08. 기대효과 / 비즈니스 모델 ⬜

- 타겟 사용자 및 시장 규모
- 수익 모델 or 사회적 가치
- 향후 확장 방향

---

## 09. 팀 소개 ⬜

- 팀원별 이름 / 역할 (기획 / FE / BE / 디자인)
- 간단한 한 줄 소개 (선택)

---

## 10. 마무리 ⬜

- 핵심 메시지 한 줄 요약
- Q&A 안내
- 연락처 / GitHub / 데모 링크 (있을 경우)
