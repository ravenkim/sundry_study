| 영역 | ✅ 완료 요약 | 🔶 부분 | ⏳ 주요 미구현 |
|------|-------------|---------|----------------|

| **AI** | 별도 저장소 학습·설계 | FE `simulateAiAnalysis` | BE → FastAPI `/analyze` E2E |
| **Infra** | Docker Compose (FE·BE·MySQL) | — | Kafka, GCS, Cloud Run |

## Back-End (Spring Boot)

### ✅ 구현 완료

| 항목 | 엔드포인트·비고 |
|------|----------------|
| 헬스체크 | `GET /ping` |
| 로그인 | `POST /login` — BCrypt 검증, **JWT accessToken** 발급 |
| 회원가입 | `POST /register`, `GET /register/check-email` |
| OAuth2 | `SecurityConfig` + Google provider, 성공 시 FE `/oauth/callback` 리다이렉트 |
| 제보 저장 (1차) | `POST /api/reports` — multipart, Building·WasteType·`PENDING` 저장 |
| DB 엔티티 | `Member`, `Building`, `Report`, `MemberPoint`, `WasteType` |
| 공통 응답·예외 | `ApiResponse`, `ControllerAdvice` (일부 컨트롤러는 미적용) |
| Kafka 스켈레톤 | `PointProducer` / `PointConsumer` (호출·Compose 미연동) |

### 🔶 부분 구현 (보완 필요)

| 우선순위 | 항목 | 현재 상태 | 남은 작업 |
|----------|------|-----------|-----------|
| P0 | `POST /api/reports` | placeholder `imageUrl`, **AI·포인트 없음**, `Map` 직접 응답 | `ApiResponse` 통일, 로그인 회원과 Report 연동, GCS 업로드 후 URL 저장 |
| P0 | Security | `/api/reports`는 `authenticated` 필요 | 제보 생성 시 `memberSeq` 저장, 역할(관리자) 구분 |
| P1 | OAuth | Google만 `application.yaml` | 카카오 provider·회원 자동가입 정책(미가입 시 처리) |
| P1 | API 경로 | 명세는 `/auth/login` 등 | 명세 정합 또는 FE와 경로 문서 통일 |

### ⏳ 미구현 API·도메인

명세 기준 경로는 `/api` prefix 가정. 실제 구현 시 프로젝트 관례(`/login`, `/api/reports`)와 맞춰 통일할 것.

## AI · 인프라 (FE/BE 공통, 참고)

| 영역 | 담당 | 남은 작업 |
|------|------|-----------|
| **AI 서비스** | 별도 FastAPI (Cloud Run) | `POST /analyze` 배포, BE에서 호출, 3단계 파이프라인 E2E |
| **FE Mock** | FE | `fe/src/globals/api/mock/simulator.ts` — BE AI 연동 후 삭제 또는 dev 전용 |
| **GCS** | BE + Infra | 버킷·서비스 계정·업로드 URL을 Report에 저장 |
| **Kafka** | BE + Compose | 브로커 추가, `PointProducer` 제보 승인 시 발행, Consumer 잔액 반영 |
| **CI/CD** | Infra | GitHub Actions, Cloud Run (P2) |

## 권장 구현 순서 (통합)

1. **BE** `GET /api/buildings` + 시드 데이터 → **FE** mock off 건물 목록  
2. **BE** `POST /api/reports` + GCS + AI 응답 형식 통일 → **FE** mock AI 제거  
3. **BE** `GET /api/points/me` + 적립 로직 → **FE** 포인트·홈  
4. **BE** `GET /api/reports/me` · 상세 → **FE** 이력  
5. **BE** 관리자 reports · dashboard → **FE** admin mock 제거  
6. **BE** rewards · exchange · admin CRUD → **FE** 샵·건물 관리
