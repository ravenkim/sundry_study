## Back-End (Spring Boot)

### ✅ 구현 완료

| 항목 | 엔드포인트·비고 |
|------|----------------|
| 헬스체크 | `GET /ping` |
| 로그인 | `POST /login` — BCrypt 검증, **JWT accessToken** 발급 |
| 회원가입 | `POST /register`, `GET /register/check-email`, `GET /register/check-username` — 요청 body에 **`affiliation`(Long, 선택)** 지원, 가입 시 `UserType.USER` 설정, 소속 FK 저장 |
| 소속 | `GET /api/affiliations` — 소속 목록 (permitAll), Flyway `R__seed_dev.sql` 시드 (삼육대학교) |
| 소속·역할 | `Affiliation` 엔티티, `UserType` enum (`USER`/`ADMIN`), `Member` → `Affiliation` FK, **`UserType.ADMIN` 시드 계정** |
| OAuth2 | `SecurityConfig` + Google provider, 성공 시 FE `/oauth/callback` 리다이렉트 |
| 제보 저장 + AI | `POST /api/reports` — JWT `memberSeq` → `Report.member`, **LocationNode(LEAF) FK**, multipart **필수**, Cloud Run `POST /analyze` 호출, `WASTE_DETECTED` → `APPROVED` 저장 + 포인트 즉시 적립 |
| AI 응답 DTO | `AiAnalysisResponse` — `result`, `message`, `ac_status`, `light_status`, `reason` |
| 에러 코드 | `ErrorCode.INTERNAL_SERVER_ERROR` (5003) — AI 서버 통신 실패 |
| 제보 조회 | `GET /api/reports/me` (페이지·상태 필터), `GET /api/reports/{reportId}` (본인만) |
| 장소 트리 (학생) | `GET /api/buildings` — **nested tree** (`buildingId`, `nodeKind`, `children`, `affiliationId`), JWT scope 필터 |
| 장소 관리 (관리자) | `GET /api/admin/location-nodes/tree?affiliationId=`, `POST/PATCH/DELETE /api/admin/location-nodes` — ADMIN 전용 |
| 포인트 | `GET /api/points/me` — `currentBalance` (가입 시 `MemberPoint` 0P 생성) |
| DB 엔티티 | `Member`, **`LocationNode`**, `Report`, `MemberPoint`, `WasteType`, **`Affiliation`**, **`UserType`** |
| 공통 응답·예외 | `ApiResponse`, `ControllerAdvice` |
| Kafka 스켈레톤 | `PointProducer` / `PointConsumer` (호출·Compose 미연동) |

> 시드: Flyway `R__seed_dev.sql` — 4개 루트 GROUP + LEAF 항목. `Building`/`Location` 엔티티 제거됨.
