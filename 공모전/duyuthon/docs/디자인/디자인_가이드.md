# 에코리포트 디자인 가이드

> KRDS(한국 디자인 시스템) 기반 | 전기(⚡ 노랑) + 에코(🌿 초록) 커스텀 컬러

---

## 1. 컬러 시스템

### 1-1. 브랜드 컬러 정의

에코리포트는 두 가지 테마 컬러를 가집니다:
- **Volt Yellow** — 전기 에너지, 제보 액션, 포인트를 상징
- **Eco Green** — 환경, 절약, 지속가능성을 상징

}

## 10. 접근성 (Accessibility)

### 컬러 대비율 확인

| 조합 | 대비율 | WCAG 등급 |
|------|-------|----------|
| `#FFC107` (yellow-500) on `#FFFFFF` | 2.0:1 | ⚠️ AA 미달 — 텍스트 단독 사용 금지 |
| `#FF8F00` (yellow-800) on `#FFFFFF` | 3.5:1 | ✅ AA (대형 텍스트) |
| `#1A1A1A` on `#FFC107` | 8.6:1 | ✅ AAA |
| `#FFFFFF` on `#4CAF50` | 2.9:1 | ⚠️ 대형 텍스트만 AA |
| `#FFFFFF` on `#388E3C` | 4.5:1 | ✅ AA |
| `#1A1A1A` on `#FFFFFF` | 16.7:1 | ✅ AAA |

> **주의**: `yellow-500(#FFC107)` 배경에 흰색 텍스트 사용 금지.  
> 노란 배경 위에는 반드시 `#1A1A1A` (다크) 텍스트 사용.
