## 1. 발표 핵심 원칙

| 원칙 | 설명 |
|------|------|
| **한 메시지** | "사진 한 장 → AI 판별 → 포인트 → 캠퍼스 전기료 절감"만 기억나게 |
| **문제 1분, 데모 2분** (5분 모드) | 통계·배경은 압축, **실제 화면/플로우**에 시간 투자 |
| **목표 vs 현재 구분** | BE AI 판별(Cloud Run) ✅, Kafka·GCS·admin reports API는 **미완** — FE mock UX는 3단계 진행 UI 시연용 |
| **숫자는 1~2개만** (5분 모드) | 예: "강의실 낭비 약 30%" 또는 "100개 강의실 기준 월 10만 원+" 중 택1 |
| **마지막 15초** | 서비스명 + 한 줄 + 데모 URL/GitHub |

**5분 압축 시 피할 것**: 기술 스택 나열 1분+, 팀원 이력 상세, 아키텍처 전체 설명  
**12분 풀 발표 시**: 30장 순서대로 진행, 슬라이드당 평균 20~25초
