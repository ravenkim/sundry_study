## 5.2.2. AI 판별 처리 흐름

사용자가 앱을 통해 제보 사진과 위치 전송 → 백엔드 수신 → AI 서버로 이미지 분석 요청 → 판별 결과(절약량, 낭비 여부)에 따라 백엔드에서 **포인트 즉시 적립** 및 데이터 저장.

```mermaid
sequenceDiagram
  participant Client as Student App
  participant BE as Spring Boot API
  participant AI as FastAPI Cloud Run
  participant YOLO as YOLOv8n
  participant Gemini as Gemini 2.5 Flash
  participant DB as MySQL

  Client->>BE: POST /api/reports (image + metadata)
  Note over BE: 운영시간·중복 검증 (AI 호출 전)
  BE->>AI: POST /analyze (image + operatingSchedules)
  AI->>YOLO: Step1 person/chair/desk
  alt person ≥ 1
    AI-->>BE: PASS (사용 중)
    BE-->>Client: 저장 안 됨
  else empty classroom
    AI->>YOLO: Step2 AC detect
    AI->>Gemini: Step3 ON/OFF + expected 계산
    Gemini-->>AI: ac_status, light_status, expected, expectedKwh
    AI-->>BE: WASTE_DETECTED (or PASS)
    BE->>DB: Report 저장 + MemberPoint 적립
    BE-->>Client: 결과 + pointAwarded
  end
```

## 5.2.3. AI 3단계 판별 로직

```
[클라이언트] 사진 업로드 + LocationNode LEAF 선택
    ▼
[Spring Boot] metadata: roomName, reportedAt, 자원 수량, operatingSchedules
    ▼
[1단계] YOLOv8n (conf=0.3, person/chair/desk)
    ├─ chair=0 AND desk=0 → ERROR (강의실 아님)
    ├─ person ≥ 1 → PASS (사용 중)
    └─ person = 0 ↓
[2단계] YOLOv8n Custom ac_best.pt (conf=0.4)
    ├─ 에어컨 미탐지 → [3단계 시나리오 B: 원본만]
    └─ 에어컨 탐지 → OpenCV 크롭 → [3단계 시나리오 A: 원본+크롭]
[3단계] Gemini 2.5 Flash
    ├─ operatingSchedules 참고 → 운영 외 시간대 판단
    ├─ ac_status=ON 또는 light_status=ON → WASTE_DETECTED
    │   └─ expected("N원"), expectedKwh("N kWh") 산출
    └─ 모두 OFF 또는 운영 중 → PASS
    ▼
[Spring Boot]
    ├─ WASTE_DETECTED → Report + estimated 필드 + MemberPoint 적립
    ├─ PASS / ERROR → 저장 안 함
    └─ AI 통신 실패 → INTERNAL_SERVER_ERROR (5003)
```

## 5.2.4. 데이터베이스 ERD

```mermaid
erDiagram
  Affiliation ||--o{ LocationNode : owns
  Affiliation ||--o{ Member : belongs
  LocationNode ||--o{ LocationNode : parent
  LocationNode ||--o{ Report : leaf_target
  LocationNode ||--o{ LocationOperatingSchedule : has_schedule
  Member ||--o{ Report : submits
  Member ||--|| MemberPoint : has
  Member ||--o{ GifticonExchange : requests
  Reward ||--o{ GifticonExchange : exchanged_to

  Affiliation {
    int id
    string name
    string address
  }

  LocationNode {
    int id
    int parent_id
    string name
    string nodeKind
    int depth
    int acCount
    int fluorescentCount
    int ledCount
  }

  LocationOperatingSchedule {
    int seq
    int location_node_seq
    int dayOfWeek
    boolean isClosed
    time powerOnTime
    time powerOffTime
  }

  Member {
    int id
    string email
    string userType
    int affiliation_id
  }

  Report {
    int id
    string status
    decimal estimated_kwh
    int estimated_savings_krw
    int estimated_point
    int point_awarded
  }

  MemberPoint {
    int id
    int balance
  }

  Reward {
    int seq
    string name
    int pointCost
  }

  GifticonExchange {
    int seq
    int pointUsed
    string status
  }
```

## 5.2.6. 주요 API 엔드포인트

| Method | Endpoint | 설명 | 인증 |
|--------|----------|------|------|
| POST | `/login` | 이메일 로그인 (BCrypt + JWT) | 없음 |
| POST | `/register` | 회원가입 | 없음 |
| GET | `/api/affiliations` | 소속 목록 | 없음 |
| GET | `/api/buildings` | 장소 트리 (LEAF `reportable` 포함) | 없음 |
| GET | `/api/points/me` | 포인트 잔액 | JWT |
| POST | `/api/points/exchange` | 포인트 교환 | JWT |
| GET | `/api/rewards` | 리워드 목록 | 없음 |
| POST | `/api/reports` | 제보 생성 + AI + 포인트 적립 | JWT |
| GET | `/api/reports/me` | 내 제보 목록 | JWT |
| GET | `/api/savings/buildings/me` | 건물별 절약량 | JWT |
| GET/PATCH/POST/DELETE | `/api/admin/location-nodes/*` | 장소 CRUD | JWT · ADMIN |
| GET/PATCH | `/api/admin/reports` | 관리자 제보 목록·상태 변경 | JWT · ADMIN |
| GET | `/api/admin/dashboard` | 월간 절감 대시보드 | JWT · ADMIN |
| GET | `/api/admin/stats` | 통계 집계 | JWT · ADMIN |
| GET/PATCH | `/api/admin/gifticon-exchanges/*` | 기프티콘 교환 관리 | JWT · ADMIN |
| POST | `/analyze` | AI Service (Cloud Run) | — |
