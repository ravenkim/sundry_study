# 1. 팀 소개

> **14팀** — 2026 두유톤 해커톤  
> **팀원**: 김해준, 차성호, 이은총  
> AI를 활용한 지속 가능한 환경 및 생활 문제 해결 서비스

---

## 김해준 — 기획 총괄 · 프론트엔드 · UI/UX · 백엔드 연동 · 인프라

**역할**
- 서비스 기획 총괄: 아이디어 선정, 기능 정의서, 사용자 시나리오, 와이어프레임, API 명세 작성
- React 프론트엔드 전체 개발 (홈, 제보 플로우, 이력, 포인트샵, 관리자 화면)
- 회원가입·소속 선택·프로필·약관 등 사용자 흐름 전반 구현
- 백엔드 API 연동 및 상태 관리 (Redux Toolkit + redux-saga)
- Docker Compose 기반 통합 배포 환경 구성 및 학교 서버 인프라 구축
- 발표 자료 초안 제작 및 프로젝트 문서 관리

**기여**
- 서비스의 전체 흐름을 설계하고, 기획부터 배포까지 전 영역을 주도적으로 완성했습니다.
- 프론트엔드 코드베이스 대부분을 단독으로 작성하며, 사용자 경험 중심의 UI를 구현했습니다.
- 팀 전체가 사용하는 개발 기준 문서와 환경 설정을 정비해 협업 효율을 높였습니다.
- 보안·배포·인프라 이슈를 선제적으로 파악하고 해결해 안정적인 운영 기반을 마련했습니다.

---

## 차성호 — 백엔드 개발

**역할**
- Spring Boot REST API 설계 및 구현
- 회원·제보·장소·리워드·기프티콘·절약량 API 구현
- DB 스키마 및 JPA 엔티티 설계·구현

**기여**
- 서비스 핵심 도메인 전체를 엔티티로 모델링하고 REST API로 구현했습니다.
- FE 화면 흐름에 맞춰 API 응답을 조율하고 DB 스키마를 직접 검증했습니다.

---

## 이은총 — AI · 백엔드 · 인프라

**역할**
- AI 모델 학습·배포 (YOLOv8n, Gemini Vision)
- FastAPI AI 서비스 Cloud Run 배포 및 BE 연동
- MySQL 서버 구축, Kafka 포인트 비동기 처리 코드
- 학교 IT팀 협조 및 해커톤 운영 지원
- 발표 자료 마무리, 프로젝트 문서 다듬기

**기여**
- 이미지 분류 AI 모델을 직접 학습하고 클라우드에 배포해 서비스의 핵심 기능을 완성했습니다.
- AI와 백엔드 간 데이터 파이프라인을 설계하고 서버 인프라 구축을 주도했습니다.

## 팀의 강점

1. **전 영역 커버**: 기획·FE·BE·AI·인프라를 3인이 분담해 빠르게 동작하는 서비스를 완성
2. **기획과 구현의 일체**: 기획자가 직접 코드를 작성해 설계 의도가 화면에 그대로 반영됨
3. **AI + 백엔드 시너지**: AI 분석 결과가 실시간으로 포인트·절약량 데이터로 이어지는 파이프라인 완성
4. **실용주의**: 데모 가능한 P0 기능에 집중하고, P1/P2는 로드맵으로 분리해 완성도 확보
