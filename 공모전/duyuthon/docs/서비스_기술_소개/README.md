# 에코리포트 서비스 & 기술 소개 문서

> **2026 두유톤 해커톤 | 14팀**  
> AI 기반 캠퍼스 에너지 낭비 제보 및 보상 플랫폼

**한 줄 소개**: 빈 강의실에 켜진 전등 사진 한 장 → AI 분석 → 포인트 적립. 학생의 작은 제보가 학교 전기료를 줄이고, 그 절약분을 학생에게 돌려주는 선순환 구조.

---

## 구현 범위 요약

| 구분 | 상태 | 비고 |
|------|------|------|
| 사용자 UI | ✅ | 홈·제보·이력·포인트샵·마이페이지·관리자 전 화면 |
| 이메일 회원가입/로그인 | ✅ | BCrypt + JWT, 소속 선택 후 가입 |
| Google OAuth | ✅ | OAuth2 Resource Server + `/oauth/callback` |
| AI 3단계 파이프라인 | ✅ | YOLOv8n → YOLOv8n Custom → Gemini 2.5 Flash |
| 제보·포인트·절약량 | ✅ | Cloud Run 연동, 즉시 적립, 건물별 집계 |
| 장소 관리 + 운영 스케줄 | ✅ | 3단 컬럼 UI + `location_operating_schedule_db` |
| 리워드·기프티콘 교환 | ✅ | 교환 신청·관리자 승인 |
| 관리자 제보·대시보드 | ✅ | `/api/admin/reports`, `/api/admin/dashboard` |
| 한전 전기 단가 동기화 | ✅ | `ElectricityTariffService`, 월별 `unitCost` |
| 운영 배포 | ✅ | `ubuntu03` Docker Compose + GCP Cloud Run (AI) |
