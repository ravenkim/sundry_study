## 5.3.6. 개발 환경

### IDE (교차 검증)

| 도구 | 용도 |
|------|------|
| **Antigravity** | AI 기반 개발 보조, 코드 생성·리뷰 |
| **Cursor** | AI 페어 프로그래밍, 에이전트 기반 코드 수정 |
| **VS Code** | 범용 경량 에디터 |
| **IntelliJ IDEA** | Spring Boot 백엔드 개발·디버깅 |
| **WebStorm** | React/TypeScript 프론트엔드 개발·디버깅 |

### AI 코딩 도구

| 도구 / 모델 | 주요 활용 |
|-------------|----------|
| **Composer 2.5** (Cursor) | 멀티파일 편집, 기능 단위 구현 |
| **Claude** | 아키텍처 설계 검토, 문서 작성 |
| **Gemini CLI** | 터미널 기반 빠른 질의, 스크립트 작성 |
| **GPT** | 대안 구현 제안, API 명세 정리 |

### 디자인 도구

| 도구 | 역할 |
|------|------|
| **Stitch** (Google) | 화면 와이어프레임·UI 시안 |
| **VinSign** | 시각 디자인·브랜딩 |
| **Google AI Studio** | 시안 → React + Tailwind 코드 변환 |

브랜드 컬러: Volt Yellow `#FFC107`, Eco Green `#4CAF50` — [디자인_가이드.md](../디자인/디자인_가이드.md)

### 로컬 개발 명령

```bash
# 통합 배포 (MySQL + AI + BE + FE)
bash deploy.sh

# FE 개발 서버 (포트 5173)
cd fe && yarn dev

# BE 테스트
cd be && ./gradlew test
```

## 5.3.7. 운영 서버 사양

| 항목 | 값 |
|------|-----|
| **호스트명** | `ubuntu03` |
| **OS** | Ubuntu 24.04.3 LTS |
| **커널** | Linux 6.8.0-106-generic |
| **CPU** | Intel Core i7-7700 @ 3.60GHz (4C/8T) |
| **RAM** | 31 GiB |
| **스토리지** | NVMe 232.9 GB (사용률 ~10%) |

### Docker 컨테이너 (운영 중)

| 컨테이너 | 이미지 | 포트 | 역할 |
|----------|--------|------|------|
| `ecoreport-fe` | `duyuthon-fe` | `8081 → 80` | FE (nginx) |
| `ecoreport-be` | `duyuthon-be` | `8080 → 8080` | BE (Spring Boot) |
| `ecoreport-mysql` | `mysql:8.4` | 3306 (내부) | MySQL `energy_db` |

### AI FastAPI (GCP Cloud Run)

| 항목 | 값 |
|------|-----|
| 리전 | `us-central1` |
| 엔드포인트 | `POST /analyze` |
| 메모리 | 2 GiB |
| 모델 | `models/ac_best.pt` |
| BE 연동 | `CAMPUS_AI_API_URL` (`.env`) |

### 접속 URL

| 서비스 | URL |
|--------|-----|
| 프론트엔드 | `http://<DEPLOY_PUBLIC_HOST>:8081` |
| 백엔드 API | `http://<DEPLOY_PUBLIC_HOST>:8080` |
| Swagger UI | `http://<DEPLOY_PUBLIC_HOST>:8080/swagger-ui.html` |
| 헬스 체크 | `http://<DEPLOY_PUBLIC_HOST>:8080/actuator/health` |

### 환경 변수 (`.env`)

| 변수 | 용도 |
|------|------|
| `MYSQL_*`, `SPRING_DATASOURCE_*` | DB 연결 |
| `JWT_SECRET` | JWT HS256 서명 |
| `GOOGLE_CLIENT_ID/SECRET` | Google OAuth2 |
| `CAMPUS_AI_API_URL` | Cloud Run `/analyze` |
| `KEPCO_API_KEY` | 한전 전기 단가 API |
| `VITE_API_HOST` | FE API baseURL (빌드 타임) |
| `DEPLOY_PUBLIC_HOST` | 학교 서버 공개 IP |
