### 아키텍처 특징

- **파일 기반 자동 라우팅**: `src/pages/url/` → `router.tsx` 자동 등록
- **모바일 우선 UI**: 최대 너비 390px, 하단 탭 5개
- **Redux Toolkit + redux-saga**: slice·saga를 `reduxStore.tsx`에 등록
- **Axios**: `src/globals/api/client.tsx`, JWT `Bearer` 자동 첨부
- **TailwindCSS v4** + **shadcn/ui** + **Pretendard**
- **i18next**: 한국어/영어 locale (`ko/en`)

### 제보 플로우 (핵심)

1. `ReportCriteriaGuide` — AI 판별 3조건 + 촬영 가이드 확인
2. 카메라·갤러리 촬영
3. `GET /api/buildings` — `reportable: true`·`alreadyReported: false` LEAF만 표시
4. `POST /api/reports` — BE 운영시간·중복 검증 → AI → 포인트 적립
5. `/report-success` — 절약 금액·전기량·적립 포인트 표시

### 관리자 장소 관리

- 모듈: `fe/src/features/admin/buildings/`
- 3단 컬럼(1·2·3단계 GROUP/LEAF) + Sheet CRUD
- API: `locationNodesApi.ts` — **mock fallback 없음**, BE 실연동 전용

## 5.3.2. Back-End

### 레이어드 아키텍처

```
Controller → Service(인터페이스+구현체) → Repository → Entity
```

- **응답 규격**: `ApiResponse<T>` (성공) / `ApiErrorResponse` (실패) + `ControllerAdvice`
- **인증**: JWT HS256, Google OAuth2, `AdminAuthorizationHelper`

### ReportService (제보 핵심)

| 단계 | 처리 |
|------|------|
| 사전 검증 | `isReportableAt()` — 운영 중 → `INVALID` |
| 중복 검증 | `existsByMember_SeqAndLocationNode_Seq` → `ALREADY_EXISTS` (2004) |
| AI 호출 | Cloud Run `POST /analyze` + metadata |
| `WASTE_DETECTED` | `estimatedSavingsKrw`·`estimatedKwh`·`estimatedPoint` 저장 + `MemberPoint` 적립 |
| `PASS`/`ERROR` | 저장 거부 (`BusinessLogicException`) |
| AI 실패 | `INTERNAL_SERVER_ERROR` (5003) |

### 전기 단가 동기화

- `ElectricityTariffService`: 한전 OPEN API → `electricity_tariff_db`
- 앱 기동 시 + 매월 5일 03:00 동기화
- API 키 미설정·실패 시 **130원/kWh** fallback

### 포인트·교환

- `RewardService.exchange()`: 잔액 확인 → 차감 → `GifticonExchange` PENDING
- 관리자: `COMPLETED`/`CANCELLED` + `processedAt` 기록
