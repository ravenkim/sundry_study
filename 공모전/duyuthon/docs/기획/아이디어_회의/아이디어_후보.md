## 후보 1. 냉장고 재료 기반 AI 레시피 + 식품 낭비 최소화

**핵심 기능**
- 냉장고 사진 또는 재료 목록 입력 → AI가 소비 기한 임박 재료 우선 레시피 추천
- 음식물 쓰레기 절감

**데이터 확보**
- 사용자가 직접 촬영/입력 → 별도 외부 DB 불필요
- 공개 레시피 데이터셋 다수 존재 (만개의레시피 등)

**수익 모델**
- 프리미엄 구독 (상세 영양 분석, 맞춤 식단)
- 식품 브랜드 파트너십 (재료 구매 연결)

## 후보 2. 중고거래 물건 상태 AI 자동 평가

**핵심 기능**
- 중고 물품 사진 업로드 → AI가 상태를 등급화하고 적정 가격 추천
- 자원 순환 촉진

**데이터 확보**
- 번개장터·당근마켓 공개 매물 이미지로 학습 가능
- 사진 기반 → 사용자 데이터 확보 쉬움

**수익 모델**
- 중고 플랫폼(당근·번개장터)에 API 공급 (B2B SaaS)
- 개인 판매자 대상 프리미엄 평가 리포트

---

## 후보 3. 기업 ESG 리포트 AI 요약 & 비교 서비스

**핵심 기능**
- 복잡한 ESG 보고서를 AI가 요약·시각화
- 기업 간 환경 성과 비교 → 투자자·소비자 정보 제공

**데이터 확보**
- 국내 상장사 ESG 보고서 전부 공개 PDF → 즉시 수집 가능
- 한국거래소·지속가능경영원 공개 데이터 활용

**수익 모델**
- ESG 분석 리포트 B2B 구독 (운용사, 기관투자자 대상)
- 기업 ESG 자가진단 서비스 (B2B)

## 후보 4. AI 가전 자가진단 및 부품 매칭

**핵심 기능**
- 가전제품 작동 소음 or 외관 사진 → AI가 고장 원인 진단
- 단종 부품은 3D 프린팅 도면 연결 or 중고 부품 시장 연결
- 초보자 AR 수리 가이드 생성

**데이터 확보**
- 가전 고장음 데이터: 유튜브·커뮤니티 공개 영상으로 수집 가능
- 부품 DB: 제조사 공개 서비스 매뉴얼 + 중고나라 크롤링

**수익 모델**
- 수리 전문가 매칭 중개 수수료
- 중고 부품 거래 플랫폼 연계 커미션
- 가전 제조사·보험사 B2B (자가진단 API)

**기술 포인트**
- 소리 분석 AI (이상 징후 포착) + 멀티모달 AI (수리 가이드 생성)
- 순환 경제 가치: 새 제품 소비 대신 수리·재사용 촉진

## 후보 5. 한국 환경 법령 RAG 서비스

**핵심 기능**
- 환경·폐기물 관련 법령을 RAG로 구축해 질의응답
- Gemini API 활용

**데이터 확보**
- GitHub 공개 한국 법 레포, 국가법령정보센터 공개 API → 즉시 활용 가능

**수익 모델**
- 환경 컨설팅사·중소기업 법령 준수 검토 B2B 구독
- 지자체·공공기관 납품
