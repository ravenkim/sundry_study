## 후보 아이디어

### 1. 자취생 냉장고 관리
**트렌드**: 자취 대학생 증가, 1인 가구 음식 낭비 문제  
**핵심 기능**: 냉장고 재료 입력 → AI가 소비기한 임박 재료 우선 레시피 추천 + 장보기 계획 최적화  
**환경 연결**: 식재료 낭비 최소화  
**데이터**: 유저 직접 입력

---

### 2. 중고 패션 스타일 큐레이션
**트렌드**: 빠른 패션 소비 + 빈티지/중고 패션 유행  
**핵심 기능**: 내 스타일 사진 업로드 → AI가 공개 중고 매물 중 취향 아이템 추천  
**환경 연결**: 새 옷 소비 대신 중고 패션 순환  
**데이터**: 유저 업로드 + 공개 중고 매물 크롤링

---

### 3. 카페 텀블러 인증 리워드
**트렌드**: 카페 매일 가는 대학생 문화  
**핵심 기능**: 텀블러 사용 인증 → 절감량 트래킹 ("이번 달 일회용 컵 12개 줄임") + 리워드/뱃지  
**환경 연결**: 일회용 컵 사용 감소  
**데이터**: 유저 직접 인증

---

### 4. 여행 탄소발자국 플래너
**트렌드**: 여행 좋아하는 대학생, 방학 여행 계획  
**핵심 기능**: 여행 경로 입력 → AI가 탄소발자국 계산 + 친환경 대안 제시 (기차 vs 비행기, 대중교통 vs 렌터카)  
**환경 연결**: 여행 탄소 배출 감소  
**데이터**: 유저 직접 입력 (공개 탄소 배출 계수 활용)

---

### 5. 친환경 챌린지 SNS
**트렌드**: 인증/챌린지 SNS 문화  
**핵심 기능**: AI가 개인 생활패턴 기반 맞춤 친환경 챌린지 추천 → 인증 → 랭킹/뱃지로 게이미피케이션  
**환경 연결**: 친환경 행동 습관화  
**데이터**: 유저 생성 콘텐츠

---

### 6. 졸업 시즌 물품 나눔
**트렌드**: 졸업 시즌 대형 폐기물 문제  
**핵심 기능**: 졸업생이 남기는 가구/가전/교재를 AI가 후배와 자동 매칭 ("컴공 3학년에게 필요한 물품" 예측)  
**환경 연결**: 멀쩡한 물건 폐기 방지, 자원 순환  
**데이터**: 유저 간 직거래

---

### 7. 대학 교재/물품 순환 플랫폼
**트렌드**: 비싼 교재, 한 학기만 쓰고 버리는 문제  
**핵심 기능**: 학교/학과 기반으로 필요한 교재 보유자와 AI 매칭 (기존 중고 플랫폼은 위치 기반)  
**환경 연결**: 교재 폐기 감소, 자원 순환  
**데이터**: 유저 간 직거래

---

### 8. 캠퍼스 탄소발자국 트래커
**트렌드**: MZ세대 환경 관심 증가  
**핵심 기능**: 통학 방법, 식단, 소비 습관 입력 → 개인 탄소발자국 계산 + AI 맞춤 절감 팁  
**환경 연결**: 개인 탄소 배출 감소  
**데이터**: 유저 직접 입력 (자취/기숙사/통학 유형별 비교)

---

### 9. 술 취향 추천 → 주류 낭비 감소
**트렌드**: 대학생 음주 문화, 홈술 증가  
**핵심 기능**: 취향(단맛/쓴맛, 도수, 가격대 등) 입력 → AI가 잘 맞을 술 추천  
**환경 연결**: 안 맞는 술 사서 버리는 낭비 감소, 로컬 수제맥주 추천으로 운송 탄소 절감  
**데이터**: 유저 직접 입력
