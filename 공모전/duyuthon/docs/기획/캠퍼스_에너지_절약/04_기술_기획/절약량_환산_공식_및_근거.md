# 절약량 환산 공식 및 근거

> 에코리포트에서 **절약 전기량(kWh) · 절약 탄소량(kg CO₂) · 소나무 흡수량 환산(그루)** 을 계산할 때 사용하는 상수·공식과 공식 출처를 정리한다.  
> 구현 위치: BE `EnergyConstants`, `SavingsCalculationService`, `AdminReportSupport` / FE `userSavingsData.ts`

---

## 1. 요약 — 서비스에서 쓰는 공식

| 지표 | 공식 | 코드 상수 |
|------|------|-----------|
| **절약 전기량** | `kWh = Σ(소비전력 W × 수량 / 1000 × 방치 시간 h)` (AI가 ON으로 판별한 자원만) | 형광등 40W, LED 20W, AC 1500W |
| **절약 금액** | `절약_원 = kWh × unit_cost` | DB `electricity_tariff_db.unit_cost_krw` (한전 API 월별) 또는 fallback `ELECTRICITY_RATE_KRW = 130` |
| **절약 탄소량** | `CO₂(kg) = kWh × 0.4594` (소수 1자리 반올림) | `CO2_KG_PER_KWH = 0.4594` |
| **소나무 환산** | `그루 = round(kWh / 20.25)` (kWh ≤ 0 이면 0) | `KWH_PER_TREE = 20.25` |
| **포인트** | `point = round(절약_원 × 0.18)` | `POINT_RATE = 0.18` |

집계 UI(홈·마이페이지)에서는 API가 내려준 **누적·이번 달 kWh**에 위 탄소·나무 공식을 FE에서 적용한다.

## 2. 절약 전기량 (kWh)

### 2.1 공식

Phase 1(현재) 기본 전력 상수와 방치 시간을 곱해 산출한다. 자세한 자원·스케줄 정의는 [자원_관리_설계.md](./자원_관리_설계.md) §Phase 1 참고.

```
kWh_자원 = (W × quantity / 1000) × off_time_hours
총 kWh = Σ (AI·판별 결과가 ON인 자원만)
```

- **off_time_hours**: 제보 시각 ~ 해당 요일 `power_off`까지(휴무·소등 후), 상한 **120분** (`OFF_TIME_CAP_MINUTES`)
- 제보 플로우: Gemini가 `expectedKwh` 문자열로 산출 → BE 저장  
- 검증·Phase 2: `SavingsCalculationService` 동일 상수로 재계산

### 2.2 소비전력(W) 상수 근거

| 자원 | 상수 | 근거·참고 |
|------|------|-----------|
| 형광등 | 40 W | 일반 **F32(32W)·F40(40W)급** 형광램프 + 안정기 손실을 포함한 강의실 천장등 **대표값**. 실제 램프는 18~40W대이며, 에너지효율등급·교체 시기에 따라 달라짐. |
| LED 조명 | 20 W | 동일 조도 대비 형광등 대비 **약 50% 전력** 수준의 LED 교체 사례를 단순화한 MVP 대표값 (40W→20W). |
| 에어컨 | 1500 W | **벽걸이형 냉방 7~9㎡급** 제품의 정격 소비전력(약 1.2~1.8kW) 중간값. 실제는 실외기·설정온도·부하에 따라 변동. |

**참고 자료 (소비전력·조명)**

- 산업통상자원부 **에너지소비효율등급 및 최소소비효율기준** (가전·조명 제품군별 정격 소비전력 공시)
- 한국에너지공단 **에너지효율 Label** — [에너지소비효율등급 제품 정보](https://eep.kemco.or.kr/)
- LED 조명 보급·절감 효과: IEA *Energy Efficiency 2023* — 조명 부문 LED 전환에 따른 단위 서비스당 전력 절감 사례 (국가별 정책 보고서)

> MVP에서는 방별 실측 W 대신 **고정 상수**를 쓴다. Phase 2 `LocationResource.custom_value`로 교체 예정.

### 2.3 전기 단가 (원/kWh)

| 항목 | 내용 |
|------|------|
| **운영 (현재)** | 한전 **전력데이터개방포털** OPEN API → 계약종별 **평균판매단가(`unitCost`)** 를 **월별** DB 저장 후 절약 금액에 사용. 상세: [전기_단가_동기화.md](./전기_단가_동기화.md) |

## 3. 절약 탄소량 (kg CO₂)

### 3.1 공식

```
절약_CO₂(kg) = 절약_kWh × CO2_KG_PER_KWH
             = 절약_kWh × 0.4594
```

- BE: `AdminReportSupport.co2KgFromKwh()` — 소수 **1자리** 반올림  
- FE: `getCo2KgFromKwh()` — 동일 계수·반올림

### 3.2 배출계수 0.4594 kg CO₂/kWh 근거

| 항목 | 내용 |
|------|------|
| 값 | **0.4594 tCO₂eq/MWh = 0.4594 kg CO₂/kWh** |
| 명칭 | 전력 **국가고유(indirect) 배출계수** — 전력 사용(Scope 2)에 전력 생산 단계 배출을 할당한 계수 |
| 적용 구간 | EG-TIPS 기준 **2017년~** 현행 국가고유 계수로 안내 (2011~2017: 0.4585) |
| 산정 주체 | **한국전력거래소(KPX)** 전력배출계수 → 환경부 **온실가스 배출권거래제** 지침 [별표 6]에 수록 |

**법·지침·공식 출처**

1. 환경부 고시 **「온실가스 배출권거래제의 배출량 보고 및 인증에 관한 지침」** (환경부고시 제2021-10호 등) — 배출활동별 세부 산정방법, 전력배출계수 적용  
2. **EG-TIPS** (에너지·온실가스 종합정보 플랫폼) 온실가스 계산기 — 국가고유 전력 계수 FAQ: [tips.energy.or.kr Q&A](https://tips.energy.or.kr/qna/qna_view.do?no=1841)  
3. 기후에너지환경부 **연도별 전력배출계수** 공표 (2023년: 0.4173 tCO₂/MWh 등 — **매년 갱신**, 코드 상수는 해커톤 MVP 고정값)

> **주의:** 기획·발표 자료 일부는 반올림 설명용으로 **0.469 kg/kWh**를 쓴 적이 있다(600 kWh → 280 kg CO₂). **실제 코드·API는 0.4594**를 사용한다. 연도별 최신 계수로 바꿀 경우 BE `EnergyConstants`와 FE `userSavingsData.ts`를 함께 수정한다.

**국제 방법론 (Scope 2)**

- GHG Protocol *Corporate Standard* — Scope 2: 구매 전력의 간접 배출, **location-based** emission factor 사용 원칙  
- IPCC *2006 Guidelines* Vol.2 Energy — 전력 간접 배출은 국가 전력 mix 기반 계수 적용 (한국은 KPX·환경부 고시 값)

## 4. 소나무 흡수량 환산 (그루)

### 4.1 공식

```
소나무_그루 = round(절약_kWh / KWH_PER_TREE)
KWH_PER_TREE = 20.25
```

- kWh ≤ 0 → **0그루** (최소 1그루 강제하지 않음)
- UI: **이번 달 kWh** → 이번 달 CO₂·나무, **누적 kWh** → 누적 CO₂·나무

### 4.2 20.25 kWh/그루 도출

**① 산림청·탄소나무계산기 — 소나무 1그루 연간 CO₂ 흡수량**

| 출처 | 소나무 1그루 연간 CO₂ 흡수 |
|------|---------------------------|
| 산림청 **탄소나무계산기** (정책브리핑 안내) | **약 9.2 kg CO₂/년·그루** |
| 탄소나무계산기 FAQ | 1톤 CO₂ 상쇄 그루 수는 **「주요 산림수종의 표준탄소흡수량 ver.1.2」** 기반 (수종·지역·60년 누적 흡수량 등) |

- 탄소나무계산기: [carbonregistry.forest.go.kr](https://carbonregistry.forest.go.kr/fcr_web/resources/carbon_calc/html/main/CTC_02_01.html)  
- 정책 소개: [탄소나무 계산기로 알아보는 온실가스 배출량 (korea.kr)](https://www.korea.kr/news/policyNewsView.do?newsId=148908662)

**② 전력 절감 → CO₂ 절감 → “소나무 1그루 연간 흡수분” kWh 환산**

```
kWh_1그루 ≈ (소나무 연간 CO₂ 흡수 kg) / (전력 CO₂ 배출계수 kg/kWh)
          ≈ 9.2 / 0.4594
          ≈ 20.0 kWh
```

**③ 서비스 상수 20.25**

- 와이어프레임·디자인 검증 예: **243 kWh → 소나무 12그루** (`243 ÷ 12 = 20.25`) — [화면_설계_와이어프레임.md](../02_서비스_기획/화면_설계_와이어프레임.md), [디자인_가이드.md](../../../디자인/디자인_가이드.md)  
- 과학적 추정(~20.0)과 UI 검증치를 맞춘 **반올림·고정 상수**로 FE/BE 공통 사용

### 4.3 산림 탄소흡수 — 연구·국가 표준 근거

| 자료 | 내용 |
|------|------|
| **주요 산림수종의 표준 탄소흡수량 (ver. 1.2)** | 국립산림과학원 기후변화연구센터. 수종·수령별 ha당 연간 CO₂ 흡수·저장량 표준. [산림탄소등록부 PDF](https://carbonregistry.forest.go.kr/fcr_web/fco/spt/board/otherDataView.do?bbsId=BBSMSTR_000000000028&nttId=577) |
| **국토교통부 탄소공간지도** 산림 방법론 | `Vol × WD × BEF × (1+R) × CF × 44/12` — 표준탄소흡수량 ver.1.2 인용. [carbonmap.kr 방법론](https://carbonmap.kr/about/openMethodologyForest.do) |
| **국립산림과학원** 정책 자료 | 40년생 소나무림 ha당 연간 약 **7.19 tCO₂/ha** 흡수 등 수령별 차이 (면적 기준, 개체 1그루와 단위 다름). [산림청 정책자료실](https://www.forest.go.kr/newkfsweb/cop/bbs/selectBoardArticle.do?bbsId=BBSMSTR_1493&nttId=3052828) |
| **「산림 탄소흡수량 국가 표준」 개발** | 산림청·국립산림과학원, 20년+ 기후·산림 연구 총괄. [정책브리핑](https://www.korea.kr/briefing/policyBriefingView.do?newsId=148752686) |

> **한계:** “소나무 N그루”는 **국민 소통용 환산 지표**이며, 실제 조림·탄소상쇄 사업의 MRV(측정·보고·검증) 결과와 1:1 대응하지 않는다. 수종·지역·수령·벌채 주기에 따라 그루당 흡수량은 크게 달라진다.

## 5. 계산 예시 (서비스 UI 기준)

### 예시 A — 와이어프레임 검증치

| 입력 | 계산 | 결과 |
|------|------|------|
| 이번 달 절약 243 kWh | CO₂ = 243 × 0.4594 | **111.6 kg** |
| | 나무 = round(243 / 20.25) | **12그루** |

### 예시 B — 제보 1건 (형광등 10 + AC 1, 2시간 방치)

| 자원 | kWh | 금액(130원) |
|------|-----|-------------|
| 형광등 10×40W×2h | 0.8 | 104원 |
| AC 1×1500W×2h | 3.0 | 390원 |
| **합계** | **3.8** | **494원** |

- CO₂: 3.8 × 0.4594 ≈ **1.7 kg**  
- 나무: round(3.8 / 20.25) = **0그루** (1그루 미만은 반올림 0)

### 예시 C — 절약 0

| kWh | CO₂ | 나무 |
|-----|-----|------|
| 0 | 0 kg | 0그루 |
