## 2. 최종 선정 아이디어: 캠퍼스 조명/공조 최적화

> 빈 강의실의 켜진 조명·에어컨 등 불필요한 에너지 낭비를 학생 크라우드소싱으로 제보하고 포인트를 지급하는 서비스

### 핵심 플로우
1. 사용자가 빈 강의실의 켜진 조명/에어컨 사진을 앱에 업로드
2. AI가 이미지를 분석하여 낭비 상태 판단 및 위치 파악
3. 관리자(건물주) 페이지에 리포트 전달
4. 제보한 사용자에게 포인트(기프티콘 교환 가능) 지급

### 비즈니스 모델
- **건물주** → 절약된 전기료의 일부를 플랫폼에 지급
- **플랫폼** → 그 중 10%를 수수료로 취득
- **사용자** → 나머지 90%를 포인트로 정산 → 기프티콘 등으로 교환

### 추가 기능 아이디어 (차성호)
- 수업 시간표 데이터 연동 → 강의실 예약 여부 자동 확인
- 학교 강의실 대여 시스템과 연결

### 악의적 사용 방지 과제
- 조명을 일부러 켜고 사진 찍는 어뷰징 방지 방법 필요 (미해결)

## 3. AI 활용 방향

- 이미지 분석: 켜진 조명/에어컨 여부 판별
- 절약량 계산: 꺼짐 등록 시간 기반으로 월 절약 전기료 산출
- 패턴 학습: 켜짐/꺼짐 패턴을 학습하여 자동 제어 시스템 구축 (자동화는 데모 시연이 어렵다는 의견으로 우선순위 후순위)
- **1차 목표**: 사용자가 직접 끄거나 제보하면 포인트 지급하는 구조
