## 논의된 아이디어

### A. 재활용 LLM 챗봇 (단기 완성 위주)
- 분리수거·재활용이 애매한 물건을 LLM에게 질문
- 구현 난이도 낮고 빠른 완성 가능
- 확장 방향: 산업 폐유 등 법률 관련 RAG 구축

### B. 한국 법률 RAG 기반 환경 법령 서비스
- GitHub에 공개된 한국 법 레포 활용
- 환경·폐기물 법령을 RAG로 구축해 질의응답
- 기술적 난이도 있지만 차별성 높음
- 이은총·김해준 긍정적 반응

### C. 통계청 API + AI 정책 제안
- 통계청 API로 사회/환경 통계 수집
- AI가 문제를 분석해 정책 제안 생성
- 비영리 vs 영리 방향성 먼저 정해야 구체화 가능

## 팀원 의견 요약

- **이은총**: 수상 확률을 높이려면 건강, 장애인, 사회적 약자에게 도움이 되는 서비스 방향 유효. 아이디어 참신함이 핵심.
- **김해준**: 사용 가능한 공공 데이터(통계청 API, 한국 법 레포)를 적극 활용 추천. 방향성(비영리/영리)을 먼저 확정해야 구체화 가능.
- **차성호**: 기술 방향에 동의, 세부 논의 대기 중.
