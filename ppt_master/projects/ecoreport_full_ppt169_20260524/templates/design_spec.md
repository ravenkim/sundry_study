## I. 템플릿 개요

| 속성       | 설명                                                |
| -------------- | ---------------------------------------------------------- |
| **템플릿 이름** | google_style (구글 스타일)                    |
| **용도**  | 연간 업무 보고, 기술 공유, 프로젝트 전시, 데이터 중심 발표 |

## V. 페이지 구조

### 일반 레이아웃

| 영역               | 위치/높이 | 설명                            |
| ------------------ | --------------- | -------------------------------------- |
| **상단 장식 바** | y=0, h=6px  | 4색 그라데이션 바, 전폭 |
| **제목 영역**     | y=50, h=60px    | 페이지 제목 + 제목 언더라인           |
| **본문 영역**   | y=130, h=500px  | 메인                      |
| **푸터**         | y=660, h=60px   | 4색 도트 장식 + 선택 페이지 번호 |

### 시그니처 디자인 요소

#### 1. 상단 4색 그라데이션 바
```
linearGradient: #4285F4 → #EA4335 → #FBBC04 → #34A853
높이: 6px, 너비: 100%
```

#### 2. 제목 언더라인(4색 세그먼트)
```
블루: 150px → 레드: 70px → 옐로: 70px → 그린: 170px
stroke-width: 4px, 제목 아래 y: 20px
```

#### 3. KPI 데이터 카드
```
크기: 280×140px
모서리 반경: 16px
테두리: 3px, 해당 브랜드 컬러
그림자: 은은한 깊이감
```

#### 4. 4색 도트 장식
```
푸터 또는 구분선에 사용
반경: 6-14px(가변)
간격: 30-50px
```

#### 5. 좌측 4색 세로 바
```
표지 전용
너비: 10px, 4구간 각 180px
색 순서: 블루 → 레드 → 옐로 → 그린
```

## VI. 페이지 유형

### 1. 표지(01_cover.svg)

- 밝은 그라데이션 배경(흰→연블루·연그린)
- 좌 4색 세로 바
- 중앙 둥근 흰 콘텐츠 카드(은은한 그림자)
- 그라데이션 메인 제목 + 부제
- 4색 분할 구분선
- 발표자(이름, 직함, 날짜)
- 하단 4색 도트

### 2. 목차(02_toc.svg)

- 흰 배경 + 상단 4색 그라데이션 바
- 페이지 제목 + 블루 언더라인
- 챕터 목록(좌 브랜드 컬러 도트 + 번호 + 제목)
- 선택: 우측 장식 그래픽 또는 통계

### 3. 챕터(02_chapter.svg)

- 다크 그라데이션(딥 블루→더 짙은 블루)
- 큰 챕터 번호(그라데이션 또는 흰색)
- 챕터 제목(흰, 큰 글자)
- 영문 부제(흰, 반투명)
- 4색 장식 요소

### 4. 본문(03_content.svg)

- 흰 배경
- 상단 4색 그라데이션 바
- 페이지 제목 + 블루 언더라인
- 유연한 본문(다중 레이아웃)
- 하단 4색 도트

### 5. 맺음(04_ending.svg)

- 밝은 그라데이션 배경
- 중앙 둥근 흰 카드
- 그라데이션 감사 제목
- 4색 구분선
- 감사 목록(브랜드 컬러 도트 + 항목)
- 맺음말 + 하단 4색 도트

## IX. SVG 기술 제약

### 필수 규칙

1. viewBox: `0 0 1280 720`
2. 배경은 `<rect>`
3. 줄바꿈 `<tspan>` (`<foreignObject>` 없음)
4. 투명도 `fill-opacity` / `stroke-opacity`
5. `<defs>` 내 `<linearGradient>`로 그라데이션 정의

### 금지 요소

PPT 비호환 SVG 기능:

- `clipPath`, `mask`
- `<style>`, `class`
- `foreignObject`
- `textPath`
- `animate*` 애니메이션
- `script`
- `rgba()` — HEX + 불투명도 속성으로 대체

> `marker-start` / `marker-end` 조건부 허용 — `shared-standards.md` 1.1절.

### 그림자 구현

`filter`가 PPT 호환에 영향을 줄 수 있음:
- 미세 테두리 색 변화로 그림자 시뮬
- 또는 구버전 PPT에서 무시될 수 있으나 신버전에서는 `filter`가 잘 동작하는 경우 수용

## XII. 사용 안내

1. 템플릿을 프로젝트 `templates/`에 복사
2. 내용에 맞는 페이지 유형 선택
3. 교체할 내용은 플레이스홀더로 표시
4. 구글 브랜드 4색 체계를 엄격히 준수
5. 넉넉한 여백으로 핵심 정보 강조
6. 데이터 주도: 큰 숫자 + 작은 라벨로 KPI 표현
