# 01_표지

안녕하세요, 저희는 14팀으로 EcoReport를 발표하게 된 김해준, 차성호, 이은총입니다. [멈춤] 오늘 소개할 EcoReport는 캠퍼스 빈 강의실의 에너지 낭비를 학생이 직접 사진으로 제보하면, AI가 판별하고 포인트를 지급하는 크라우드소싱 플랫폼입니다.

핵심 포인트: ① 빈 강의실 사진 한 장 ② AI 자동 판별 ③ 포인트 즉시 적립
소요 시간: 0.3분

# 03_문제정의

[전환] 먼저 왜 이 문제를 해결하려 했는지부터 말씀드리겠습니다. 캠퍼스 강의실의 에너지 비용 중 약 30%가 빈 공간에서 낭비된다는 추정이 있습니다. 100개 강의실 기준으로 월 10만 원 이상이 조명과 에어컨 방치로 불필요하게 지출되는 거죠. [멈춤] 기존에도 해결 시도는 있었습니다. IoT 센서는 수천만 원이 들고, 관리인 순찰은 야간에 공백이 생기고, 포스터 캠페인은 효과 측정조차 어렵습니다. 세 가지 모두 지속 가능성이 낮아요. 저희가 세운 가설은 단순합니다. 합리적인 보상이 있으면, 학생은 자발적으로 에너지 낭비를 제보한다는 것입니다.

핵심 포인트: ① 교내 에너지의 30% 빈 공간 낭비 ② 기존 해결책 3가지 한계 ③ 보상 기반 자발 제보 가설
소요 시간: 0.9분

# 04_솔루션

[전환] 저희 솔루션의 핵심은 세 가지 축의 결합입니다. 크라우드소싱, AI 자동 판별, 그리고 포인트 보상이죠. IoT와 비교해 보면, IoT는 수천만 원의 초기 투자와 6개월 이상의 구축 기간이 필요하지만, EcoReport는 설비 투자 없이 즉시 도입할 수 있습니다. [멈춤] 구조는 선순환입니다. 학생이 사진을 제보하면, AI가 5초 이내에 낭비를 판별하고, 포인트가 즉시 적립되고, 그 절약분이 다시 포인트 재원으로 순환됩니다. AI는 YOLOv8n으로 가구·사람을 탐지하고, 커스텀 모델로 에어컨을 찾고, Gemini 2.5 Flash로 최종 ON/OFF 상태를 판별하는 3단계 파이프라인입니다.

핵심 포인트: ① 설비 투자 없이 즉시 도입 ② 학생 포인트 보상 기반 자발 참여 ③ AI 3단계 선순환 구조
소요 시간: 0.8분

# 05_핵심기능

[전환] 핵심 기능 세 가지를 보여드리겠습니다. 첫째, AI 이미지 분석입니다. 사진 한 장을 업로드하면 3단계 파이프라인이 5초 이내에 낭비 여부를 판별합니다. Cloud Run에 배포되어 BE와 실제 연동 완료 상태입니다. 둘째, 제보와 포인트 정산입니다. 낭비가 확인되면 포인트가 즉시 적립되고 기프티콘으로 교환할 수 있습니다. 셋째, 관리자 대시보드입니다. 6개 화면으로 구성되어 제보·통계·포인트·장소 관리까지 모두 BE와 연동 완료했습니다. [멈춤] 학생 UI 9화면, 관리자 UI 6화면, 총 15개 화면이 구현 완료된 상태입니다.

핵심 포인트: ① AI Cloud Run 연동 완료 ② 포인트 적립·교환 플로우 ③ 15화면 풀 구현
소요 시간: 1.0분

# 06_서비스플로우

[전환] 실제 사용 흐름을 보여드리겠습니다. 시나리오는 공학관 A동 303호에서 수업이 끝나고 조명이 켜져 있는 상황입니다. 학생이 로그인하고, 홈에서 포인트를 확인한 뒤, 제보 화면에서 사진을 찍고 위치를 선택합니다. 그러면 백엔드가 Cloud Run AI에 분석을 요청하고, 낭비가 확인되면 제보가 저장되고 +100P가 즉시 적립됩니다. 마지막으로 포인트샵에서 기프티콘으로 교환할 수 있죠. [멈춤] 구현 범위를 명확히 말씀드리면, AI 판별과 전체 UI, Google OAuth, 장소 관리 CRUD, Docker 배포는 완료 상태입니다. AI 진행 UX 애니메이션과 포인트 적립 연동은 UX 시연용 mock으로 시연합니다.

핵심 포인트: ① 6단계 제보 플로우 완성 ② BE→Cloud Run AI 실연동 ③ mock과 완료 범위 명확 구분
소요 시간: 1.1분

# 07_기술스택

[전환] 기술 스택을 레이어별로 간략히 정리하면, 프론트는 React 19에 TailwindCSS v4, Redux-Saga, shadcn/ui를 사용했고, 백엔드는 Spring Boot 4와 MySQL 8.4, JWT, Google OAuth2, Flyway로 구성했습니다. AI는 YOLOv8n 두 개와 Gemini 2.5 Flash를 FastAPI로 감싸 Cloud Run에 배포했고, 인프라는 Docker Compose로 ubuntu03 서버에 24시간 운영 중입니다. 아키텍처는 React → Spring Boot → MySQL, 그리고 Spring Boot → Cloud Run FastAPI → Gemini로 이어지는 단방향 흐름입니다.

핵심 포인트: ① React+Spring Boot 레이어드 풀스택 ② Cloud Run AI 실배포 ③ ubuntu03 24시간 운영
소요 시간: 0.6분

# 08_기대효과

[전환] 기대 임팩트를 숫자로 보여드리면, 100개 강의실 기준 월 600~1,000kWh를 절약할 수 있고, 이는 월 280~470kg의 CO₂ 절감, 연간 소나무 50~80그루의 흡수량에 해당합니다. 전기료로는 월 8~13만 원 절약이 가능합니다. [멈춤] 더 나아가 전국 430개 4년제 대학, 공공기관, 오피스, 아파트 공용부까지 확장할 수 있습니다. 학생이 스스로 만드는 탄소중립 문화, IoT 없는 스마트캠퍼스, 이것이 EcoReport의 사회적 가치입니다.

핵심 포인트: ① 월 600~1,000kWh 절약 추정 ② 소나무 50~80그루 탄소 흡수량 ③ 전국 확장 가능성
소요 시간: 0.5분
