## 템플릿 파일 구조

각 템플릿은 아래 표준 파일을 포함합니다(목차는 선택).

| 파일명 | 필수 | 용도 | 설명 |
|----------|----------|---------|-------------|
| `design_spec.md` | 예 | 설계 명세 | 색·타이포·레이아웃 전체 명세 |
| `01_cover.svg` | 예 | 표지 | 제목·부제·날짜·기관 |
| `02_toc.svg` | 선택 | 목차 | 챕터 목록·내비게이션 |
| `02_chapter.svg` | 예 | 챕터 | 챕터 번호·제목 |
| `03_content.svg` | 예 | 본문 | 고정 헤더/푸터, 유연 본문 영역 |
| `04_ending.svg` | 예 | 맺음 | 감사 인사·연락처 |

> **설계 철학**: 템플릿은 시각적 일관성·구조적 페이지를 정의하고, 본문 페이지는 유연성을 최대화해 실제 콘텐츠에 맞게 AI가 배치를 정합니다.

## design_spec.md 표준 구조

모든 템플릿 설계 명세는 아래 장 구조를 따릅니다.

```markdown
# [템플릿 이름] - 설계 명세

> 적용 시나리오 한 줄 설명

## I. 템플릿 개요
## II. 캔버스 명세
## III. 색 구성
## IV. 타이포 체계
## V. 페이지 구조
## VI. 페이지 유형
## VII. 레이아웃 모드(권장)
## VIII. 간격 명세
## IX. SVG 기술 제약
## X. 플레이스홀더 명세
## XI. 사용 가이드(권장)
```

## 사용법

### 라이브러리에서 프로젝트로 복사

```bash
# Google 스타일
cp templates/layouts/google_style/* projects/<프로젝트>/templates/
```

### 복사 후

1. `design_spec.md`를 읽고 설계 명세를 이해합니다.
2. 필요 시 프로젝트 요구에 맞게 색을 조정합니다.
3. 로고 파일은 `images/`에 둡니다.
4. 실행자 역할로 템플릿 기반 SVG 페이지를 생성합니다.

## SVG 기술 제약(모든 템플릿 준수)

#### 필수

- viewBox: `0 0 1280 720`
- 배경은 `<rect>`
- 줄바꿈은 `<tspan>`
- 투명도는 `fill-opacity` / `stroke-opacity`
- 그라데이션은 `<defs>`의 `<linearGradient>` 등

#### 금지(PPT 비호환)

| 금지 요소 | 대안 |
|----------------|-------------|
| `<foreignObject>` | `<text>` + `<tspan>` |
| `clipPath` | 레이아웃 재설계 |
| `mask` | `fill-opacity` 등 |
| `<style>` / `class` | 인라인 속성 |
| `textPath` | 일반 `<text>` |
| `animate*` | 정적 디자인 |
| `script` | 상호작용 미지원 |
| `rgba()` | HEX + `fill-opacity` |
| `<g opacity="...">` | 자식마다 불투명도 |
