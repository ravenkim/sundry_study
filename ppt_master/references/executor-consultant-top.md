# 실행자 상위 컨설팅 — MBB급 스타일

> 공통 지침: executor-base.md. 기술 제약: shared-standards.md.

---

## 역할 정의

MBB급(맥킨지·베인·BCG) 상위 컨설팅 스타일 SVG 실행자. 전략 수립·이사회·투자 로드쇼·C레벨 의사지원 등 **프리미엄 컨설팅**. 데이터 기반 인사이트·피라미드 서사·극도의 단순함. 청중은 C레벨 의사결정자.

---

## SCQA 프레임(서사 구조)

MBB급 자료는 SCQA를 따릅니다.

| 요소 | 역할 | 전형적 페이지 |
|---------|---------|---------------|
| **S - 상황** | 공감대 형성 | 표지·1~2페이지 |
| **C - 복잡화** | 문제·긴장 제시 | 2~3페이지 |
| **Q - 질문** | 풀어야 할 질문 | 전환 페이지 |
| **A - 답** | 핵심 답 | 본문 전반 |

**순서**: 표지가 S+C 성격 → 요약이 Q에 답 → 챕터가 A 전개 → 맺음이 S 회고

**제목 쓰기**:

| SCQA | 약한 제목 | MBB급 제목 |
|-------------|------------|-----------------|
| S | "산업 배경" | "디지털 침투율 60% 돌파, 산업은 심화 국면" |
| C | "직면 과제" | "그러나 세 가지 구조적 모순이 확대 배포를 제약" |
| Q | "전략 질문" | "18개월 안 파일럿에서 전면 배포로 어떻게 넘길 것인가?" |
| A | "해결책" | "세 단계: 집중·확장·스케일" |

## 데이터 맥락화(단독 수치 금지)

> **황금률**: 수치는 단독으로 두지 않는다. 비교 문맥이 필요하다.

| 방법 | 패턴 | 시각 구현 |
|--------|---------|----------------------|
| **시간 비교** | "X에서 Y로" | 추세선+변화폭 화살표 |
| **벤치마크** | "X 대 업계 평균 Y" | 회색 점선 기준 막대 |
| **경쟁 비교** | "자사 X 대 경쟁사 Y" | 나란히 막대, 자사 강조 |
| **목표 갭** | "실적 X / 목표 Y" | 진행 바+갭 주석 |
| **순위** | "M개 중 N위" | 가로 막대+순위 표시 |

**데이터 주석 세 가지**: (1) 값 자체(크고 볼드) (2) 비교 기준(전기·업계·경쟁사) (3) 의미("그래서 무엇인가")

```xml
<text x="160" y="280" text-anchor="middle" font-size="42" font-weight="bold" fill="#1E293B">97.3%</text>
<text x="160" y="310" text-anchor="middle" font-size="13" fill="#64748B">업계 평균 82% | 경쟁사 A 89%</text>
<text x="160" y="335" text-anchor="middle" font-size="12" fill="#059669">업계 대비 15.3%p 우위</text>
```

## 피라미드 원칙(결론 우선)

> 임원은 *과정*이 아니라 *결과*에 관심이 있다.

```
         ┌─────────────────┐
         │  핵심 결론      │   ← 페이지 제목·테이크어웨이
         └────────┬────────┘
      ┌───────────┼───────────┐
  ┌───┴───┐  ┌───┴───┐  ┌───┴───┐
  │ 논거1 │  │ 논거2 │  │ 논거3 │   ← 핵심 뒷받침
  └───────┘  └───────┘  └───────┘
```

| 단계 | 위치 | 글자 |
|-------|----------|-----------|
| 핵심 결론 | 테이크어웨이 박스 | 16~18px 볼드 |
| 논거 | 본문 | 14~16px |
| 지원 데이터 | 차트·카드 | 12~14px |

**대비**: 제목 "시장 조사 결과"(X) → "메타버스 상용화에는 5~10년"(O); 본문 "조사 결과…"(X) → "세 가지 논거: (1)…(2)…(3)…"(O)

## MBB급 레이아웃 패턴

### 본문 페이지 표준 구조(1280×720)

```
┌──────────────────────────────────┐
│ 그라데이션 상단 바 (0,0 → 1280,6) │
├──────────────────────────────────┤
│ 주장형 제목 (x=40, y=50, 24px)    │
├──────────────────────────────────┤
│ 테이크어웨이 박스 (x=40, y=75,    │  ← 어두운 배경+흰 글, 한 문장 결론
│   w=1200, h=45)                  │
├──────────────────────────────────┤
│ 본문 (x=40, y=140,               │  ← 차트·데이터·분석
│   w=1200, h=520)                 │
├──────────────────────────────────┤
│ 출처 | 기밀 | 페이지 #           │  ← y=700, 10px
└──────────────────────────────────┘
```

### 전략 로드맵

3단계 가로 배치, `<rect rx="8">`+제목+행동 목록, `<polygon>` 화살표 연결:

```
핵심 집중(0~6개월)  ──→  역량 확장(6~12개월)  ──→  스케일(12~18개월)
x=40,w=380              x=450,w=380                     x=860,w=380
```

### 벤치마킹 매트릭스

가로 표; 자사 행은 테마색, 나머지 회색. 선행 지표는 녹, 후행은 적. `<circle>` 또는 `<rect>`로 점수 표현.

### 워터폴(변화 귀인)

시작 → 증감 요인 → 끝. 증가 녹, 감소 적, 시작·끝 짙은 막대, 누적은 점선 연결.

## 전략적 색 사용

MBB는 색을 절제하며 **정보 전달**에 씁니다.

| 목적 | 방법 |
|---------|--------|
| **초점** | 대상 데이터만 테마색, 나머지 회색 |
| **인지 부하 감소** | 같은 시리즈는 `fill-opacity` 1.0/0.6/0.3 |
| **의미** | 녹=긍정, 적=부정, 회색=기준 |
| **브랜딩** | 그라데이션 상단 바·장식선에 브랜드색 |

**금기**: 주색 3개 초과; 포인트색 전역 남발 금지; 데이터 시리즈는 색이 아니라 농도 변주; 배경은 흰색 또는 아주 연한 회색.

## 차트 vs 표 선택

| 상황 | 권장 형태 | 이유 |
|----------|-----------------|--------|
| 범주 2~7 비교 | **막대** | 직관적 비교 |
| 시계열 추세 | **선** | 시간 흐름 명료 |
| 정밀 값·긴 순위 | **표** | 막대 50개는 혼란 |
| 구성 비 | **도넛** | 파이보다 현대적 |
| 2차원 포지션 | **2×2 매트릭스** | 전략 사분면 |
| 변화 귀인 | **워터폴** | 요인 분해 |

## 발표 노트 스타일

### 내러티브 톤

**임원·의사결정자** 대상. 피라미드 — 문장마다 정보. 침착·권위·통찰.

### 연출 마커

| 마커 | 용도 | 예 |
|--------|---------|---------|
| `[멈춤]` | 핵심 인사이트 후 흡수 | "이는 10억 달러 시장을 놓친다는 뜻입니다. [멈춤]" |
| `[관찰]` | 반응 보고 상세 여부 결정 | "[관찰] 질문 있으시면 그때 확장하겠습니다." |
| `[데이터]` | 구어체 수치 | "[데이터] 63%는 거의 3분의 2" |
| `[벤치마크]` | 비교 기준 강조 | "[벤치마크] 업계 평균 12% 대비 자사 23%는 거의 두 배" |
| `[전환]` | 이전 페이지 연결, 각 페이지 첫머리 | "[전환] 전략 틀 위에서 실행 경로를 보겠습니다." |

### 작성 지침

- **피라미드**: 결론 → 논거 → 세부
- **수치 맥락화**: 모든 숫자에 비교 축
- **임원 언어**: "전략적 함의는…", "핵심 인사이트는…"
- **유연 표기**: 시간 부족 시 생략 가능한 내용에 표시
- **핵심 포인트**: `핵심 포인트: (1) 핵심 인사이트 (2) 데이터 뒷받침 (3) 전략적 함의`

### 노트 예시

```markdown
# 03_strategic_path

[전환] 문제와 기회를 정리했으니 가장 중요한 대응 경로입니다.

3단계 전략을 권고합니다. [멈춤]

1단계: 집중. 향후 6개월 동안 자원을 화동 시장 정복에 쏟습니다.
[데이터] 화동은 업계 성장의 거의 3분의 2를 차지하고, [벤치마크] 침투율은 경쟁사 A의 절반에 불과합니다. [멈춤]

2단계: 확장. 화동을 템플릿으로 화남·화북에 복제.
3단계: 스케일. 디지털 플랫폼으로 전국 커버리지.

[관찰] 1단계 자원 배분은 부록에 있습니다 — 지금 상세가 필요하신가요?

핵심 포인트: (1) 집중-확장-스케일 (2) 화동 우선의 데이터 근거 (3) 18개월 전면 배포
소요 시간: 3분
유연: [시간 부족 시 2·3단계 세부는 생략하고 재무 영향으로 점프]
```

## MBB급 품질 체크 보충

### 콘텐츠

- [ ] **SCQA 완결**: 서사가 상황-복잡화-질문-답 구조
- [ ] **데이터 맥락화**: 모든 수치에 비교 축
- [ ] **결론 우선**: 매 페이지 테이크어웨이에 한 문장 결론
- [ ] **MECE**: 분류가 상호 배타·전체 포괄

### 시각

- [ ] **의도적 색**: 색이 정보 전달
- [ ] **여백**: 빽빽하지 않음
- [ ] **위계**: 결론>논거>세부가 크기·굵기로 구분
- [ ] **브랜드 일관**: 상단 바·푸터 통일

### 노트

- [ ] **피라미드**: 페이지마다 결론 우선
- [ ] **연출**: `[멈춤]`·`[관찰]`을 요지에 배치
- [ ] **유연**: 시간 조절용 생략 표기
