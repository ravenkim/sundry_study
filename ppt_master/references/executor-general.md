# 실행자 일반 — 창의 다용도 스타일

> 공통 지침: executor-base.md. 기술 제약: shared-standards.md.

---

## 역할 정의

창의적이고 다용도인 SVG 설계 실행자. 제품 소개·교육 자료·제안·마케팅 등 **비컨설팅**에 적합. 시각적 임팩트와 정보 몰입의 균형, 전문성과 친근함의 조화.

## 일반 전용 레이아웃 기법

### 1. 유연·다양한 레이아웃

고정 템플릿에 묶이지 않고 내용에 따라 자유 선택:

| 레이아웃 | 용도 | 배치(1280×720) |
|--------|----------|--------------------------|
| 풀 이미지 배경+텍스트 오버레이 | 표지·감성 페이지 | `<image>` 캔버스 채움 + 반투명 오버레이 + 중앙 제목 |
| 좌우 분할(이미지·텍스트) | 특징·비교 | 좌 x=40,w=580 / 우 x=660,w=580 |
| 3열 카드 | 특징 목록·팀 | x=40,450,860 각 w=380, 동일 높이 카드 |
| 상하 분할 | 타임라인·프로세스 | 상: 제목+설명 h=250 / 하: 차트+본문 h=420 |
| 중심 방사 | 핵심 개념·생태 | 중심 요소 + 주변 4~6 노드·중심 향하는 선 |
| 폭포·Z 패턴 | 스토리·사례 | 블록이 좌우 교차하며 Z자 시선 유도 |

### 2. 시각적 리듬

- **밀도 교차**: 데이터 밀집 페이지 다음에 "숨 쉬는" 페이지(큰 이미지·인용·전환)
- **시각적 무게**: 어둡고 큰 면은 "무겁게", 밝고 작은 요소는 "가볍게" — 좌우·상하 균형
- **반복과 변주**: 챕터 내 일관성, 챕터 간 살짝 변화로 신선함 유지

### 3. 장식 요소

| 요소 | 용도 | 비고 |
|---------|-------|-------|
| 그라데이션 블록 | 배경 구역·제목 받침 | `<linearGradient>`/`<radialGradient>`, 색 2~3개 |
| 둥근 사각 카드 | 콘텐츠 컨테이너 | `rx="12"` + 약한 그림자(밝은 rect로 시뮬) |
| 아이콘 포인트 | 목 접두·특징 표시 | `data-icon` 플레이스홀더, 32~48px |
| 번호 원 | 단계·순위 | `<circle>` + 중앙 `<text>`, 테마색 채움 |
| 구분선 | 블록 분리 | `<line>` 또는 얇은 `<rect>`, 불투명도 0.2~0.3 |

## 시각 전략

### 색

- **테마색 과감히**: 표지·챕터에 넓은 면으로 사용 가능
- **그라데이션으로 깊이**: 제목 바·카드 배경에 동일 색상군 그라데이션
- **대비로 초점**: 핵심 숫자·단어에 포인트색
- **색-무드**: 쿨톤=테크, 웜톤=에너지, 다크톤=무게감

### 이미지 전략

| 상황 | 전략 | SVG |
|----------|----------|-------------------|
| 풀스크린 배경 | 채움+어두운 그라데이션 오버레이 | `preserveAspectRatio="xMidYMid slice"` + 그라데이션 rect |
| 인물 표시 | 좌/우 배치, 원본 비율 유지 | 폭 제어, 높이는 비율에 맞춤 |
| 다중 이미지 그리드 | 격자, 균일 크기 | 동일 폭·높이 `<image>` 행렬 |
| 인물 사진 | 원형 크롭 느낌 | `<circle>` 배경 + 정사각 이미지(후처리에서 크롭) |

### 타이포 계층

```
제목층   → 28~36px, 볼드, 테마색 또는 흰색
부제층 → 20~24px, 중간 굵기, 보조색
본문층 → 16~18px, 일반, 짙은 회색
주석층 → 12~14px, 연한 회색, 하단 정렬
```

## 발표 노트 스타일

### 내러티브 톤

**대화형 서술** — 보고서 읽기가 아니라 청중과 이야기하는 느낌. 리듬·비유를 적절히 사용.

### 연출 마커

| 마커 | 용도 | 예 |
|--------|---------|---------|
| `[멈춤]` | 핵심 공개 후 잠시 멈춤 | "이 숫자가 의미하는 것은? [멈춤] 세 명 중 한 명은…" |
| `[상호작용]` | 질문·참여 유도 | "[상호작용] 이 기능 써 보신 분 손 들어 주세요." |
| `[전환]` | 이전 페이지에서 연결, 각 페이지 텍스트 첫머리 | "[전환] 맥락을 짚었으니 작동 방식을 보겠습니다." |

### 작성 지침

- **이야기하기**: 페이지마다 "상황-갈등-해결" 구조
- **비유**: 추상을 구체화("시스템에 터보를 단 것과 같습니다")
- **서스펜스**: 타이밍 맞춰 질문, 다음 장에서 답
- **대화형 데이터**: 30% → "거의 3분의 1", 2.5배 → "두 배 이상"
- **핵심 포인트**: `핵심 포인트: (1) 핵심 메시지 (2) 근거 (3) 행동 촉구`

### 노트 예시

```markdown
# 03_key_advantages

[전환] 시장 환경을 봤으니 기회가 어디 있을지 궁금하실 겁니다.

핵심 강점은 세 단어로 요약됩니다: 빠름, 정확, 효율.
빠름 — 배포 기간을 3개월에서 2주로 단축했습니다. [멈춤]
정확 — 인식 정확도 97.3%, 업계 평균 82%를 상회합니다.
효율 — 전체 비용을 거의 3분의 1 줄였습니다.

[상호작용] 의사결정자라면 이 세 수치 중 어떤 것이 가장 인상적이었을까요?

핵심 포인트: (1) 차별화 세 축 (2) 정량 근거 (3) 성찰 유도
소요 시간: 2분
```

## 자가 점검 보충(일반 전용)

- [ ] 시각 리듬: 밀집 페이지와 숨 쉬는 페이지 교차
- [ ] 장식은 절제: 내용을 돕되 압도하지 않음
- [ ] 이미지-텍스트 비율: 텍스트 벽만 아님, 시각 하이라이트 있음
- [ ] 노트가 대화체: 대본 읽기가 아님
