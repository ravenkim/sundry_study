# 이미지 레이아웃 명세(필수)

이미지가 있는 페이지의 레이아웃 규칙. 전략가 계획 단계와 실행자 생성 단계 모두 준수합니다.

**핵심 원칙: 이미지 원본 종횡비로 레이아웃을 계산해 불필요한 여백·크롭 없이 표시합니다.**

---

## 레이아웃 결정 흐름

```
1. 이미지 원본 치수 → 비율(가로/세로) 계산
2. 비율에 따라 레이아웃 유형 선택
3. 이미지 최대 표시 크기 계산
4. 남는 공간에 텍스트 영역 배분
5. 설계 명세 이미지 자원 목록에 기입
```

**실행 시점**: 이미지 방식에 "B) 사용자 제공"이 포함되면, 전략가가 여덟 가지 확인을 마친 뒤·콘텐츠 분석·개요 전에 스캔을 실행하고 이미지 자원 목록을 채웁니다.

---

## 레이아웃 유형 선택(필수)

| 이미지 비율 | 레이아웃 | 이미지 위치 | 설명 |
|-------------|-------------|----------------|-------------|
| > 2.0(초광각) | 상하 분할 | 상단 전폭 | 캔버스 폭에 맞추고 높이는 비율에 따름 |
| 1.5~2.0(광각) | 상하 분할 | 상단 | 콘텐츠 폭=이미지 폭, 높이 비례 |
| 1.2~1.5(일반 가로) | 좌우 분할 | 좌 | 높이 우선 맞춤, 가로 비례 |
| 0.8~1.2(정사각에 가까움) | 좌우 분할 | 좌 | 콘텐츠 영역 높이에 맞춤, 가로 비례 |
| < 0.8(세로) | 좌우 분할 | 좌 | 높이=콘텐츠 영역 높이, 가로 비례 |

> 경계(예: 1.5): 텍스트 양으로 결정 — 텍스트 많으면 좌우, 적으면 상하.

## 치수 계산식

### 캔버스 파라미터(형식 공통)

| 형식 | 캔버스 | 여백(좌우, 상하) | 콘텐츠 영역(W×H) | 제목 높이 | 본문 시작 Y |
|--------|--------|--------------------|-----------------------|-------------|----------------|
| PPT 16:9 | 1280×720 | 60, 60 | 1160 × 600 | 60px | 80px |
| PPT 4:3 | 1024×768 | 50, 50 | 924 × 608 | 60px | 70px |
| 샤오홍슈 | 1242×1660 | 60, 80 | 1122 × 1500 | 80px | 100px |
| 위챗 모멘츠 | 1080×1080 | 60, 60 | 960 × 960 | 60px | 80px |
| 스토리 | 1080×1920 | 60, 120/180 | 960 × 1620 | 80px | 140px |
| 위챗 기사 | 900×383 | 40, 40 | 820 × 303 | 40px | 50px |

> 아래 식에서 **W**·**H**는 제목을 뺀 콘텐츠 영역 가로·세로입니다. PPT 16:9 예: W=1160, H=600.

### 상하 분할

```
이미지 폭 = W = 1160 px
이미지 높이 = W / R = 1160 / R px
텍스트 영역 높이 = H - 이미지 높이 - 간격(20px)

검증: 텍스트 높이 >= 150px(최소 3~4줄)
불만족 → 좌우 분할로 전환
```

### 좌우 분할

**방법 1(높이 우선, 세로 이미지에 적합)**:
```
이미지 높이 = H = 600 px
이미지 폭 = H × R = 600 × R px
텍스트 폭 = W - 이미지 폭 - 간격(20px)
```

**방법 2(폭 제한, 광각을 좌우로 쓸 때)**:
```
이미지 폭 = W × 0.7 = 812 px
이미지 높이 = 이미지 폭 / R
텍스트 폭 = W - 이미지 폭 - 간격(20px)
```

**검증**: 텍스트 폭 >= 280px; 아니면 이미지 영역 폭 축소.

## 레이아웃 예시

### 초광각(비율 2.45)

```
원본: 1960×800, R=2.45 → 상하 분할
이미지: 1160×473, 텍스트: 1160×147 → 상하 약 7:3
```

### 일반 가로(비율 1.38)

```
원본: 1614×1171, R=1.38 → 좌우 분할
이미지: 773×560(좌), 텍스트: 367×560(우) → 좌우 약 7:3
```

### 광각 경계(비율 1.75)

```
원본: 1820×1040, R=1.75
상하 시도: 이미지 높이=663, 텍스트=-43 ❌
좌우 전환: 이미지 780×446(좌), 텍스트 360×600(우) → 좌우 약 7:3
```

## 세로 캔버스 재정의

기본 표는 **가로 또는 정사각 캔버스**를 가정합니다. 세로(높이>가로)에서는 좌우 열이 너무 좁아져 규칙이 달라집니다.

| 캔버스 방향 | 이미지 비율 | 권장 레이아웃 | 이유 |
|-------------------|-------------|-------------------|--------|
| 세로(샤오홍슈, 스토리) | > 1.5(광각) | 상하 | 가로와 동일 |
| 세로 | 1.2~1.5(일반) | 상하 | 세로 캔버스에서 좌우는 과도하게 좁음 |
| 세로 | 0.8~1.2(정사각에 가까움) | 상하 | 상단 절반에 이미지가 잘 맞음 |
| 세로 | 0.5~0.8(세로) | 좌우 | 긴 캔버스에서 세로 이미지가 한쪽에 적합 |
| 세로 | < 0.5(극세로) | 좌우 | 한쪽 이미지·한쪽 텍스트 |

> 정사각(위챗 모멘츠 1:1)은 가로 캔버스 규칙을 사용합니다.

## 다중 이미지 레이아웃

한 슬라이드에 이미지가 여러 장이면 콘텐츠 영역을 균등 분할합니다.

### 그리드 식

```
열 수 = columns
행 수 = rows
간격 = 20px(PPT) 또는 30px(소셜)

셀_폭  = (W - (columns - 1) * gap) / columns
셀_높이 = (H - (rows - 1) * gap) / rows
```

### 흔한 패턴

| 장수 | 레이아웃 | 그리드 | 설명 |
|-------------|--------|------|-------------|
| 2(둘 다 가로) | 나란히 | 2×1 | 동일 폭 두 열 |
| 2(둘 다 세로) | 위아래 | 1×2 | 동일 높이 두 행 |
| 2(혼합) | 큰+작음 | 맞춤 | 위 가로 전폭+우하 세로 |
| 3 | 큰+작은 둘 | 1+2 | 좌 큰(폭 50%), 우열에 2행 스택 |
| 4 | 격자 | 2×2 | 동일 셀 |

### PPT 16:9에서 2×2 예

```
W=1160, H=600, gap=20
셀_폭  = (1160 - 20) / 2 = 570
셀_높이 = (600 - 20) / 2 = 290

위치:
  (60, 80)   570×290    (650, 80)  570×290
  (60, 390)  570×290    (650, 390) 570×290
```

> 다중 이미지는 모든 `<image>`에 `preserveAspectRatio="xMidYMid meet"`로 셀 안 표시를 통일합니다.

## 금지 관행

| 금지 | 올바른 접근 |
|-----------|-----------------|
| 고정 50:50 등 임의 비율 | 이미지 비율에 따른 동적 계산 |
| 광각을 정사각에 억지 배치 | 상하 또는 이미지 영역 폭 확대 |
| 세로 이미지를 가느다란 가로 띠에 | 좌우 분할·이미지 좌측 |
| 이미지 주변 공백 10% 초과 | 레이아웃 재계산 또는 대안 |
| 핵심이 잘리는 크롭 | `preserveAspectRatio="xMidYMid meet"` |
| 텍스트 영역 과소 | 상하 시 텍스트 높이 ≥150px, 좌우 시 폭 ≥280px |

```xml

       x="60" y="80" width="780" height="446"
       preserveAspectRatio="xMidYMid meet"/>
```

### 채움 크롭(배경만)

```xml
<image href="../images/bg.png"
       x="0" y="0" width="1280" height="720"
       preserveAspectRatio="xMidYMid slice"/>
```

## 이미지 자원 목록 템플릿

설계 명세·콘텐츠 개요의 이미지 자원 표에 포함:

| 필드 | 설명 | 예 |
|-------|-------------|---------|
| 파일명 | 이미지 파일명 | `p12_0.png` |
| 원본 치수 | 가로×세로 | 1524×968 |
| 비율 | 가로/세로 | 1.57 |
| 페이지 | 사용 슬라이드 | 5페이지 |
| 유형 | 시각 유형 | 배경·사진·삽화·다이어그램·장식 |
| 레이아웃 계획 | 상하/좌우+분할 비 | 상하 6:4 또는 좌우 7:3 |
| 이미지 영역 | 표시 치수 | 1160×420 또는 780×446 |
| 텍스트 영역 | 남는 공간 치수 | 1160×200 또는 360×600 |

**유형** 필드는 Image_Generator의 프롬프트 전략 선택에 씁니다.

## 자동화 도구

```bash
python3 scripts/analyze_images.py <프로젝트경로>/images                    # 기본: PPT 16:9
python3 scripts/analyze_images.py <프로젝트경로>/images --canvas ppt43     # PPT 4:3
python3 scripts/analyze_images.py <프로젝트경로>/images --canvas xiaohongshu  # 샤오홍슈
```

`--canvas`로 대상 캔버스(기본 `ppt169`)를 고릅니다. 이 명세의 식으로 레이아웃 유형·이미지·텍스트 영역 치수를 계산하고, 이미지 자원 목록에 바로 붙일 Markdown 표를 출력합니다.
