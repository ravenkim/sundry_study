| 형식 | viewBox | 비율 | 용도 |
|--------|---------|-------|----------|
| PPT 16:9 | `0 0 1280 720` | 16:9 | 비즈니스 발표·회의 |
| PPT 4:3 | `0 0 1024 768` | 4:3 | 구형 프로젝터·학술 발표 |
| 샤오홍슈(RED) | `0 0 1242 1660` | 3:4 | 이미지+텍스트·지식 포스트 |

| 스토리 / 틱톡 | `0 0 1080 1920` | 9:16 | 세로 스토리·숏폼 커버 |
| 위챗 기사 헤더 | `0 0 900 383` | 2.35:1 | 위챗 기사 커버 이미지 |
| 가로 배너 | `0 0 1920 1080` | 16:9 | 웹 배너·디지털 사이니지 |
| 세로 포스터 | `0 0 1080 1920` | 9:16 | 모바일·엘리베이터 광고 |
| A4 인쇄 | `0 0 1240 1754` | 1:√2 | 인쇄 포스터·전단 |

## 형식 선택 의사결정

```
콘텐츠 목적?
├── 발표
│   ├── 최신 기기 → PPT 16:9 (1280x720)
│   └── 전통 기기 → PPT 4:3 (1024x768)
├── 소셜 공유
│   ├── 샤오홍슈 → 1242x1660
│   ├── 위챗 모멘츠 / IG → 1080x1080
│   └── 스토리 / 틱톡 → 1080x1920
└── 마케팅 자료
    ├── 위챗 기사 헤더 → 900x383
    ├── 배너 → 1920x1080
    └── 인쇄 → 1240x1754
```

## 레이아웃 원칙

### 가로(16:9, 4:3, 2.35:1)
- 시선 흐름: Z자형, 좌→우
- 여백: 40~80px
- 레이아웃: 다열, 좌우 분할, 그리드
- 카드 크기(16:9): 단열 행 530~600px, 이중 행 265~295px

### 세로(3:4, 9:16)
- 시선 흐름: 상→하
- 여백: 60~120px
- 레이아웃: 단열, 상하 분할, 카드 스택
- 카드 크기(3:4): 높이 400~600px, 간격 40~60px

### 정사각(1:1)
- 시선 흐름: 중심 방사
- 여백: 60~100px
- 핵심 영역: 약 800×800px

## 형식별 디자인

| 형식 | 제목 영역 | 본문 영역 | 특이 사항 |
|--------|-----------|--------------|---------------|
| PPT | 80~100px | 전폭 활용 | 페이지 번호 우하단 |
| 샤오홍슈 | 180~240px(강조) | 상하 여백 넉넉 | 하단 120~160px 브랜드 |
| 위챗 모멘츠 | 200~280px | 중앙 500~600px | 하단 150~200px QR 영역 |
| 스토리 | — | 중앙 1500px 부근 | 상단 안전 120px, 하단 180px |
| 위챗 기사 헤더 | 중앙/좌 정렬 48~72px | — | 이미지 우측 또는 배경 |

## viewBox 예시

```xml
<svg width="1280" height="720" viewBox="0 0 1280 720">   <!-- PPT 16:9 -->
<svg width="1242" height="1660" viewBox="0 0 1242 1660"> <!-- 샤오홍슈 -->
<svg width="1080" height="1080" viewBox="0 0 1080 1080"> <!-- 위챗 모멘츠 -->
<svg width="1080" height="1920" viewBox="0 0 1080 1920"> <!-- 스토리 -->
<svg width="900" height="383" viewBox="0 0 900 383">     <!-- 위챗 기사 헤더 -->
```
